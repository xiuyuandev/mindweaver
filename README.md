# 织思 / MindWeaver 1.0

仅 Windows 的纯 Rust 原生思维导图 + 概念图 + 卡片笔记工具。本地文件、中文优先、离线可用。

技术栈：Rust + egui/eframe + wgpu + DirectWrite。
禁止：WebView / HTML / CSS / JS / Electron / Tauri。

1.0 只做本文列出的能力。未列出的能力不属于 1.0 范围。

---

## 1. 1.0 必须有的能力

### 1.1 文件与文档

- 新建、打开、保存、另存为；单窗口多标签。
- 原子写入、3 秒自动恢复点、崩溃恢复、滚动备份。
- 外部修改检测、文件锁/只读、关闭前未保存确认。
- 最近文件、起始页、模板、`.zmind` 文件关联、单实例。
- `.zmind` 旧文件继续可读；格式扩展不破坏旧文件。

### 1.2 思维导图画布

- 节点增删改、层级移动、复制/剪切/粘贴、`Ctrl+D`、多选与批量操作。
- `Tab` 子节点、`Enter` 同级、`F2`/双击/直接输入编辑；`Shift+Enter` 软换行。
- 撤销/重做，栈上限 100–2000 可配；一次用户动作一条撤销。
- 折叠/展开、整图折叠、聚焦子树、双击圆点逐级展开。
- 拖拽重排（前/内/后三区）、非法落点反馈、跨层拖动、`Esc` 取消。
- 画布平移/缩放：滚轮、中键、空格拖、`Ctrl+滚轮` 锚点缩放、`Ctrl+0/1/2`。
- 小地图、面包屑、空格握把、悬停工具条；选中节点常显「＋」加子主题。
- 五种布局：放射式思维导图、逻辑图向右、组织结构图向下、鱼骨图、时间轴；切换与整理布局。
- 关系线、概要、边界、自由主题、概念分组、图片。

### 1.3 样式、主题与检查器

- 四套内置主题：纸感 `snow`、墨夜 `ink`、雾青 `mist`、暖砂 `sand`；概念图四套 `cm-*`。
- 节点级覆盖：填充、边框色/宽、文字色、字号、字重、斜体/下划线/删除线、对齐、圆角、形状、分支色。
- 分支线：颜色、线宽、线型、箭头、锥形；概念图命题线同套编辑。
- 快速样式复制/粘贴、恢复默认。
- 检查器 288 px 宽（可拖 240–360，记忆），头行 40、对象行 44、分段 30、分组 28、组内行距 6。
- 检查器内容：样式、内容（备注/链接/标签/任务/卡片来源）、概念排布；全键盘可达。
- 图标/标记/任务状态/优先级选择器；标签颜色与层级。
- 全部文字对比度 ≥ 4.5:1，图形/状态色 ≥ 3:1；遵循系统「减少动画」。

### 1.4 内容表面

- 全屏大纲：行 32、缩进 24、版心 800、页头 40、页脚 24；行内编辑、搜索、多选、折叠、拖拽。
- 卡片笔记页：单一编辑表面（无预览/编辑分栏）；正文版心 640；标题/正文/列表/元信息按内容字阶。
- 笔记库：侧栏 232（可拖 200–280）、列表 360（可拖 320–440）；三/两/单栏断点 1200/840；行 60。
- 卡片库搜索：标题/正文/标签/来源；拼音/精确文本；标签 AND；批量选择与操作。

### 1.5 搜索与导航

- 全局搜索 `Ctrl+F`：节点标题、备注、链接、标签、概念图命题短语。
- 默认拼音（原文/全拼/首字母），可切精确文本；结果分组、±24 字摘录、命中高亮。
- 结果跳转：折叠子树先展开祖先（一条批量撤销）；聚焦视图外先退出聚焦。
- `Ctrl+H` 标题逐个/全部替换，带预览。
- 大纲/画布/检查器选中同步；节点、关系线、注解三条选中道互斥。

### 1.6 卡片笔记与库

- 卡片可挂在节点上或独立存在；正文 Markdown。
- 3 秒自动保存、两阶段保存、失败不丢稿、`Ctrl+S` 重试。
- 外部修改行内条（重新加载/覆盖/取消）；只读卡片禁止编辑。
- 卡片与节点双向跳转；库是归档状态唯一真相源。

### 1.7 概念图

- 独立概念、自由摆放、有向命题线、四档箭头、线型/线宽/命题注释。
- `Ctrl+L` 连线态、两选直连、新建概念并连接、反向连接、短语建议。
- 概念分组、钉住位置、整理全部/仅选中。
- 概念检查器、概念图大纲与行菜单、命题短语进全局搜索。
- `.cxl` 打开/保存自身文件；PNG/SVG/PDF 与画布同源。

### 1.8 导入导出

- 导入：`.zmind`、Xmind（常用字段）、Markdown、OPML、FreeMind、缩进纯文本。
- 导出：PNG、SVG、PDF、Markdown、纯文本大纲、OPML、FreeMind。
- 导出与画布读同一份 `Scene`；PNG 支持 1x/2x/3x 与透明背景；PDF 单页自动尺寸。
- 导入到新标签页；失败给出明确原因；常用丢失项写入报告。

### 1.9 演示、设置与系统

- 演示：`F5` 从选中/根开始，`→/空格` 步进、`←` 回退、`Esc` 退出、`H` 隐藏控制条；深色舞台。
- 设置中心：外观/主题、编辑/撤销上限、保存、导出、文件与库、动效。
- 快捷键查看、改绑、冲突检测、禁用单项、恢复默认，`shortcuts.json` 持久化。
- 深浅色跟随系统、Mica/Win11 与 Win10 回退、文件关联、单实例、离线可用。
- 中文：微软拼音实机组合输入、CJK 禁则换行、中英混排、字体不糊、拼音检索。
- DPI：100/125/150/200% 与多屏基础可用。

## 2. 体验与视觉规则

### 2.1 主题

| id | 名称 | 画布底色 | 强调色 | 点阵 |
| --- | --- | --- | --- | --- |
| `snow` | 纸感 | `#FCFBF8` | `#2F6F5E` | 无 |
| `ink` | 墨夜 | `#17191C` | `#D8A75B` | 有 |
| `mist` | 雾青 | 浅青纸底 | 深青 | 无 |
| `sand` | 暖砂 | 暖纸底 | 陶土 | 无 |

- 画布、PNG、SVG、PDF 的底色/点阵只读 `Theme` 唯一出口。
- 换强调色只借色相：强调色、软强调色、两张分支色表、层级默认色一起旋转，彩度/感知明度保持。

### 2.2 画布字阶（唯一合同表）

| 层级 | 字号 | 字重 | 行高倍数 | 单行行高 | 内距 |
| --- | --- | --- | --- | --- | --- |
| 中心 | 28 | 600 | 1.40 | 39.2 | 26×12 |
| 一级 | 20 | 400 | 1.44 | 28.8 | 18×10 |
| 二级 | 16 | 400 | 1.44 | 23.04 | 14×8 |
| 三级+ | 15 | 400 | 1.46 | 21.9 | 14×8 |

- 单行合同盒高：63 / 49 / 39 / 38。
- 字重只用 400/500/600；600 即旧「粗体」，不用 700。
- 概念图：主概念 15、其余 14；盒宽=文字+28，夹 96–240，单行高 36、双行 52。

### 2.3 内容字阶（关键档）

| 角色 | 字号/行高 | 字重 |
| --- | --- | --- |
| 页面标题 H1 | 30/42 | 600 |
| 大纲页标题 | 28/40 | 600 |
| H2 / H3 / H4 | 22/33、18/28、16/26 | 600 |
| 阅读正文 | 16/28 | 400 |
| 列表标题 / 摘要 / 元信息 | 15/22、13/19、12/18 | 600/400/400 |

- 正文不得低于 13；不用纯黑正文；不用低于 4.5:1 的灰。
- 数字/拉丁优先 Segoe UI Variable，中文优先 Microsoft YaHei UI；同行基线对齐。

### 2.4 画布几何

- 节点圆角 10；形状：圆角/直角/胶囊/椭圆/下划线。
- 一级主题实色卡，描边由卡色派生；二级以下淡染分支色。
- 分支线自父端向子端收细；线宽四档；导出同源。
- 画布节点不投影；阴影只给菜单/对话框/悬浮工具条。
- 悬停环 1 px、选中环 1.5 px、键盘焦点 1.5 px + 1 px 外偏移（alpha 0.80）。
- 动效 180 ms 基准；悬停 120 ms；遵循「减少动画」时直接终态。

### 2.5 检查器与面板

- 检查器 288（240–360），头行 40、对象行 44、分段 30 无描边、分组 28、组间 8 px hairline、组内左右 12、行距 6。
- 色板 8 列 × 24 px；第 9 格自定义虚线圆；无颜色斜杠格。
- 数值格可键入、`↑`/`↓` 步进；`Enter` 提交、`Esc` 取消。
- 「本节点 / 含子树」作用域在分组标题右侧；样式编辑 500 ms 合并一条撤销。
- 错误条 28 px；`Esc` 两级（控件→松焦点→回画布）。

### 2.6 内容表面

- 全屏大纲：页头 40、版心 800、页脚 24；行 32、缩进 24、圆点 4；行尾固定 24 px 动作道。
- 卡片页：单一表面；正文 640；H1 30/42；无卡片投影；表格/分栏不做。
- 笔记库：侧栏 232（200–280）、列表 360（320–440）；行 60 三行式；标签 1 个 + `+n`；批量条 44。
- 起始页：版心 880；四张 72 px 快速卡；最近文件异步读，缺失文件留行标灰。

## 3. 数据与格式不变量

1. 文档变更只能走 `mw_core::Command` + 撤销栈；任何面板/壳层不得直接改 `Document`。
2. `.zmind` 是 ZIP + JSON：`mimetype` + `manifest.json` + `content.json` + `notes/` + `assets/`。
3. `Scene` 是几何与视觉唯一真相源：画布、golden、PNG/SVG/PDF 读同一份 `Scene`。
4. `Frame.viewport = Some` 只裁剪到视口；`None` 是全图/导出。
5. 字段扩展不升版本时不破坏旧文件；缺失键 = 老行为；新增字段必须有往返测试。
6. 概念图 `.cxl` 保真槽优先；没有保真槽时按标准 CXL 读概念/命题/坐标/字号/颜色/箭头。
7. 所有坐标是世界单位；屏幕恒定尺寸（圆点/手柄/箭头）在渲染层经镜头换算。
8. 1.0 不扩充多画布/Workbook 数据模型。

## 4. 1.0 验收

### 4.1 用户旅程

1. 新建 → 输入中文 → 建子树 → 改样式 → 保存 → 重开，内容与视口正确。
2. 20k 文档打字、撤销、折叠、搜索不卡（预算见 `DEVELOPMENT.md`）。
3. 全屏大纲编辑 → 卡片页编辑 → 笔记库搜索/归档 → 回到画布，数据一致。
4. 概念图建概念/连线/分组/导出 `.cxl`，再打开保真。
5. Xmind/Markdown 导入 → 编辑 → PNG/SVG/PDF 导出，画面与画布一致。
6. 只读/外部修改/磁盘失败/强退恢复都有明确出口，不丢数据。
7. 微软拼音实机组合输入：候选、确认、取消、光标、快捷键让位正确。
8. 100/125/150/200% DPI 与多屏基础无错位、无糊字。

### 4.2 工程门

- `cargo fmt --all -- --check` 干净。
- `cargo clippy --workspace --all-targets` 与基线比新增 0。
- 全量测试通过；便携 crate 至少 `mw-core`/`mw-format`/`mw-io`/`mw-markdown`/`mw-ui` 全绿。
- `stage-b` 与 `stage-cm` 正式门双跑 `--tol 0` 零差异（Windows 基准机）。
- 安装包/绿色包可启动，版本、许可证、用户手册齐全。

## 5. 文档规则

1. 只有三个文档：`README.md`（产品与范围）、`DEVELOPMENT.md`（工程与实现）、`STATUS.md`（进度与发布）。
2. 不新建说明文档；实现细节写进 `DEVELOPMENT.md`，进度写进 `STATUS.md`。
3. 代码注释里出现的 `docs/xx` 是历史引用；1.0 以本文三份文档为准。
4. 范围外的能力不写、不排期、不做。
