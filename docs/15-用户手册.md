# 织思用户手册（10 分钟上手）

> 适用版本：v0.1.0 开发版（2026-10-30）。界面与快捷键以当前 release 为准；
> 大纲页与卡片页在 B2 中重做过，本手册按重做后的界面写。

## 1. 安装与启动

织思目前提供**免安装绿色版**：解压后运行 `MindWeaver.exe`（开发构建里也叫 `mw-shell.exe`）。需要 Windows 10 1809+ / Windows 11（x64）。

- 也可以按用户安装：`powershell -File scripts/install.ps1 -Source <解压目录>`，装到 `%LOCALAPPDATA%\Programs\MindWeaver`，注册 `.zmind` 文件关联与卸载项；`-Uninstall` 可干净移除。
- 当前发布包**没有代码签名证书**，SmartScreen 可能提示未知发布者；签名钩子与发布流程见 `docs/archive/20-签名与发布.md`。
- 首次启动会落在开始页：新建空白图、打开最近文档、导入其他格式。
- 数据默认都在本地；不登录、不联网、不上传。
- 窗口大小 / 面板宽度 / 上次打开的标签会自动记住；下次启动恢复。

## 2. 新建与打开

| 操作 | 方式 |
| --- | --- |
| 新建空白图 | 开始页「新建空白图」或 `Ctrl+N` |
| 打开 `.zmind` | `Ctrl+O`，或把文件拖进窗口 |
| 最近文档 | 开始页列表；文件被移动后会标灰 |
| 多标签 | `Ctrl+T` 新建标签；`Ctrl+W` 关闭；`Ctrl+Tab` 切换 |
| 另存为 | `Ctrl+Shift+S` |

第一次保存会问路径；之后 `Ctrl+S` 直接写回。保存是原子的：先写临时文件再改名，断电不会留下半份文档。

## 3. 画布基础

- **选中**：单击节点；`Shift` 单击加选；空白处拖框多选；`Alt`+拖空白套索。
- **新建节点**：选中后 `Tab` 建子节点，`Enter` 建同级；双击空白建自由主题。
- **改文字**：双击节点或按 `F2`；`Enter` 提交，`Esc` 取消，`Shift+Enter` 换行。
- **改结构**：拖动节点到目标节点上改父；拖到空白变成自由主题；`Ctrl+拖拽` 复制子树。
- **折叠**：节点右侧圆点单击；折叠状态会保存。
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`）。
- **缩放 / 平移**：滚轮缩放（以指针为锚）；空白拖动或空格+拖动平移；`Ctrl+0` 适配全图。
- **视图跟随**：新建子 / 同级节点后，画布会自动平移让新节点留在屏幕内；为了不抢你的缩放控制，它不会自动缩小——要看全貌按 `Home` 适应画布。

## 4. 检查器（右侧）

选中节点后，检查器分三段（顶行「样式 / 内容 / 标记」）：

- **样式**：分支色／填充／边框三排色板（8 列 × 24 px，第 9 格是自定义色）；字号／边宽是数值格，
  可以直接键入，也能用 `↑`/`↓` 或 `+`/`−` 步进；`Enter` 提交、`Esc` 取消。
  分组标题右侧有作用域开关「本节点 / 含子树」。
- **内容**：备注框（3 行起，超过 8 行可展开）、标签行（6 px 色点 + 文字，没有胶囊）、
  以及卡片的「来源」一行（新建 / 打开 / 解除 / 关联已有卡片）。
- **标记**：图标集。

面板默认 288 宽，可拖到 240–360 并记住；无选中时只显示一句提示。
`Ctrl+Shift+I` 开合检查器（`F9` 是备用键）；`Esc` 先在检查器内逐级退，再退到画布。

## 5. 卡片笔记

每个节点最多挂一张卡片。卡片就在节点旁边打开，是一整页「所见即所得」的 Markdown：
没有阅读 / 编辑两个模式，光标停在哪一行，哪一行才现出 `##`、`**` 这些标记。

- **打开**：选中节点后命令面板「打开卡片」，或从卡片库双击；`Esc` 关闭，`Ctrl+S` 立即保存（平时也会自动保存）。
- **同页编辑**：标题、标签、正文在同一页；标签是芯片，回车连加、点 × 删除，输入时自动补全。
- **正文排版**：标题、粗体 / 斜体 / 行内码 / 删除线、引用、列表、任务框、代码块、分隔线实时生效；正文里写 `[[节点标题]]` 或 `[[卡片标题]]` 形成反链。
- **版式**：只有一栏正文，版心 720 px（窄窗夹到 640），没有常驻侧栏目录；
  页首显示保存状态与阅读字数，光标所在行才现出标记。
- **焦点**：卡片页是前景模态，编辑时 `Enter` / `Esc` 不会漏给底下的画布；`Ctrl+Z` 只撤销文本。

### 卡片库（独立管理页）

命令面板「卡片库」、开始页「卡片库」或「插入 → 卡片库」进入。三栏：

- **左：标签树**——全部 / 收件箱 / 未打标签 / 层级标签，累计计数、颜色点、可折叠；
- **中：卡片列表**——标题、摘要、标签芯片、日期；搜索 + 标签 + 排序组合过滤；
- **右：预览**——Markdown 排版、元信息、字数，可「打开编辑」或「定位节点」。

`Ctrl` 点选或复选框批量选择，可归档到当前主题、导出选中、移出库。页首「管理标签」可重命名 / 合并；
`Esc` 从卡片回到列表，再按一次退出卡片库。

反链与统一搜索：正文里的 `[[…]]` 会在卡片底部列出反链并标出断链；`Ctrl+F` 同时搜节点、卡片、标签、路径。

## 6. 全屏大纲、搜索、命令面板

- **大纲**（`F8`）：不再挤在侧边，整块中央面板变成一列可编辑的结构：
  - `Enter` 新建同级，`Ctrl+Enter` 新建子节点；
  - `Tab` 降级，`Shift+Tab` 升级；
  - `↑` / `↓` 选择上一 / 下一行；`←` / `→` 折叠 / 展开，或在叶子上跳到父 / 子；
  - `Ctrl+Shift+↑` / `Ctrl+Shift+↓` 在兄弟间重排；`Delete` / `Backspace` 删除子树；`F2` 改名；`Space` 折叠；
  - 顶部筛选框：`Tab` 跳回行表继续键盘操作；`Esc` 先清筛选，再按一次返回画布（`F8` 亦可）；
  - **聚焦子树**：`Alt+Enter` 只看当前节点及其后代；表头出现面包屑「大纲 › 祖先 › 当前」，点「大纲」回全图、点祖先跳那一层，`Esc` 先退出聚焦再退出大纲；聚焦根的 `Enter` 建子节点，子节点不能用 `Shift+Tab` 升出视野；
  - 行首分支色、折叠计数与画布一致；拖动行可改父、改序。
  - **行尾角标**：任务方框（未开始 / 进行中 / 完成，单击循环，`Ctrl+T` 同效）、备注点（单击选中节点并在检查器「内容」页聚焦备注）、卡片强调点（单击打开卡片）、`#n` 标签计数；悬停有操作提示，正在改名的行不响应角标。
- **搜索**（`Ctrl+F`）：分组显示节点 / 卡片 / 标签 / 路径；`Enter` 跳转。
- **命令面板**（`Ctrl+K`）：所有命令都可键盘到达；输入中文子串即可，例如「主题：墨夜」「导出」「设置」。
- **菜单**：顶栏「文件 / 编辑 / 视图 / 插入」，`Alt+F` 直接打开文件菜单；菜单内 `Tab` / `Enter` 操作，`Esc` 关闭。

## 7. 复习与知识内化

- **主动回忆**：命令面板「主动回忆」。卡片按间隔重复到期；选择「忘记 / 模糊 / 记住」会影响下次到期日。
- **知识视图**：命令面板「知识视图」，按标签把卡片与主题画成关系图；点击可跳到卡片。
- **学习统计**：命令面板「学习统计」，看到期数量、连续天数、复习分布。
- **合集导出**：命令面板「导出学习合集」，把导图与卡片导出为 Markdown + 可打印 HTML。

## 8. 导入与导出

**导入**：Markdown、OPML、FreeMind（`.mm`）、XMind（`.xmind`）、缩进大纲文本；导入会开新标签，不覆盖当前文档。

**导出**（`Ctrl+E`）：

| 格式 | 说明 |
| --- | --- |
| PNG | 可选范围与倍率；大图自动分块渲染，上限约 32MP |
| SVG | 矢量，图片以 data URI 内嵌 |
| PDF | **真矢量**：DirectWrite 字形轮廓、连线/边界/概要/关系/折叠点，A4 横向自动分页；文字不可选、不可搜索（是路径），节点图片暂未嵌入 |
| Markdown / 大纲文本 | 纯文本大纲 |
| OPML / FreeMind | 与其他大纲工具交换 |

`Ctrl+P` 直接进入 PDF 导出。

## 9. 自动保存与恢复

- 编辑后约每 3 秒写一份**恢复点**（可在设置改 1–30 秒）；不直接改正本。
- 正常保存后恢复点清除。
- 崩溃后重开：对应文档会提示恢复；也可命令面板「恢复中心」查看所有恢复点，逐条「恢复 / 丢弃」。
- 第二个实例打开同一文件时只读，避免自动保存互相覆盖。
- 外部程序改了磁盘文件时，保存前会提示「重新加载 / 覆盖保存 / 取消」。

## 10. 设置

命令面板 →「设置」：

- **外观**：减少动画（覆盖系统设置）。
- **自动保存**：1–30 秒。
- **导出默认值**：倍率、是否不透明背景。
- **笔记库路径**：留空用默认 `%APPDATA%\织思\notes`；改路径立即重开库（不移动旧文件）。

## 11. 主题与外观

内置四套主题：纸感（默认浅色）、墨夜（深色）、雾青（浅冷）、暖砂（暖浅）。命令面板输入「主题：」+ 名字即可切换；检查器可改当前节点颜色，不影响主题。

**主题编辑器**：命令面板「主题编辑器」打开。调强调色、画布、面板、文字等槽位，画面即时预览；顶部操作条可以「保存预设 / 清空微调 / 恢复打开时 / 完成 / 取消」。已保存的预设点名字即可套用，名字右侧的 ✕ 删除（需确认）。预设写在 `%APPDATA%\织思\themes.json`，下次启动仍在。

## 12. 数据放在哪

| 内容 | 位置 |
| --- | --- |
| 文档 | 你保存的 `.zmind` 路径 |
| 恢复点 | 文档同目录 `.autosave/`，未命名文档在 `%APPDATA%\织思\autosave` |
| 笔记库 | 默认 `%APPDATA%\织思\notes`，可在设置改 |
| 设置 | `%APPDATA%\织思\settings.json` |
| 主题预设 | `%APPDATA%\织思\themes.json` |
| 快捷键 | `%APPDATA%\织思\shortcuts.json` |
| 导出记忆 | `%APPDATA%\织思\export.json` |
| 复习日志 | `%APPDATA%\织思\review.json` |

`.zmind` 是 ZIP：`mimetype`、`manifest.json`、`content.json`、`notes/<id>.md`、`assets/<sha256>`。可以用任意 ZIP 工具查看；手改前先备份。

## 13. 常见问题

**Q：中文输入法候选框位置不对？**
A：在画布内双击进入行内编辑；组合输入（拼音未上屏）时 `Enter`/`Esc` 归输入法，不会误提交节点。若仍有问题，记录输入法版本与 `MW_TRACE` 轨迹后反馈；五款输入法 × 125/150/200% 的人工验收清单见 `docs/archive/19-验收-IME-DPI-多屏.md`。

**Q：导出的 PDF 不能选文字？**
A：当前 PDF 是**真矢量路径**（字形轮廓），打印与缩放都清晰，但文字不是文本对象，不能选中/搜索；需要可复制文字时请导出 Markdown 或大纲文本。

**Q：第二个窗口打不开编辑？**
A：同一文档只允许一个实例编辑，另一实例只读；这是为了避免自动保存互相覆盖。

**Q：换机器后 golden 对不上？**
A：GPU / 驱动 / DPI 变化会导致像素差异；先看差异位置与幅度，再决定是否重拍基线。

**Q：数据会上传吗？**
A：不会。没有账号、云同步、遥测；所有网络能力都不在范围内。

## 14. 键盘速查

`Ctrl+N/O/S/Shift+S` 新建/打开/保存/另存为；`Ctrl+Z/Y` 撤销/重做；`Tab/Enter/Delete` 建子节点/同级/删除；`Ctrl+F` 搜索；`Ctrl+K` 命令面板；`F8` 全屏大纲（`Enter` 同级、`Ctrl+Enter` 子级、`Tab` 缩进、`Shift+Tab` 升级、`Ctrl+Shift+↑↓` 重排、`Alt+Enter` 聚焦子树、`Ctrl+T` 循环任务状态、`F2` 改名、`Esc` 逐级退出）；`Ctrl+Shift+I` 检查器（`F9` 备用）；`F6` 画布与面板交接；`Home` 适应画布，`Ctrl++` / `Ctrl+-` 缩放；`Alt+F` 菜单；`Ctrl+Tab` 切标签。
