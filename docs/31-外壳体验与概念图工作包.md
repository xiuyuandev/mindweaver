## 2. 全局纪律（20 个包都适用）

1. **先写报告再写代码**：每个包在 `shots/x100/<ID>/report.md` 写范围、非目标、验收场景、预计证据。
2. **文档先行**：与 `docs/30` 冲突的设计，先改 `docs/30` 再动代码。
3. **只 Windows、只纯 Rust**：无 WebView / HTML / CSS / JS / Electron / Tauri。
4. **文档变更只走 `Command`**：概念图、起始页、检查器都不许直接改 `Document`。
5. **中文四痛点是验收项**：IME 不打架、CJK 禁则换行、字体不糊、拼音检索。
6. **不新增依赖 / crate / 构建工具**；不引入外部素材。
7. **不改 `.zmind` 格式、不改 `Node`/`NoteCard` 字段**（概念图复用既有字段，见 `docs/30` §5.2）。
8. **不拿 golden 当审美证据**：golden 只证明稳定，好看必须有人工判词。
9. **不跳批、不抢门**：门未过只修当前批。
10. **不提交 git**，除非用户明确要求。
