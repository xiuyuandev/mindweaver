# 02 · 功能需求清单

> 状态：草案 v0.3（2026 本地功能对标）· 更新：2026-10-18 · 上游：01 · 下游：06、07、09

**优先级定义**：P0 = 1.0 必须交付（缺一不可发布）；P1 = 1.0 应交付（里程碑 M2 至少完成 80%）；P2 = 加分项（依次让位于 P0/P1，可滑入 1.x）。

> **2026 基准说明**：本清单原先参照的是 2020 年前后的 XMind 观感。2026-10-18 对照本机 Xmind 26 实拍（`shots/reference/xmind2026-*.png`）重立：**只要求本地思维导图的核心能力**，AI 工作区、云同步、多人协作、社区模板、付费专区和账户体系明确不做。

## 2. 文档管理（模块 A）

| 功能 | 需求描述 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| 新建文档 | `Ctrl+N` 新标签页创建空白文档；首次保存前标记"未命名"，触发另存 | P0 | 标签页状态正确，无标题冲突 |
| 打开 / 另存 | `Ctrl+O` / `Ctrl+Shift+S`，系统文件对话框默认定位"文档"目录 | P0 | CJK 路径与文件名全链路正确（07 §6） |
| 保存 | `Ctrl+S` 原子写入（临时文件+替换）；保存失败必须明确报错且保留原文件 | P0 | 保存过程中断电不损坏原文件 |
| 自动保存 | 文档变更后**每 3 秒**后台写恢复点（`mw-shell/autosave.rs`，不动正本）；保存后状态栏提示"已自动保存 HH:mm" | P0 | 全程不阻塞输入（08 预算）；探针按 3 秒节流轮询 |
| 崩溃恢复 | 崩溃/强关后再次启动检测自动保存文件，弹恢复对话框（预览节点数/修改时间） | P0 | 演练：任务管理器杀进程后数据丢失 ≤ 最近 30 秒 |
| 多标签 | 单窗口多标签；标签显示文档名+修改标记"●"；关闭前确认未保存变更；`Ctrl+Tab` 切换 | P1 | 每标签独立 undo 栈与视口 |
| 最近文件 | 开始页与"文件"菜单列出最近文件（当前实现最多 8 个）；与系统跳转列表（Jump List）联动 | P1 | 文件被移动/删除时置灰并可从列表移除 |
| 开始页 | 无文档打开时显示：新建 + 模板 + 最近文件。**当前实现**为 10 张模板：结构模板 6 张（思维导图/逻辑图/组织架构/鱼骨图/时间轴/概念图）+ 内容模板 4 张（空白/读书笔记/会议记录/产品规划） | P1 | 模板用 `mw_core::Command` 构造，保存仍走另存为 |
| 文件关联 | 关联 `.zmind` 扩展名与图标；双击在已有实例中打开新标签（单实例策略） | P1 | 第二次双击不新起进程 |
| 滚动备份 | 同目录隐藏备份 `.<文件名>.zmind.bak`（上一版本）；设置中可配置保留份数（默认 3） | P2 | 不干扰资源管理器常规视图 |

## 3. 节点编辑（模块 B）——中文输入规则统一适用（见 07 §3）

| 功能 | 需求描述 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| 新建子节点 | `Tab`：为选中节点创建子节点并立即进入编辑态；选中态节点外侧同时提供「＋」圆钮（同义入口） | P0 | 树为空时首个节点自动成为根 |
| 新建同级节点 | `Enter`：在选中节点后创建同级；根节点上则创建一级子节点 | P0 | — |
| 删除 | `Del`：删除节点及整棵子树；有子树时需确认（可撤销，确认文案说明节点数） | P0 | 删除根被禁止并提示 |
| 进入编辑 | 双击 / `F2`（插入模式）；选中态直接输入可打印字符 = 进入编辑并**替换**原文本（可 `Ctrl+Z` 恢复） | P0 | IME 组合输入下同样适用 |
| 软换行 | 编辑态 `Shift+Enter` 在节点内换行；节点超宽默认 300px 自动折行（可配 160–600px） | P0 | 折行遵循 CJK 禁则（07 §4） |
| 提交/取消 | 编辑态失焦或 `Enter` 提交；`Esc` 取消并还原原文；切换选择时自动提交 | P0 | **组合输入（composing）期间任何提交/取消/快捷键均被抑制** |
| 移动节点 | 拖拽：拖动节点至目标，按落点分区（上方=之前/中央=成为子级/下方=之后）；禁止拖入自己的子树 | P0 | 落点指示器三种形态（06 §5） |
| 键盘移动 | `Alt+↑/↓` 同级上下移；`Ctrl+Shift+←` 升级；`Ctrl+Shift+→` 降级（成为上一同级节点的子节点） | P0 | 根节点不可升级 |
| 设为根主题 | 画布节点右键或大纲行菜单把选中主题提为中心主题：新根摘出原父级（原父级概要跨度收口）、旧根剩下的整棵树追加到新根孩子末尾、自由主题提根交出坐标；一条命令、一次撤销（2026-11-01 打磨轮 64 / M31，见 `shots/x100/M31/`） | P2 | 概念图与「已是根」不给入口；旧根固定追加在末尾；无快捷键 |
| 复制/剪切/粘贴 | `Ctrl+C/X/V`：内部为结构化子树；对外剪贴板同时写入缩进文本大纲；从外部粘贴纯文本按行首缩进推断层级建树 | P0 | 跨文档、跨应用（记事本/Word/浏览器）双向可用 |
| 复制节点 | `Ctrl+D` 复制选中子树为新同级节点（自动改名加"副本"后缀仅当重名冲突） | P1 | — |
| 多选 | 画布空白处拖拽框选；`Ctrl+点击` 加选；多选后可批量设置样式、删除、移动 | P0 | 框选以节点包围盒相交为准 |
| 批量操作 | 多选支持：样式统一、移入同一父节点、删除、复制、折叠 | P1 | 撤销时作为单一命令回滚 |
| 插入关系线 | 单选节点后 `Ctrl+L` 或右键「插入关系线」进入插入态：源节点描强调环、指针变十字、虚线随指针；点另一个节点落地一条关系线（同时选中它，颜色/箭头/文案在检查器改），点源节点/空白/`Esc` 取消。仅思维导图（悬停节点四边锚点仍可拖出连线，本行补更易发现的键盘/菜单入口；概念图用拖出连线入口） | P1 | 思维导图同一对节点只留一条，重复时提示且不落地；落地可一步 `Ctrl+Z` 撤销 |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Y`（兼容 `Ctrl+Shift+Z`）；栈上限默认 500 步（可配 100–2000，设置中心「编辑」组，2026-10-31 打磨轮 51 / M28，见 `shots/x100/M28/`）；文本编辑按"提交"粒度入栈 | P0 | 任意命令序列 undo 后文档与快照逐字节一致 |
| 查找 | `Ctrl+F`：全文匹配节点标题 + 备注 + 链接文本与概念图命题短语；默认拼音（原文 / 全拼 / 首字母），搜索条脚注右侧可切「精确文本」（仅原文、大小写不敏感，`Ctrl+Shift+M`；2026-10-31 打磨轮 52 / M29，见 `shots/x100/M29/`）；结果按节点/卡片/标签/路径/命题分组；命中高亮并编号（3/17）；`Enter/Shift+Enter` 上/下一个；支持全拼/首字母/多音字（07 §5） | P0 | 匹配方式可切换"精确文本/拼音"；命题命中显示「概念 · 源 → 目标」并可跳转选中该边；命中折叠子树里的节点时先展开挡路祖先再跳转（一条 Batch，一次撤销全收回）；命中在当前聚焦视图之外时先退出全部聚焦再跳转，并用 toast 说明 |
| 查找替换 | `Ctrl+H`：替换节点标题文本，逐个/全部；替换预览 | P2 | `Ctrl+Enter` 替换当前、`Ctrl+Shift+Enter` 替换全部；当前行第二行显示 `→ 替换后的标题`；只对标题的字面命中给替换入口（拼音/备注/链接只跳转不替换）；逐个替换后当前行前进到下一行（到底绕回，不再命中则按原下标夹取）；一次替换一条 `SetText`、`Ctrl+Z` 只回这一步 |

## 4. 层级结构与导航（模块 C）

| 功能 | 需求描述 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| 折叠/展开 | 非编辑态 `/` 切换选中节点折叠；`Ctrl+/` 全部折叠；`Ctrl+Shift+/` 全部展开；折叠开关为分支末端圆点，可点击 | P0 | 折叠数徽标显示隐藏子节点数；`Ctrl+/` 整图折叠后与 `Alt+Enter` 聚焦视图内，圆点逐颗核对过：只画在**有父级且有下级**的节点上，根与聚焦根不画、叶子不画（`mm-collapse-all-dots` / `mm-focus-dots`，2026-11-01 打磨轮 67 / M9b） |
| 聚焦 | `Alt+Enter` 将选中子树聚焦为全图；画布顶部出现面包屑（根…父级 > 当前）；`Esc` 或点面包屑逐级返回；搜索跳转到视图外的命中时**退出全部聚焦**再定位（toast 说明，不静默失败） | P1 | 聚焦只影响视图，不改数据；退出聚焦只由用户显式动作（Esc / 面包屑 / 点搜索结果）触发 |
| 大纲面板 | 左侧树形列表：与画布同数据双向编辑；支持在面板内拖拽调整层级与顺序；行内直接改文字；点击行定位画布节点 | P1 | 画布与面板选中状态同步 |
| 缩放 | `Ctrl+滚轮`（以光标为锚点）；`Ctrl+=/Ctrl+-`；`Ctrl+0` 回 100%；`Ctrl+1` 适应画布；`Ctrl+2` 适应选中子树；范围 10%–500% | P0 | 缩放帧率满足 08 预算 |
| 平移 | 触控板双指、按住空格/中键拖拽、拖动滚动条（P2） | P0 | 拖拽画布空白处不误触发框选（阈值 4px） |
| 小地图 | 右下角缩略导航图：显示全图与当前视口框；拖动视口框快速定位；可折叠 | P1 | 大文档采样降精度保证 <60fps 绘制 |
| 面包屑导航 | 状态栏上方显示当前选中节点路径（祖先链），点击任一祖先跳转并选中 | P1 | 路径超宽时中部省略 |
| 跳转 | 命令面板 `Ctrl+K`：搜索命令与节点（复用拼音索引），回车跳转选中 | P1 | 命令与节点结果分组显示 |
| 展开层级 | 双击折叠圆点：展开到下一级（逐级深入），区别于全展开 | P2 | 双击只多露一层（折叠态：自己展开 + 有下一层的直接子级折回；展开态：直接子级展开）；一次双击 = 一条撤销；单击与既有折叠基线零变化（`mm-toggle-drill` / `-deep`，2026-11-01 打磨轮 66 / M32） |

## 5. 布局引擎（模块 D）

| 功能 | 需求描述 | 优先级 | 验收要点 |
| --- | --- | --- | --- |
| 放射式（思维导图） | 根居中，一级分支左右自动均衡分配（按子树权重），下级同侧展开；贝塞尔曲线连接线 | P0 | 左右子树节点数偏差 ≤1（权重均衡模式下） |
| 逻辑图（向右） | 全部向右的树形布局；连接线为圆角折线 | P0 | — |
| 组织结构图（向下） | 自上而下布局；直线连接 | P0 | — |
| 布局参数 | 面板可调：同级间距（默认 24px）、层级间距（默认 80px）、节点内边距（12×8px）；文档级记忆 | P1 | 参数随文档保存 |
| 布局切换 | 任意时刻 `Ctrl+T` 打开布局/主题面板切换；切换带 300ms 过渡动画（位置插值） | P1 | 动画可全局关闭（无障碍设置） |
| 增量重排 | 编辑仅重算受影响子树；平移缩放完全不触发重排 | P0 | 5k 节点下满足 08 重排预算 |
| 整理布局 | 命令"整理"：丢弃一切手工偏移恢复纯自动布局 | P1 | 有手工偏移时提示将丢失（可撤销） |
| 手工微调 | 拖拽时按住 `Alt` = 相对自动位置偏移（保留布局整体自动）；纯自由定位模式 v1 不提供 | P2 | 重排时保留相对偏移 |

## 8. 导入导出（模块 G）

**导出矩阵**（画布渲染类走 Rust 导出管线，见 04 §5）：

| 格式 | 内容 | 选项 | 优先级 | 说明 |
| --- | --- | --- | --- | --- |
| PNG | 整图位图 | 缩放 1x/2x/3x、透明背景、边距、是否含背景纹理 | P0 | 后台线程导出+进度+完成提示音可关 |
| SVG | 矢量图 | 同上（无缩放概念） | P0 | 文本转路径可选（保证他机观感一致） |
| PDF | 单页文档 | 页面 A4/A3/A2/自动、横竖向、边距、内容缩放模式（适应页/实际大小） | P1 | 文本保持可选中文本层（可复制） |
| Markdown | 大纲文本 | 有序/无序列表、是否含备注（引用块）、标题映射（根=H1） | P0 | — |
| 纯文本大纲 | 缩进大纲 | 缩进 2/4 空格或 Tab | P0 | 与导入对称 |
| OPML | 大纲交换 | 含备注 | P1 | 可导入到大纲类工具（如 Workflowy） |
| FreeMind | `.mm` | 映射文本/折叠/颜色/链接 | P1 | 为互操作保留 |
| HTML | 自包含页面 | 单文件（内联 SVG + 可折叠大纲） | P2 | 供分享预览，无需本软件即可打开 |

> **当前实现（2026-10-18，M4）**：已落地的七种是 PNG / SVG / PDF / Markdown / 大纲文本 / OPML / FreeMind，入口 `Ctrl+E` / 菜单 / 命令面板（13 §4.23/§4.24）。**HTML 未做**。已实现选项：PNG 的 1×/2×/3×、文档底色/透明；**未实现**：边距、是否含背景纹理开关、SVG 文本转路径、PDF 的页面尺寸/横竖向/边距/内容缩放（当前是单页、按整图尺寸自动定页、嵌入 2× 位图，文字不可选）、后台线程 + 进度 + 完成提示音。文件名的来源后缀会被剥掉（七种源格式），导出固定整棵树。

**导入矩阵**：

| 来源 | 规则 | 优先级 | 已知损失 |
| --- | --- | --- | --- |
| Markdown | 标题层级（H1–H6）+ 列表缩进混合树；代码块/引用降为备注 | P0 | 行内样式丢弃 |
| 缩进纯文本 | 每行按前导缩进（Tab/2/4 空格自动探测）挂层级 | P0 | — |
| FreeMind `.mm` | 节点 `TEXT`/`FOLDED`/`COLOR`/`LINK`；`richcontent` 文本归入备注 | P1 | 云、箭头、自定义图标丢弃 |
| OPML | outline 嵌套 → 树；`text`/`title` 与 `_note` 映射 | P1 | 自定义属性丢失 |
| XMind `.xmind` | Zen 版（content.json）与 XMind 8 版（content.xml）双解析器；标题/备注/折叠/标记/标签/关系线/浮动主题 | P1 | 边界、概要、评论、逐节点样式、链接、图片附件丢弃；解析失败给出明确原因 |

导入通用行为（**规格**）：新建标签页打开结果（不覆盖原文件）；导入报告提示丢失项（可复制）；大文件 >5MB 走后台线程。**当前实现（2026-10-18，M4）**：五种来源都从汉堡菜单 / 命令面板 / 拖放进入，除 `.zmind`（走「打开」）外**一律开新标签页**、旧标签保留；标签先显示来源文件名、`Ctrl+S` 走另存为。**未实现**：丢失项报告、>5MB 后台解析（当前同步解析，会卡 UI）、同来源重复导入去重（13 §4.24）。

## 9. 演示模式（模块 H）

> 优先级说明：个人单机使用下演示属低频的锦上添花，整体仍标 **P2**；但原生栈已在 M2c 收尾时实现（见本节实现状态），后续只做增强而不必再论证是否值得做。

| 功能 | 需求描述 | 优先级 |
| --- | --- | --- |
| 进入/退出 | `F5` 从选中节点（无选中则从根）开始；`Esc` 退出返回原视口 | P2 |
| 步进 | `→/空格` 展示下一个节点（先序遍历）；`←` 回退一步；自动居中并伴随 350ms 缓动 | P2 |
| 演示控制条 | 底部悬浮控制条：进度（7/23）、上一步/下一步/退出；`H` 隐藏 | P2 |
| 背景 | 强制深色纯背景 + 当前路径高亮，聚焦内容 | P2 |

> **原生栈实现状态（2026-10-18，M2c 收尾）**：演示模式已落地（13 §4.32）。`F5` 从选中节点（无选中则根）进入，**`F5` 与 `Esc` 都可退出**并恢复进入前视口；`→/空格` 下一个、`←` 上一个，按**文档先序**（尊重折叠，自由主题排在主树之后——不是视觉 y 序）；切换 350ms 缓动居中+缩放，连按从当前插值相机续接，系统「减少动画」时直接终态。底部控制条含进度 `n/N`、标题、上一步/下一步/退出，**可鼠标点击**、端点禁用；`H` 隐藏/显示。进入后强制深色纯背景（`#121418`）、非路径节点淡化到 16%、装饰淡化到 10%，路径保持全亮；标题栏/标签条/状态栏/大纲/检查器/小地图/右键与画布编辑全部挂起。**与规格的偏差**：不切 OS 全屏（演示是窗口内状态，`F11` 才是铺满显示器）、没有自动播放/演讲者备注/多显示器演示窗口，演示状态不持久化。
