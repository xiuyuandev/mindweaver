## 0. 一句话结论

这三个界面不是“再换一套皮肤”，而是要把它们从**控件堆叠的网页感**，改成
**以文字、留白和节奏为主体的内容表面**：

- 大纲像幕布：**文字即结构**，不是一棵画满线和框的树。
- 卡片页像 Typora：**只有一个写作表面**，Markdown 只在光标所在处露出。
- 笔记库像成熟阅读器：**导航、列表、阅读三层清楚**，行短、标签安静、动作按需出现。

违反这三句话的实现，即使测试全绿，也视为未完成。

## 2. 标杆调研结论

调研只使用公开页面、公开截图与产品文档；**不运行、不拆解、不复制**竞品代码、
字体、图标、主题、文案或专有资产。像素值是我们的设计决定，不是竞品实测值。

### 2.1 幕布：文字即结构

公开资料能确认的事实：

- 产品定位是“极简大纲笔记，一键生成思维导图”；强调极简输入、结构化思考。
- 核心操作只有三个键：`Enter` 新建同级，`Tab` 缩进，`Shift+Tab` 提升。
- 完整键盘表包括 `Ctrl+Enter` 切换完成、`Alt+.` 展开/收缩、`Ctrl+]` 进入当前主题、
  `Ctrl+[` 返回上级、`Ctrl+Shift+↑/↓` 移动主题、`Ctrl+Shift+Backspace` 快速删除。
- 公开截图里正文是主角：小圆点、缩进、较大行距、极少边框；标题是页面标题而不是
  一个高亮卡片；折叠控制在行尾/悬停处，不与正文抢注意力。

**我们学什么**：

1. 行只承载文字；层级靠缩进和留白，不靠竖线、连接线、色块。
2. 选中反馈必须轻：一层极淡的底，不加描边，不画成输入框。
3. `Enter / Tab / Shift+Tab` 是肌肉记忆；层级操作不需要鼠标。
4. 标题、正文、说明文字之间靠字号与灰度分层，不靠卡片。
5. 折叠、拖拽、更多动作在悬停/选中时出现；默认画面里只有内容。

**不照搬**：

- 不复制它的圆点造型、折叠三角位置、蓝色品牌色或页面布局参数。
- 不照搬它的云端协作、分享、模板、社区入口。
- 我们的节点有卡片、任务、标签、图片等数据，不能为了“像幕布”而删掉能力；
  这些能力必须通过**按需出现**表达，而不是常驻角标。

### 2.2 Typora：单一写作表面

Typora 官方支持文档与公开资料能确认的事实：

- 核心是 **seamless live preview**：取消“源码/预览”分栏，在同一个表面即时渲染。
- **Focus Mode**：除当前行/当前块之外的内容淡出，帮助聚焦。
- **Typewriter Mode**：打字时滚动文章，让光标固定在窗口中部；可配置是否鼠标点击也保持居中。
- 有 **Outline / Catalog** 面板，但它是可召出的导航，不是常驻在正文右侧的第二个页面。
- 界面刻意保持极简：没有常驻格式工具栏，没有阅读/编辑模式切换，内容优先。

**我们学什么**：

1. 卡片页只有一个表面：读、写、看都在同一页，不做预览分栏、不做模式切换。
2. Markdown 语法只在光标所在块/片段露出；离开后立即回到排版结果。
3. 目录、字数、保存状态是辅助信息，不能和正文抢视觉层级；目录默认不常驻。
4. 专注模式是“淡出其他块”，不是把其他内容删掉或盖黑；打字机模式只负责光标锚定。
5. 正文排版本身就是设计：字号、行高、段距、标题间距、引用线、代码块底色要成套。

**不照搬**：

- 不复制 Typora 的主题 CSS、字体、图标或菜单结构。
- 不因为“极简”就删掉标签、反链、来源、图片等已有能力；它们应放在属性行/页尾，
  而不是变成正文里的彩色装饰。
- 不引入表格、数学公式、Mermaid 等新块类型；本轮只把已有块做到精致。

### 2.3 成熟笔记库：三层，而不是三堆卡片

参考 Apple Human Interface Guidelines 的 Sidebars / Lists and tables、Bear、
flomo、Craft、Linear 的公开设计说明，可归纳为：

| 原则 | 公开依据 | 对我们的约束 |
| --- | --- | --- |
| 侧栏只做导航，最多两层 | Apple HIG：侧栏一般不超过两层；更深层级用“侧栏 → 内容列表 → 详情”的分栏 | 标签树在侧栏最多显示两级；更深标签通过搜索/筛选表达 |
| 列表行要短、可扫 | Apple HIG：行文本简洁，避免过高行；大量文本用详情页展开 | 列表只放标题、单行摘要、一个标签/日期；正文去预览/编辑页 |
| 选中反馈要明确但不抢 | Apple HIG：导航型列表持续高亮选中行；选项型列表短暂高亮 | 侧栏与列表用不同的、各自唯一的选中语义；都不加边框 |
| 标签是关系，不是装饰 | Bear/flomo 的标签体系强调用标签建立跨目录关系 | 标签默认是文字；颜色只保留 6px 圆点，不做彩色 chip 墙 |
| 键盘优先 | Linear/Craft 的公开交互强调命令面板、方向键与即时动作 | 列表支持 `↑↓/J/K`、`Enter`、`Esc`、搜索聚焦与批量选择 |
| 空状态是引导 | Apple HIG：空列表要解释原因并给出下一步 | 左对齐一句话 + 一个文字动作；不用 56px 大图标 |

**成熟笔记库的样子**：

- 左边知道“我在哪”（全部 / 收件箱 / 未打标签 / 归档 / 标签）。
- 中间知道“有哪些”（短行、可扫、可多选、可搜索）。
- 右边知道“这张是什么”（按阅读排版展开，不重复列表里的标签墙）。
- 任何一栏都不需要“刷新”按钮；本地数据变化即时反映。
- 批量操作只在选择模式出现；默认画面没有复选框。

## 3. 共同设计公理（三界面都适用）

1. **内容即界面**：正文、标题、列表行不是卡片；禁止卡片套卡片、禁止给每行加外框。
2. **一屏一主任务**：大纲负责结构，卡片页负责写作，笔记库负责查找；不要在一个界面
   里塞另一个界面的主任务。
3. **留白先于线条，字号先于颜色**：能用间距分层就不画线；能用字重/灰度分层就不上色。
4. **一个状态一个语义**：悬停、选中、键盘焦点、编辑、拖拽、禁用不能互相冒充。
5. **动作按需出现**：默认只显示内容；拖拽握把、折叠、更多、复选框在悬停/选中/选择模式出现。
6. **键盘优先，鼠标不劣化**：每个关键动作都有键盘路径；鼠标路径不要求先记快捷键。
7. **中文先于英文**：按 CJK 行高、标点、禁则和 IME 组合态设计；英文只是混排的一部分。
8. **动效只解释状态**：不做弹跳、缩放表演、逐字动画；减少动画时全部落位。
9. **空状态是引导**：一句话说明为什么空、下一步做什么；不做插画展览。
10. **证据先于自信**：没有实拍、输入脚本和人工判词，不许写“已经精致”。

### 3.1 明确禁止的“玩具感”

| 禁止 | 原因 | 替代 |
| --- | --- | --- |
| 选中行加 1px 描边或大色块 | 像输入框/按钮，破坏文字主体 | 6–8% 强调色底，无边框；键盘焦点才画环 |
| 每行一个白色卡片 + 圆角 + 阴影 | 卡片套卡片，视觉噪音 | 平面列表 + 1px 分隔线或纯留白 |
| 彩色标签 chip 墙 | 颜色抢正文，像后台管理系统 | 标签纯文字；侧栏最多 6px 色点 |
| 常驻格式工具栏 | 写作时持续干扰 | 斜杠菜单 + 选中时浮出的小工具条 |
| 顶栏大标题 + 正文再写一遍 | 信息重复，层级混乱 | 标题只出现一次，在正文里 |
| 空状态 56px 图标 + 居中两行字 | 像模板页 | 左对齐 16px 标题 + 13px 说明 + 文字动作 |
| 右上角“刷新” | 本地应用不需要 | 数据变化即时刷新；提供手动重载放进更多菜单 |
| 固定 224/330 三栏 | 窄窗挤压、宽窗浪费 | 1200/840 两档断点，2 栏时预览变页面 |
| 绝对坐标排文字 | DPI/字号变化必错位 | 用行高、基线、垂直布局链 |
| 用强调色大面积铺底 | 抢内容，且深色主题易刺眼 | 强调色只做 2–8% 状态底、焦点环、极少量文字 |

## 4. 共享内容设计系统

### 4.1 字阶（内容表面专用）

现有 chrome 字阶（10.5–15 / 24）继续用于标题栏、菜单、按钮。内容表面新增下表；
**不得把 chrome 的 13px 当作正文**，也不得在正文里混用 13.5/14/15 三档“差不多”的字号。

> **2026-11-02 校准**：本表原为设计期的目标值；B2-C/B2-D 落地时按实机观感调过 9 档，
> 那批实现已过 G-B2-3 与 G-B2-4 两道门、36 场卡片页与库页基线按新值定版。
> 因此本表**以 `crates/mw-core/src/design.rs` 的 `content::TYPE_SCALE` 为准**（下值即实测值），
> 原名/原行高不一致的 9 档已按实现更正，并在「变更」列标出差异。
> 同类口径见 `docs/x100/log/decisions-2026-11-02-stage-c.md` §1 G03。

| 大纲页标题 | 28 | 40 (1.43) | 600 | 全屏大纲文档标题 | 行高 38 → 40 |
| 一级标题 H2 | 22 | 33 (1.50) | 600 | 卡片正文一级标题 | 行高 32 → 33 |
| 二级标题 H3 | 18 | 28 (1.56) | 600 | 卡片正文二级标题 | 同原值 |
| 三级标题 H4 | 16 | 26 (1.63) | 600 | 卡片正文三级标题 | 同原值 |

规则：

- 只用 400 / 500 / 600 三档字重；不用 700，不用合成粗体。
  （常量：`WEIGHT_REGULAR = 400` / `WEIGHT_MEDIUM = 500` / `WEIGHT_SEMIBOLD = 600`，
  `WEIGHT_BOLD_ALIAS = WEIGHT_SEMIBOLD`——所谓「粗体」就是 600，不是第二套字重；
  解析层 700 只作 `clamp` 上限。）
- 中文正文不增加字距；英文小标签最多 `0.01em`，不做全大写 + 大字距的“后台感”。
- 数字与拉丁优先 `Segoe UI Variable`，中文优先 `Microsoft YaHei UI`；同一行内基线对齐。
- 标题、正文、元信息三层灰度；不要用纯黑正文，也不要用低于 4.5:1 的灰。

### 4.2 版心与节奏

| 界面 | 版心 | 正文宽 | 页面顶/底留白 | 说明 |
| --- | --- | --- | --- | --- |
| 大纲 | 800 max | 760 | 32 / 64 | 结构扫描，允许比阅读页宽 |
| 卡片页 | 720 max | 640 | 48 / 96 | 约 40 个汉字/行，长文舒适 |
| 笔记库预览 | 680 max | 600 | 40 / 64 | 约 37 个汉字/行 |

- 版心水平居中；窗口不足时左右各留 32（大纲/预览）或 24（卡片页窄窗）。
- 页面级留白允许 `48 / 64 / 96`；控件、列表、面板仍只用
  `2 / 4 / 8 / 12 / 16 / 24 / 32`。这是对 `docs/16` §3.2 的唯一扩展。
- 垂直节奏以 4 为网格；标题上间距大于下间距，段落之间 12，列表项之间 4。
- 行内不设首行缩进；用段距而不是空格表达段落。

### 4.3 颜色与状态

全部通过语义 token，不写死 hex：

| token | 亮色 | 暗色 | 用途 |
| --- | --- | --- | --- |
| `surface.page` | 主题背景色 | 主题背景色 | 大纲、卡片页、列表、预览的底 |
| `surface.panel` | 主题面板色 | 主题面板色 | 笔记库侧栏 |
| `text.primary` | 正文主色 | 正文主色 | 标题、正文 |
| `text.secondary` | 主色 70% | 主色 72% | 摘要、说明、12px 元信息 |
| `text.faint` | 主色 48% | 主色 50% | **仅**占位、禁用与装饰性提示；不承载必须读到的信息 |
| `link` | 强调色（亮色不足 4.5:1 时向正文压暗） | 同左 | 链接、可点文字 |
| `state.hover` | 主色 4% | 主色 6% | 行/按钮悬停 |
| `state.selected` | 强调色 7% | 强调色 12% | 内容选中 |
| `state.navSelected` | 强调色 4% + 2px 条 | 强调色 8% + 2px 条 | 侧栏导航选中 |
| `state.editing` | 强调色 3% | 强调色 8% | 大纲编辑行（可无） |
| `hairline` | 主色 8% | 主色 12% | 分隔线、输入框边 |
| `divider` | 主色 6% | 主色 10% | 列表行分隔、页脚线 |
| `tag.dot` | 6 个低饱和色 | 同左提亮 | 侧栏标签圆点，仅 6px |

- 强调色不参与大面积填充；一屏内强调色面积不超过 5%。
- 标签 chip 禁止彩色底；如需可点的标签，用文字 + hover 下划线 + 6% 中性底。
- 链接只用 `link`（强调色文字 + hover 下划线）；访问过的链接不变色。
- 正文与 `text.secondary` 对页面/面板 ≥ 4.5:1；12px 元信息用 `text.secondary`，
  不得用 `text.faint`；`text.faint` 只做占位/禁用；`link` 对页面 ≥ 4.5:1；
  焦点环与表面 ≥ 3:1。
- `surface.page` 取 `ThemeUi.bg`，`surface.panel` 取 `ThemeUi.panel`；
  不要拿画布自定义色 `canvas_bg` 当内容页底——那是导图画布的背景，
  会被用户的画布配色带走。

### 4.4 边框、圆角、阴影

- 内容表面默认 **0 边框**；只允许：
  - 页头/页脚 1px `divider`；
  - 三栏之间的 1px `hairline`；
  - 列表行之间 1px `divider`（内缩 16px）；
  - 输入框 1px `hairline`；
  - 代码块 1px `hairline`（可选）。
- 圆角只允许：选中行/标签 6；代码块/斜杠菜单/图片 10；弹窗 18。
- 阴影只允许浮层（斜杠菜单、目录浮层、弹窗）使用 `POPOVER` / `WINDOW` 档；
  行、卡片、预览、面板一律无阴影。
- 禁止彩色阴影、禁止 1px 外再套 1px、禁止给正文块加投影。

### 4.5 动效与滚动

- 悬停 120ms；选中 180ms；浮层 160ms；聚焦滚动 180ms；全部 ease-out。
  （2026-11-02 校准：选中原写 140ms，实装走 `motion::BASE = 180ms` 这一全局基数，
  单点改 140 会把节奏碎片化，故**合同改为 180ms**；依据见
  `docs/x100/log/decisions-2026-11-02-stage-c.md` §4 I3。）
- 只做透明度与 2–4px 位移；不做缩放、弹跳、弹簧。
- `reduce_motion` 下全部 0ms；打字过程中不做任何布局动画。
- 滚动条 6px 宽、4px 拇指、圆角 8；默认透明，悬停/滚动时 120ms 淡入，
  空闲 300ms 后淡出；不使用常驻粗滚动条。
- 滚动不做惯性“甩动”；鼠标滚轮一格 = 标准行高三行（按现有输入归一规则）。

### 4.6 焦点与键盘

- 鼠标点击显示“选中”，键盘 Tab/方向键显示“焦点环”；两者不同时伪装成同一种状态。
- 焦点环：1.5px 强调色 80%，外偏移 1px；只在键盘导航时出现。
- 所有输入框、行内编辑、搜索框在 IME 组合态：
  - `Enter` / `Esc` / `Tab` 先归输入法；
  - 组合文字带下划线，候选窗贴光标；
  - 组合期间不切换行、不提交、不触发全局快捷键。
- 弹窗、菜单、斜杠菜单打开时，内容表面不收裸键；关闭后焦点回到原行/原列表项。

## 5. 全屏大纲规范

### 5.1 结构

```
┌──────────────────────────────────────────────────────────────┐
│ ← 大纲 · 织思            13 个主题              ⌕  ≡  ⋯       │ 40px
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  织思                                                         │ 28/38 标题
│                                                              │
│  • 纯 Rust 原生                                               │ 32px 行
│      • winit + windows-rs                                     │
│      • wgpu 四层合成器                                        │
│  • 中文排版                                         ·          │
│      • DirectWrite 度量                                       │
│  • 交互与性能                                       3          │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 13 个主题 · 选中 1                                      ?    │ 24px
└──────────────────────────────────────────────────────────────┘
```

- 不再保留 56px 页头、13/13 数量胶囊、常驻快捷键提示、右侧标签计数与双色圆点。
- 根节点是页面标题，不是“第一行高亮卡片”；标题 28/38/600，可双击/F2 编辑。
- 子节点从标题下 24px 开始；层级靠 24px 缩进，不画竖线/连接线。
- 页头 40px：返回、面包屑（`大纲 › 当前聚焦节点`）、主题计数、搜索、筛选、更多。
  控件 28×28，图标 16，组间 8；无大按钮。
- 页脚 24px：左侧只显示计数与选中摘要；右侧只放一个 `?` 帮助入口，不常驻按键表。
- 内容列 800 max，正文宽 760；水平居中，窄窗左右 32。

### 5.2 行解剖

| 部件 | 规格 | 出现时机 |
| --- | --- | --- |
| 行高 | 32（单行）；换行每行 +24；有说明行 +20 | 始终 |
| 缩进 | 每级 24 | 始终 |
| 拖拽握把 | 6 点，16×20，距列左 8 | 悬停/选中 |
| 项目符号 | 4px 圆点，距文本 12，垂直居中 | 始终（折叠时换成 12px chevron） |
| 文本 | 16/26/400，`text.primary` | 始终 |
| 折叠 chevron | 12px，替换圆点；折叠时显示子项数（如 `3`），11.5 辅助色 | 折叠时始终；展开时悬停 |
| 右侧指示 | 单个 5px 圆点：有卡片/备注才显示；不再显示标签计数与双色点 | 始终 |
| 说明行 | 13/20，`text.secondary`，与文本同 x | 有说明时 |
| 任务框 | 14×14，1.5px 边；完成后文字 `text.faint`，不划删除线 | 任务节点 |
| 更多 | 16px `⋯`，距列右 8 | 悬停/选中 |

- 文本换行时不截断；换行文本与首行文本左对齐，悬挂缩进。
- 行内不显示标签、优先级、图标集合；这些进检查器/右键菜单，避免每行变成仪表盘。
- 大纲选中行的底色从列左 24 到列右 8，圆角 6；**不加边框**。
- 行与行之间无分隔线；靠 32px 行高与留白分层。极多同级节点也不加斑马纹。

### 5.3 状态表

| 状态 | 视觉 | 触发 |
| --- | --- | --- |
| 默认 | 无底、无边框 | 始终 |

| 选中 | `state.selected` 7%，圆角 6，无边框 | 单击/键盘选中 |
| 键盘焦点 | 选中底 + 1.5px 焦点环（仅键盘） | Tab/方向键进入 |
| 编辑 | `state.editing` 3%，无边框；光标可见；握把隐藏 | 双击/F2/直接输入 |
| 多选 | 每个选中行 5% 底；主选行 7% | Shift/Ctrl 选择 |
| 拖拽源 | 行降到 40% 不透明度 | 拖动开始 |
| 拖拽目标 | 2px 强调色插入线；成为子级时整行 6% 底 | 拖动经过 |
| 折叠 | 圆点变 chevron；子项数 11.5 辅助色 | 折叠 |
| 搜索命中 | 命中字符 12% 强调色底，不加粗 | 搜索 |

### 5.4 编辑契约

- 同一时刻只有一个活动行编辑框；编辑框与行使用同一字体、字号、行高、左边距。
- 编辑使用本地草稿；`Enter` 提交并拆分/新建，`Esc` 取消并恢复原文；
  失焦提交；提交后形成**一条**撤销记录。
- `Enter` 在光标处拆分当前行：光标前留在本行，光标后成为新同级行；
  光标在行尾时新建空同级行。空行按 `Enter` 退出编辑并删除空行。
- `Tab` / `Shift+Tab` 改变层级；有子树的节点整体移动；到根层级后 `Shift+Tab` 不再上提。
- 行内换行用 `Shift+Enter`；不在大纲里用 `Shift+Enter` 打开说明/备注（与幕布不同，
  因为我们节点文本本身支持多行；说明行走检查器/卡片）。
- 粘贴多行文本：按行拆成多个同级节点；粘贴单行纯文本替换选中。
- IME 组合态：`Enter` 确认候选，不拆行；`Tab` 不缩进；`Esc` 取消组合。
- 编辑态 `Ctrl+Z` 只撤销文本；退出编辑后的 `Ctrl+Z` 撤销结构命令。

### 5.6 拖拽

- 悬停 120ms 后显示 6 点握把；拖动超过 4px 才进入拖拽，避免误触。
- 拖动时显示行幽灵（90% 不透明度），目标行显示：
  - 上 1/4：插入到目标前；下 1/4：插入到目标后；中间 1/2：成为子级。
- 目标行是自身/后代时显示禁止光标与红色 1px 线，不执行。
- 悬停折叠节点 500ms 自动展开；拖到视口上/下 24px 自动滚动。
- `Esc` 取消拖拽，文档不变；松开后一条撤销记录。
- 多选拖拽保持相对顺序；跨父级移动后展开目标父级。

### 5.7 搜索、筛选、聚焦

- `Ctrl+Shift+F` 打开大纲内筛选条（32px，页头下）；`Ctrl+F` 仍是全局搜索。
- 筛选时保留祖先上下文：命中行正常，祖先行 48% 灰，非命中分支隐藏。
- 命中字符 12% 强调底；计数 `3/17`；`Enter` 下一个，`Shift+Enter` 上一个，`Esc` 清空。
- 筛选条件：文本 / 任务状态 / 是否有卡片 / 标签；标签筛选与文本 AND。
- 折叠状态在筛选期间保持不变；清空筛选后恢复原折叠。
- 聚焦模式：只显示当前节点及后代；页头显示面包屑；`Esc` 逐级返回；
  聚焦根的 `Enter` 建子节点；子节点不能 `Shift+Tab` 升出视野。

### 5.8 长文、窄窗、DPI

- 行虚拟化：只绘制视口 ± 10 行；20k 节点打开、滚动、折叠不卡顿。
- 20k 节点：首屏 ≤ 100ms；滚动 ≥ 55fps；单次折叠/展开 ≤ 16ms。
- 窄窗（800×600）：隐藏页头副标题与筛选按钮文字，只留图标；列宽自动减到
  窗口 − 64；不出现横向滚动。
- 150%/200% DPI：行高、缩进、命中区按逻辑像素缩放；文字不裁切、不重叠。
- 主题：四主题都通过；深色下选中底 12%，焦点环 80%，不出现低对比灰字。

### 5.9 大纲禁止项

- 禁止树形竖线、连接线、每层缩进引导线。
- 禁止根节点大色块/大描边。
- 禁止行内同时出现标签计数、双色点、优先级、备注点、卡片点、折叠 chevron、握把。
- 禁止固定 1040px 列宽与 56px 页头。
- 禁止用 `Ctrl+滚轮` 改变大纲字号；字号由设计系统固定，缩放走全局。
- 禁止把大纲做成“侧栏 232px 树”再套一个全屏壳；全屏大纲是独立内容页。

### 5.10 大纲验收场景

| 场景 | 内容 | 必测 |
| --- | --- | --- |
| `outline-default` | 13 节点、3 层、1 任务、1 说明、1 折叠 | 4 主题 × 1.0/1.5/2.0 DPI |
| `outline-hover-select` | 脚本 hover 一行、选中一行 | 选中无边框、hover 不抢 |
| `outline-edit-ime` | 双击编辑 + 微软拼音组合 | 组合态不拆行、不缩进 |
| `outline-focus` | 聚焦子树 + 面包屑 | 返回路径、Esc 逐级 |
| `outline-search` | 筛选 3 条命中 + 祖先上下文 | 命中高亮、计数、清除恢复 |
| `outline-drag` | 拖拽到目标中部/前/后 | 插入线、禁止落点、Esc |
| `outline-narrow` | 800×600 / 640×460 | 不横向滚动、页头收缩 |
| `outline-20k` | 20k 节点性能脚本 | 首屏/滚动/折叠预算 |
| `outline-wrap` | 长文折行夹具：2/2/3 行 + 说明行叠加 + Shift+Enter 硬换行 | 不截断、每行 +24、悬挂缩进、行尾角标不压字；1.5/2.0 两档 DPI |

人工判词：**遮住页头与页脚，只看内容区，应当像一篇有层级的长文，而不是一棵控件树。**

### 5.11 实现边界（给实现者）

- **单一数据源**：只读现有 `Document` 生成“可见行扁平表”（`node_id / depth / parent / collapsed / visible_index`），不复制节点数据，不新建第二套大纲模型。
- **绘制**：行绘制为纯函数（行度量 + 状态 → 图元）；虚拟化按可见行切片，只画视口 ±10 行。
- **编辑**：单一 overlay `TextEdit`，其字体、行高、左边距、内距必须与行绘制同源；IME 继续喂 `set_ime_cursor_area`；提交只发一条现有节点文本命令。
- **状态**：选择、键盘焦点、文本焦点分开存放；`Esc` 从文本焦点退回行焦点，再退回页面；不允许用 egui 自动焦点代替大纲焦点模型。
- **禁止**：为大纲另建 `Document`/节点树；在绘制层直接改文档；用“弹输入框”代替行内编辑。

## 6. 卡片笔记页规范

### 6.1 结构

```
┌──────────────────────────────────────────────────────────────┐
│ ←  织思 › 纯 Rust 原生          1,240 字  已保存 14:32   ⋯   │ 40px
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  把知识变成自己的                                             │ H1 30/40
│                                                              │
│  更新于 2026-10-25 · 来源：织思 › 纯 Rust 原生                 │ 12/18
│  #知识/方法  #整理术                                          │ 13/20
│                                                              │
│  阅读不是收藏，是重写。                                        │ 16/28
│                                                              │
│  ## 三个动作                                                  │ H2 22/32
│  ...                                                         │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

- 顶栏只做导航与状态：返回、来源面包屑、字数、保存状态、更多。
  **不再在顶栏重复一遍卡片标题**，不再放“标签管理”“关闭 X”等大按钮。
- 标题是正文的第一行 H1，可双击/F2 编辑；下方依次是元信息、标签、正文。
- 元信息：更新日期、来源（可点回导图节点）、字数；12/18 辅助色。
- 标签：纯文字 `#知识/方法`，13/20；多个标签之间 8px；hover 出现下划线/删除 ×；
  不做彩色 chip。
- 正文宽 640，版心 720，顶部 48、底部 96；无卡片边框、无背景块、无阴影。
- 目录默认不常驻；顶栏“目录”图标或 `Ctrl+Shift+O` 打开 240px 浮层。
- 页脚无固定工具栏；保存状态在顶栏，写作区不出现常驻按钮。

### 6.2 正文排版

| 块 | 规格 |
| --- | --- |
| H1 | 30/40/600；标题下方 8 到元信息，元信息下 12 到标签，标签下 40 到正文 |
| H2 | 22/32/600；上 40、下 12 |
| H3 | 18/28/600；上 28、下 8 |
| H4 | 16/26/600；上 24、下 8 |
| 段落 | 16/28/400；段间 12；行内不缩进 |
| 无序列表 | 圆点 4px；缩进 24；项间 4；列表上下 8 |
| 有序列表 | 数字右对齐到 20px 列；缩进 24；项间 4 |
| 任务 | 16px 方框；完成文字 `text.faint`，不划删除线；项间 4 |
| 引用 | 左侧 2px 强调色 30%；内距 16；文字 16/28 `text.secondary` |
| 行内码 | 0.92em；中性底 6%；圆角 3；水平内距 3 |
| 代码块 | 13.5/22 等宽；底 `surface.panel` 60%；圆角 10；内距 16；语言标签 11 辅助色 |
| 分隔线 | 1px `divider`；上下 32 |
| 图片 | 最大宽 100%；圆角 10；无边框/阴影；下方 8px 可编辑说明（可选） |
| 链接 | 强调色；hover 下划线；不在正文里显示裸 URL |
| 反链 | 页尾 32px 留白 + 1px 分隔线；“反向链接”13/20/600；条目 13/20 |

- 正文颜色 `text.primary`；不要用纯黑。
- 正文中不出现“卡片外框”“阴影”“彩色标签墙”。
- 正文中的强调只允许：粗体 600、斜体、行内码、链接；不新增高亮底色。

### 6.3 单一表面与语法揭示

这是卡片页的核心，不允许退化成“上编辑/下预览”或“阅读/编辑模式”。

- 默认显示排版结果，不显示 Markdown 标记。
- 光标进入某个块时，只在该块露出块级标记：
  - 标题行首 `#` / `##` / `###`；
  - 引用行首 `>`；
  - 列表行首 `-` / `1.`；
  - 任务行首 `- [ ]` / `- [x]`；
  - 代码块围栏 ` ``` `。
- 光标进入某个行内片段时，**优先**只在该片段露出标记：
  - `**粗体**`、`*斜体*`、`` `代码` ``、`[文字](链接)`；
  - 离开片段立即隐藏。
  - **工程底线**：逐片段隐藏若做不到，允许“活动块内行内标记整体露出”，但不得为了隐藏标记
    把整页拆成多个控件，导致光标、选区或滚动跳变；逐片段隐藏作为加分项，不作为门禁。
- 光标不在块内时，块标记隐藏；当前块可用 2% 中性底提示，禁止整块描边。
- 输入 `#` + 空格、`>` + 空格、`-` + 空格、`1.` + 空格时即时转换块类型；
  `Ctrl+Z` 一次撤销转换。
- 粘贴 Markdown 文本时保留结构；粘贴纯文本时按当前块类型处理。
- 不在渲染层和编辑层之间切换控件；光标位置、选区、滚动在切换中不跳。

### 6.4 专注模式与打字机模式

- **专注模式** `Alt+Z`：
  - 当前块保持 100%，其他块淡到 35%（不是 0，不是模糊，不加遮罩）；
  - 背景、标题、元信息不变；
  - 120ms 渐变；减少动画时立即落位；
  - 再按一次或 `Esc` 退出（`Esc` 先退专注，再退页面）。
- **打字机模式** `Alt+Shift+Z`：
  - 光标保持在视口 42% 高度；
  - 只在键盘输入时滚动；鼠标点击默认不强制居中（可在设置改为始终居中）；
  - 滚动 180ms ease-out；不改变选区；
  - 减少动画时瞬时滚动。
- 两种模式可叠加；状态在当前会话内记住，不写入文档。

### 6.5 斜杠菜单

- 触发：空块行首输入 `/`，或 `Ctrl+/`；URL/正文中间的 `/` 不触发。
- 尺寸：宽 280 max，最多 8 行可见，行高 30，圆角 10，`POPOVER` 阴影。
- 行：16px 线性图标 + 13px 名称 + 右对齐快捷键/说明；无分组大标题，最多两条细分隔线。
- 命令：标题 1/2/3、无序列表、有序列表、任务、引用、代码块、分割线、图片。
  本轮不新增表格、数学公式、Mermaid。
- 键盘：`↑↓` 选择，`Enter` 插入，`Esc` 关闭，输入即过滤；IME 组合态不拦截。
- 插入后光标落在新块内容起点；菜单关闭不抢焦点。

### 6.6 标签、来源、反链

- 标签在标题下方独立一行，纯文字；`#` 开头，层级用 `/`；输入时自动补全。
- `Enter` 添加标签，`Backspace` 在空输入时删除最后一个，点击标签打开笔记库筛选。
- 来源：`来源：织思 › 纯 Rust 原生`，点击回到画布并选中该节点；无来源显示“独立卡片”。
- 反链：正文 `[[标题]]` 或节点引用产生的反向链接，列在页尾；断链用 `text.faint` + 删除线。
- 不在标题上方放标签 chip 行；不在正文里自动插入标签墙。

### 6.7 保存、冲突、只读

- 编辑时本地草稿即时更新；库内卡片 `NoteStore::upsert` 去抖 800ms，文档内卡片在
  flush 时合并为一批命令；顶栏状态：`保存中…` → `已保存`，12/18 辅助色 + 6px 点；
  不使用彩色胶囊。
- 关闭/返回时同步 flush；失败不关闭，显示行内错误条与“重试/另存副本”。
- 外部修改：行内 32px 提示条“文件已在外部修改：重新加载 / 覆盖 / 取消”；
  不直接用模态遮住正文，除非需要三选确认。
- 只读：顶栏显示“只读”，正文不可编辑；`Ctrl+S` 提示另存为。
- 恢复：沿用自动恢复点；卡片正文不因恢复点产生重复段落。

### 6.8 键盘

| 键 | 行为 |
| --- | --- |
| `Ctrl+S` | 立即保存 |
| `Ctrl+Z/Y` | 文本撤销/重做（不跨块结构） |
| `Alt+Z` | 专注模式 |
| `Alt+Shift+Z` | 打字机模式 |
| `Ctrl+Shift+O` | 目录浮层 |
| `Ctrl+/` | 斜杠菜单 |
| `Esc` | 关菜单/目录 → 退专注 → 返回 |
| `Tab` | 在标签/正文/反链之间移动焦点；正文内 Tab 插入缩进（列表） |
| `Ctrl+Enter` | 不绑定提交；正文中不打断写作 |

- 所有键在 IME 组合态先归输入法；`Esc` 第一次取消组合，第二次才关菜单/退出。
- 正文内 `Enter` 新建段落；标题行 `Enter` 转到正文；空列表项 `Enter` 退出列表。

### 6.9 长文与性能

- 20k 中文字符：打开 ≤ 150ms；连续输入 200 字无 >50ms 卡顿；
  滚动 ≥ 55fps；IME 组合更新 ≤ 16ms。
- 块级缓存：只重排当前块与相邻块；不因一个字符重排全文。
- 图片懒加载；大图解码不阻塞输入；代码块高亮按块缓存。
- 恢复点/保存不阻塞 UI 线程。

### 6.10 卡片页禁止项

- 禁止顶栏标题与正文 H1 重复。
- 禁止常驻右侧目录、常驻格式工具栏、阅读/编辑模式切换。
- 禁止“上下分栏预览”。
- 禁止把标签做成彩色 chip 墙。
- 禁止正文外层再套白色卡片/圆角/阴影。
- 禁止在正文里显示未激活的 Markdown 标记（除当前块/片段）。
- 禁止用 13px 当正文；正文必须 16/28。
- 禁止把“打开编辑”做成大主按钮；整页就是编辑面。

### 6.11 卡片页验收场景

| 场景 | 内容 | 必测 |
| --- | --- | --- |
| `card-empty` | 新卡片、占位标题、空正文 | 空状态不空洞、可直接写 |
| `card-default` | 300 字中文 + H2/H3 + 引用 + 列表 + 任务 | 排版节奏、对比度 |
| `card-code` | 代码块 + 行内码 + 链接 + 图片 | 代码块/图片不玩具 |
| `card-tags` | 3 个层级标签 + 来源 + 反链 | 标签不抢戏、反链安静 |
| `card-focus` | 专注模式当前块/其他块 | 35% 淡出、无遮罩 |
| `card-typewriter` | 打字机模式光标锚定 | 42% 位置、不跳 |
| `card-slash` | 斜杠菜单 + 键盘过滤 | 280px、8 行、IME |
| `card-ime` | 微软拼音组合 | 组合不提交、不拆块 |
| `card-selection` | Shift+点击、Shift+方向键、Ctrl+A、跨块复制 | 选区不跳、复制内容正确、撤销可回 |
| `card-conflict` | 外部修改/只读提示 | 行内提示、不遮正文 |
| `card-narrow` | 800×600 / 640×460 | 版心收缩、目录浮层 |

人工判词：**把顶栏遮住，正文应当像一篇排好版的长文；把光标放进任意一行，它才变成可编辑的 Markdown。**

### 6.12 实现边界（给实现者）

这是 B2 最容易做成“假 Typora”的地方，以下边界不可退让：

- **单一真源**：`NoteCard.body` 仍是 Markdown 字符串；块模型是从它派生的视图，不落盘、不改 `.zmind`、不新增 frontmatter。
- **块布局**：把现有 Markdown 渲染提取为“块列表”（`block_id / source_range / kind / rect`）；非活动块正常绘制，活动块用 overlay `TextEdit` 覆盖在同位置。
- **不得整页切换控件**：禁止“渲染模式 ↔ 编辑模式”整页替换；只允许活动块的局部替换，且切换前后光标、选区、滚动不跳。
- **语法揭示底线**：活动块必须露出块级标记；行内标记允许在活动块整体露出（逐片段隐藏为加分项）。任何实现都不得把整页拆成多块 `TextEdit` 造成焦点/选区跳变。
- **跨块编辑底线**：必须支持 `Shift+点击`、`Shift+方向键`、`Ctrl+A`、`Ctrl+C/X` 的跨块选择与复制；选区用源偏移区间表达。只支持单块选择视为未完成。
- **撤销**：块内输入由 `TextEdit` 本地撤销；提交/flush 时，文档内卡片形成一条（或一次批量）`SetCardTitle/SetCardBody/SetCardTags` 命令记录；库内独立卡片走 `NoteStore::upsert`，至少保证页内文本撤销。禁止每次按键 push 命令，也禁止提交后无法撤销文档内卡片。
- **性能**：块级缓存，只重排当前块与相邻块；图片懒加载；不因一个字符重排全文。
- **禁止**：把块模型写回磁盘；在渲染层直接改 `NoteCard`；用两个并排/上下控件冒充单一表面。

## 7. 笔记库规范

### 7.1 信息架构

侧栏只保留：

| 项 | 定义 | 计数 |
| --- | --- | --- |
| 全部卡片 | 所有未归档卡片 | 全部 |
| 收件箱 | 未归档、无标签、且未挂到任何导图节点 | 未整理 |
| 未打标签 | 未归档、标签为空（含已挂导图但未打标签） | 全部未打标签 |
| 归档 | 已归档卡片 | 归档数 |
| 标签树 | 最多两级；第三级及更深通过搜索/筛选表达 | 每个标签的未归档数 |

- “收件箱”不再等于“全部卡片”；当前截图里 4 = 4 是错误语义，必须修正。
- 不设“最近编辑”侧栏项；用排序“最近更新”表达。
- 不设“刷新”；本地 store 变化即时更新。手动重载放“更多”菜单。
- 标签排序：置顶/常用可选（P1）；本轮按名称/计数稳定排序，不随机。
- 标签颜色只做 6px 圆点；同一标签在侧栏/列表/预览中颜色一致。

### 7.2 自适应布局

| 窗口宽 | 布局 | 说明 |
| --- | --- | --- |
| ≥ 1200 | 三栏：侧栏 232 + 列表 360 + 预览余量（≥480） | 默认桌面 |
| 840–1199 | 两栏：侧栏 232 + 列表；选中卡片后预览以整页阅读面打开 | 1080×720 属此档 |
| < 840 | 单栏列表；侧栏为抽屉；预览/编辑为整页 | 800×600 / 640×460 |

- 侧栏可拖宽 200–280；列表可拖宽 320–440；宽度写入会话状态。
- 两栏模式的预览页使用卡片页的阅读排版，顶部返回列表；不挤成 300px 窄栏。
- 三栏之间只留 1px `hairline`；无阴影、无圆角面板、无卡片边框。
- 页头 48px：返回、标题 18/28/600（复用 H3）、计数 12 辅助色；右侧“更多”（管理标签/导入/导出）。
  不再放“刷新”“关闭 X”和大文字按钮。

### 7.3 侧栏

- 背景 `surface.panel`；宽度 232；内边距 8；行高 30（标签行 28）。
- 分组标题 11.5/16/500 `text.faint`；中文不用全大写，不加字距。
- 导航行：图标 16 + 文本 13 + 计数 11.5 右对齐；圆角 6。
- 选中：`state.navSelected`（4% 底 + 2px 强调条），无边框；hover 4% 中性底。
- 标签行：6px 圆点 + 文本 13 + 计数 11；展开 chevron 12 在悬停/展开时出现。
- 标签树最多两级；更深层级不出现在侧栏，避免无限缩进。
- 侧栏底部不放关键动作；管理标签放页头“更多”。

### 7.4 列表

- 列表宽 360（320–440）；背景 `surface.page`；顶部搜索 32px，下方排序行 28px。
- 行高 60；内边距 12×16；行间 1px `divider`，左右内缩 16；无卡片底、无圆角、无阴影。
- 行内容：
  - 标题 14.5/22/500，最多 1 行省略；
  - 摘要 12.5/19/400，最多 1 行省略；
  - 元信息 11.5/16：最多 1 个标签（纯文字，如 `#知识`）+ 日期；超出标签用 `+n`；
  - 默认不显示复选框；选择模式才出现 16px 复选框。
- hover：4% 中性底；选中：7% 强调底，无边框；键盘焦点：1.5px 环。
- 多选：`Ctrl+click` 进入选择模式；选择模式下单击切换；`Shift+↑↓` 范围选择；
  `Ctrl+A` 全选当前筛选结果；底部出现 44px 批量条（归档/导出/移出/加标签/取消）。
- 批量条在列表栏内，不横跨全窗；危险动作二次确认；一次批量只形成一次确认与一条结果提示。
- 列表滚动虚拟化；10k 卡片首屏 ≤ 100ms，滚动 ≥ 55fps。

### 7.5 预览

- 背景 `surface.page`；左侧 1px `hairline`；顶部 40px 内边距，左右 40。
- 标题 30/40/600；元信息 12/18；标签纯文字 12.5/19；正文 16/28；版心 600。
- 标题与正文直接复用 §4.1 的 H1 与阅读正文，**不为预览新开一套字阶**。
- 正文使用卡片页的阅读排版，但不可编辑；双击标题/正文或 `Enter` 打开卡片页。
- 右上角 hover 出现 28px 铅笔图标；不设“打开编辑”大按钮。
- 预览滚动位置独立；切换卡片重置到顶部；返回列表保留列表滚动。
- 空预览：左对齐 13/20 `text.faint` “选择一张卡片查看内容”；无大图标。
- 预览内不重复列表的标签墙；最多一行标签 + 来源 + 日期。

### 7.6 搜索、筛选、排序

- 搜索框 32px，内距 10，图标 14，placeholder “搜索标题、正文、标签…”；
  `Ctrl+F` 聚焦；输入去抖 120ms；`Esc` 先清空再退出。
- 搜索范围：标题、正文、标签、来源节点标题；命中高亮 12% 强调底。
- 标签筛选：点击侧栏标签为单选；`Ctrl+click` 多选；多标签为 **AND**；
  已选筛选显示为一行纯文字 chip（中性底 6%，无彩色），可逐个移除。
- 排序：最近更新（默认）、创建时间、标题；搜索时默认按相关度，再按更新时间。
- 计数：列表顶部右侧 11.5 辅助色 `N 张`；不做大胶囊。
- 无结果：左对齐“没有匹配的卡片” + “清除筛选”文字动作；不显示空插画。

### 7.7 空、加载、错误

- 全空：列表左对齐 16/26/600 “还没有卡片”，13/20 说明“在导图节点上按
  Ctrl+Shift+N 新建，或从文件导入”，一个文字动作“导入…”。无 56px 图标。
- 无标签：侧栏标签区显示 12/18 `text.faint` “给卡片打标签后会出现在这里”，不占大块。
- 加载：3 行 60px 骨架，4% 中性底；不用 spinner。
- 错误：列表顶部 32px 行内条，`text.secondary` + “重试”文字动作；不弹模态。
- 只读/库损坏：页头下方行内条，说明原因与恢复入口。

### 7.10 笔记库验收场景

| 场景 | 内容 | 必测 |
| --- | --- | --- |
| `library-default` | 20 张卡、3 层标签、1 来源 | 三栏、行密度、预览 |

### 7.11 实现边界（给实现者）

- **单一查询入口**：侧栏计数、列表行、预览都从同一个 `CardQuery`（scope / tags AND / sort / search）取数；视图层不得各自过滤，避免“收件箱 4 = 全部 4”这类语义分裂。
- **选择按 id**：列表选择、批量操作、预览跟随都用卡片 id，不用行下标；排序/筛选变化后选择不漂移。
- **单一预览组件**：三栏预览、两栏整页预览共用同一阅读组件；禁止为两栏另写一个编辑器。
- **批量失败整批报告**：批量加/删标签、归档/移出必须返回逐 id 结果；UI 汇总成功/失败数量，不允许静默部分成功。
- **刷新**：不设刷新按钮；`NoteStore` 变化后重建查询结果，列表滚动与选择保持。
- **性能**：10k 卡片只渲染可见行；分页/索引 API 可在 `mw-core` 内加，但不改 `.zmind`、不引数据库。

## 8. 数据、命令与文件格式影响

- **大纲**：不新增或修改 `Document` / `Node` / `Command` 的字段与语义；所有结构操作仍通过现有命令改文档并进撤销栈。
- **卡片页**：不改 `NoteCard` 字段与 `.zmind`；正文仍存 `notes/<id>.md`。保存分两路：
  - 文档内卡片：标题/正文/标签分别走 `SetCardTitle` / `SetCardBody` / `SetCardTags`，
    flush 时合并成一批命令（一次撤销）。
  - 库内独立卡片：走 `NoteStore::upsert`（去抖 800ms）；不伪造 Document 命令。
  - 不新增 frontmatter，不允许直接写文件绕过上述两条路径。
- **笔记库**：
  - 现有 `NoteCard` 已有 `tags`、`source_doc`、`source_node`、`created`、`updated`，
    足以定义全部 / 收件箱 / 未打标签 / 归档；不新增持久化字段。
  - 允许为性能新增**内部查询 API**（如 `CardQuery` / 分页 `list_meta` / 批量标签更新），
    但不得改变 `.zmind` 容器格式，不做迁移。
  - 批量加/删标签若需要新 store API，按 `docs/27` 的命令审计补测试；失败必须整批报告，
    不允许静默部分成功。
- **明确不做（本轮）**：置顶、手动排序、卡片颜色、封面、文件夹、表格/公式/Mermaid、
  云同步、多人协作、AI。它们不是这次“克制与精致”的必要条件。
- **兼容**：旧 `.zmind`、旧笔记库路径、旧主题 id 继续可用；不做格式版本升级。

## 9. 证据与验收总则

### 9.1 四类证据

每个 CER 工作包必须有：

1. **行为证据**：纯函数单测 / 命令往返 / `MW_GOLDEN_INPUT` 脚本 + `MW_TRACE`；
   IME、键盘、拖拽、搜索、批量操作不能只靠“代码看起来正确”。
2. **视觉证据**：至少一张参考图和本项目实拍；记录逻辑尺寸、DPI、主题、缩放；
   竞品参考只用于比较层级/密度/几何，不进入 golden，不复制资产。
3. **回归证据**：受影响 golden 双跑 `--tol 0`；旧文件读取/保存/往返；
   撤销/重做至少一次；选择/焦点变化必须有键盘路径。
4. **工程证据**：fmt、相关测试、clippy 新增 0、release 构建；性能场景记录条件与数字。

### 9.2 golden 与实拍

- 静态 golden 只证明稳定，**不证明好看**；每个界面必须有用户/人工判词。
- 内容表面截图必须包含：默认、悬停/选中、编辑、空状态、窄窗、深色；
  卡片页另加长文、代码、专注、IME、跨块选区；笔记库另加选择模式、无结果、两栏。
- 所有涉及输入态的截图必须用脚本停在稳定帧；禁止截到 hover 残留或动画中间态。
- 现有 `outline` / `outline-focus` / `outline-compact` / `outline-edit` / `library` / `card-slash`
  基线在 B2 重做后会整体重拍；重拍前先记录旧哈希与漂移原因。

### 9.3 人工验收判词

每次功能门至少回答：

1. **10 秒判词**：第一眼是否知道这是“大纲 / 写作页 / 笔记库”，而不是后台表格？
2. **无框测试**：正文、列表、大纲行是否没有外框？允许的矩形只剩代码块、图片、输入框、菜单、窗口。
3. **颜色测试**：除强调色和 6px 标签点外，是否没有第二种装饰色？标签是否没有彩色 chip？
4. **宽度测试**：卡片正文 640、预览 600、大纲 760；是否出现超过 50 字的行长？
5. **层级测试**：遮住 chrome，是否仍能靠字号/留白/缩进读懂结构？
6. **5 分钟任务**：大纲建 10 个节点并缩进/折叠；卡片写 300 字含标题/引用/任务；
   笔记库找到并批量归档 3 张卡。全程不查文档。
7. **没有“像模板”**：空状态、按钮、标签、页头是否像产品的一部分，而不是演示页。
8. **中文**：微软拼音组合、CJK 禁则、中英混排、200% DPI 下是否仍成立。

任一项失败，本轮只能记 `已实现` 或 `阻塞`，不能记 `已验证`。
