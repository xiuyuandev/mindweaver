## 5. 文档生命周期（写作前先看这一节）

1. **新建**：先在本文件 §3 加一行，再写正文；没进索引的文档视为不存在。
2. **取代**：旧文移入 `archive/` → 在 `archive/README.md` 补一行（归档时间 + 替代入口）→
   全仓搜一遍旧文件名，把所有引用改到新入口。
3. **删除**：只有「从未被引用 + 内容已被完全覆盖」才删除；否则一律归档。
4. **数字**：只写进 `STATUS.md`；其它文档写「见 `STATUS.md` §1」，**不许复制会过期的数字**。
5. **状态词**：只用 `未开始 / 进行中 / 已实现 / 已验证 / 阻塞 / 延后`；
   `已验证` 只在人工门通过后使用。
6. **逐轮记录**：只追加到 `x100/log/`，不要写进 `HANDOFF.md` / `PLAN.md` / `README.md`。
7. **快照要带日期**：任何「实测/当前」数字前面写清日期，过期即改或删。
8. **一处一真相**：同一结论不要在两篇文档里各写一遍；写两遍就一定会有一次忘记改。
9. **机器体检**：改完文档跑 `powershell -File scripts/doc-hygiene.ps1`（断链 / 已知过期断言 /
   索引与归档台账覆盖）。它挡不住语义错误，但能挡住「引用指错地方」和「复制了过期数字」这两类最常见的腐烂。
