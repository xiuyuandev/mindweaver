### 3.1 金样确定性修复

`outline-edit-ime` 首次双跑出现「同一脚本、同一二进制、截图停在光标闪烁两态」的
126 px 漂移；根因是 egui 文本光标按真实时间闪烁，`golden::prepare` 只归零了
`animation_time`。修复：金样模式下 `visuals.text_cursor.blink = false`，
新增单测 `prepare_freezes_time_dependent_visuals`。四个编辑场景各连跑三次哈希相同
且等于既有基线；此后 8 场景与 45 组门全绿。

另：隔离 profile 必须每遍清空——复用上一遍的 `APPDATA`（含空
`notes/index.json`）曾让同一场景整列偏移 1–3 px。

### 3.2 第二处金样确定性修复（2026-10-26）

排查 `outline-edit-ime` 双跑时发现：带 `MW_GOLDEN_INPUT` 的脚本场景从不清桌面指针，
鼠标恰好压在窗口里某一行上时，同一份构建能截出**带 hover / 不带 hover** 两种图
（实测 3.06% 与 5.06% 两种漂移，包围盒正好是一整行的 hover 底）。修复：离屏且脚本
**不含指针动作**时，每帧先发 `PointerMoved(-10000) + PointerGone`；指针归脚本管的
场景（`GoldenInput::owns_pointer()`）不清，否则 `hover` 的 120/160ms 计时攒不满、
握把不出现。修复后该场景与基线逐字节一致，23 个指针/大纲场景复跑 0 差异。
