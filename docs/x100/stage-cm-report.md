## 6. 为什么人工判词过不去

`docs/31` §1.3 给 G-CM-2 的判词是「概念能关联笔记、卡片能跳回概念、**大纲可编辑结构**、导出往返无损」。
前两条和第四条都做到了，第三条只做到「新建概念 / 改名 / 删除概念」——
**改结构（建/删连线）没有**。`docs/30` §5.9 要求「新建连线即进入短语编辑态，未填不给落线」，
而大纲行里没有短语输入位，所以这一条不是「顺手补一下」，需要一个设计：

- 大纲行尾给一个短语输入位（与行首 `解决 →` 前缀同一套行内编辑契约）；
- `Tab` 在概念图 = 「在这行下面新建一个概念，并立刻要求写短语」；
- 短语留空 → 撤销这条线（与画布拖出连线的 `blank_new` 同一条规则）。

这个设计要先落到 `docs/30` §5.6/§5.9，再开工写代码——**先改文档再写代码**是硬约束。
