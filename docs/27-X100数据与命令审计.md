# 27 · X100 数据模型、命令与格式审计

> 审计基线：2026-10-22 当前工作区 · `.zmind` 格式版本 **1**
>
> 结论先行：现有核心模型足以承载第一阶段的画布、编辑和导入导出升级；X44、X49、X58、
> X59、X72 需要新增可选字段或新对象。所有扩展必须向后兼容读取版本 1，并通过命令层撤销。

## 2. 需要扩展的数据

### 2.1 样式

`StyleOverride` 目前缺少以下一等字段：

- 字体家族和 Unicode/CJK 回退策略。
- 明确字重（当前主要是 `bold: bool`）。
- 下划线、删除线和文本对齐。
- 线形（curve/elbow/straight 已有文档级，缺少节点/分支覆盖）。
- 箭头与锥形线的逐分支覆盖。
- 形状预设仍用字符串自由值，后续需要稳定枚举和旧值回退。

建议：全部追加 `Option<T>`，缺失时继承；不得把旧 `shape` 字符串直接改成不可反序列化的枚举。

### 2.2 节点内容

当前 `Node` 已有 `note/link/icon/labels/image/card_id/task`，但缺少：

- 评论线程和作者/本地时间字段。
- 音频附件引用及时长。
- 通用附件列表（当前 `image` 只能表达一张图片/占位）。
- Xmind 的标注框（callout）语义。
- 分组/取消分组所需的展示分组，而不能只靠修改父子结构。

建议：新增对象使用稳定 id；附件继续引用 `assets/` 哈希，不把大字节塞进 `content.json`。

### 2.3 多画布

当前 `.zmind` 的 `content.json` 只写一个 `rootId` 和一张 `nodes` 表。X72 需要：

- `Workbook { sheets: Vec<Sheet> }` 或等价的兼容投影。
- 每个 Sheet 拥有自己的 `Document`、主题、布局、视口和活动选择。
- 文件级元数据与 Sheet 级元数据分离。
- 版本 1 文件加载时包装成单个默认 Sheet，保存时保持可读；是否降回版本 1 由字段能力决定。
- Undo/Redo 必须明确是当前 Sheet 历史还是工作簿级结构历史。

该项是破坏面最大的结构调整，不得在 X01–X10 中提前实现。

| 轮次 | 新命令/扩展 | 必须测试 |

## 4. 格式兼容策略

### 版本 1 读取

- 保持现有 `FileDoc` 反序列化，所有新字段 `serde(default)`。
- 旧主题 id 继续回退到当前安全主题。
- 旧节点没有新内容时，不写空对象，保持文件可读。

### 版本 2 写入

- 只有在实际使用多 Sheet 或新字段时才写版本 2；即使写 2，也要尽量保留旧字段的可解释性。
- 加载版本 1 时自动建立单 Sheet 投影，不立即改写原文件。
- 首次保存升级之前，先生成 `.bak`；失败时原文件不变。
- 提供“另存为兼容副本”时，明确哪些字段会被降级或丢弃。

### 安全边界

- 保持 ZIP 条目数、单条体积和解压总量守卫。
- `assets/` 路径、卡片 id 和文件名继续做路径穿越检查。
- Sheet id 和评论 id 使用稳定 ID；导入外部文件时要解决冲突，不覆盖现有对象。

## 5. 导入导出字段矩阵

| 能力 | `.zmind` | Xmind | Markdown/OPML/FreeMind | 当前风险 |
| --- | --- | --- | --- | --- |
| 多 Sheet | 待实现 | 需扩展导入 | 通常不支持 | 需明确丢失报告 |
| 样式覆盖 | 完整保留 | 部分导入 | 多数丢失 | 扩展字段往返 |
| 关系/概要/边界 | 已存 | 部分导入 | 多数不支持 | 导出目标需声明 |
| 图片/附件 | 资源包已有基础 | 部分导入 | Markdown 可外链/嵌入 | 安全与体积 |
| 评论/音频 | 待实现 | 部分导入 | 不支持 | 需可选 Web 格式？不新增 Web 运行路径 |
| 卡片笔记 | 专有扩展 | 无直接对应 | Markdown 可读 | 保留为织思特色 |

## 6. 第一阶段不改的代码

X01–X10 只做参考、审计、测试基建和语料，不进行以下改动：

- 不改变 `Document` 数据结构。
- 不升级 `.zmind` 格式版本。
- 不改画布行为、主题令牌或现有菜单。
- 不碰当前会话不确定来源的 `theme.rs` 与渲染实例改动。
- 不清除 O01–O04 未提交代码。

因此第一阶段的通过标准是“证据和路线可信”，不是“界面已经变好看”。
