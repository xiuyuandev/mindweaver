## 1. Xmind 2026 官方口径（与本次视觉直接相关）

| 能力 | 官方描述 | 对织思的启示 |
| --- | --- | --- |
| 快速样式 | 格式面板里四种标记：极其重要、重要、删去、默认；用于标注重要度与任务完成 | 检查器顶部应有“一眼可点”的快速样式，而不是把颜色藏进多层分组 |
| 自定义风格 | 从当前导图提取风格 → 风格编辑器 → 下一步定义快速样式 → 保存；格式面板「所有风格 → 自定义」可选取/右键编辑、重命名、复制、删除 | 主题不是一堆散落色板，而是“提取 → 编辑 → 保存 → 套用”的完整对象 |
| 设置 | `Ctrl+,`；外观跟随系统/浅色/深色；默认缩放 300/200/150/120/100/80/50%；默认风格；中日韩字体；应用后生效 | 设置面板要分区、可预期、即时生效；默认缩放与字体是显式选项 |
| 演说模式 | 演说者视图、深浅外观、幻灯片比例、三种演说节奏、隐藏分支、图片位置/全屏、`?` 快捷键 | 演示是独立“舞台”，不是把检查器叠在画布上 |
| 格式面板 | 快速样式、风格、颜色、分支线宽、主题元素都在“格式”上下文里 | 检查器应按“选中对象”切换内容，而不是永远展示同一堆控件 |
| 主题元素 | 备注、标签、边界、关系线、标记、图片、任务等是主题的附属物 | 检查器先回答“这个主题是什么”，再回答“给它加什么” |

## 2. 我们不再做什么

- 不再保留 13 套“换色即主题”的旧主题；只保留 **纸感**，新增 **墨夜 / 雾青 / 暖砂**。
- 不再用“每个分组一圈灰边框”表达层级；层级靠字号、留白、底色差和一条分隔线。
- 不再让检查器常驻所有控件；按选中对象与一级页签组织。
- 不再给按钮加多层阴影/渐变/描边；一个主操作、一个次操作、一个危险操作，其余收进菜单。

## 3. 设计系统 v4 目标

### 3.1 字体

| 角色 | 字号 | 行高 | 字重 |
| --- | --- | --- | --- |
| 画布中心 | 26 | 1.32 | 600 |
| 画布一级 | 19 | 1.38 | 600 |
| 画布正文 | 15 | 1.45 | 400 |
| 面板标题 | 14 | 1.4 | 600 |
| 面板正文 | 13 | 1.5 | 400 |
| 辅助/元信息 | 11.5 | 1.4 | 400 |

字体栈：`Microsoft YaHei UI` → `Segoe UI Variable` → `Segoe UI` → 系统 sans。数字与拉丁用 `Segoe UI Variable` 优先。

### 3.2 间距与圆角

- 间距只允许：`2 / 4 / 8 / 12 / 16 / 24 / 32`。
- 圆角只允许：`6`（小控件）、`10`（卡片/输入）、`14`（浮层）、`18`（大模态）。
- 面板内边距统一 `16`；分组之间 `24`；控件行高 `32`。

### 3.3 边框与阴影
- 边框只保留两级：`hairline`（#000 6%）与 `strong`（#000 12%）。
- 阴影只保留三级：
  - `PANEL`：y2 / blur8 / alpha18
  - `WINDOW`：y6 / blur22 / alpha30
  - `POPOVER`：y10 / blur28 / alpha38
- 禁止彩色阴影、禁止 1px 外再套 1px。

### 3.4 颜色

每套主题只给：
- 1 个画布底色
- 1 个面板底色
- 1 个卡片底色
- 1 个正文色 + 1 个弱化色
- 1 个强调色（只用于选中/主按钮/焦点）
- 6–8 个低饱和分支色

强调色不参与大面积填充；大面积只靠底色差与留白。

### 3.5 动效

- hover `120ms`、面板/页签 `180ms`、模态 `200ms`。
- 只做透明度和 2–4px 位移；不做弹跳、不做缩放超过 1.02。
- `reduce_motion` 下全部落位。

### 3.6 内容表面扩展（28 专属）

外壳与画布仍只允许 §3.2 的 `2 / 4 / 8 / 12 / 16 / 24 / 32`；**内容表面（全屏大纲、卡片笔记页、卡片库）额外允许页面级留白 `48 / 64 / 96`**，只用于：

- 页面上下边距（卡片页顶部 `48`、底部 `96`；库预览上下 `40 / 64`）。
- 版心左右留白与页面级大呼吸（大纲内容列居中、卡片段落之间 `12–16`、库页分区间 `32`）。

页面级留白**不得**降级成控件内距或列表行距；控件、列表、标签仍按 §3.2。内容表面的字号/行高/版心/状态/验收见 28 §4–§7 与 §9，不在本文重复。

## 5. 页面验收矩阵

每个主题至少过：

1. 开始页（空状态、最近文档、模板）
2. 画布（中心/一级/二级/标签/任务/图片/折叠/选中/悬停条）
3. 检查器（260 / 360 / 520 三档宽度）
4. 卡片阅读页（长文、代码、引用、标签）
5. 卡片库（列表、筛选、空状态）
6. 命令面板 / 搜索
7. 导出 / 设置 / 主题编辑器 / 版本历史 / 恢复中心
8. 演示模式
9. 1.0 / 1.5 / 2.0 三档 DPI

判定：无裁切、无重叠、无“每个分组一圈框”、无低于 4.5:1 的正文、无彩色阴影。

**内容表面的判定另加 28 §9 的八项人工判词**（10 秒测试、无盒测试、颜色测试、宽度测试、层级测试、5 分钟任务、模板测试、中文/IME 测试）。外壳矩阵通过不代表内容表面通过；两者证据分开归档。
