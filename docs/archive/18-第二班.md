## S01 真矢量 PDF 导出（完成）

### 做了什么

- 新模块 `crates/mw-shell/src/export_pdf.rs`：`Scene` → PDF 内容流，全部几何是路径，**没有一张位图**。
- 文字由 DirectWrite `GetGlyphRunOutline` 取字形轮廓，再写入 PDF 路径；粗体用「填充 + 细描边」补偿合成加粗。
- 连线、边界、概要、关系线、折叠圆点、角标、标签均走路径；半透明颜色先按画布底色混合成实色。
- A4 横向（842×595 pt）、36 pt 页边距、96 dpi → 72 pt（×0.75）；按节点矩形切带，优先把切线落在卡片空隙里。
- 每页用 PDF 裁剪窗口限定内容窗口；只写该页附近的图元，避免上千份字形轮廓在每页重复（文件从 13.6 MB 降到 1.7 MB）。
- 导出不再依赖 GPU：`Format::Pdf` 走 CPU 线程 `export_job::start_vector`；PNG 仍要求 GPU。
- CLI 批量导出：`mw-shell --export-pdf <输入.zmind> [--out <文件> | --out-dir <目录>] [--theme …]`，使用真实 DirectWrite 度量。
- 修复分页裁剪框的垂直锚点：裁剪框顶边固定贴内容带顶部（`PAGE_H - MARGIN`），否则带高不足一页时顶部整段被裁掉（Q3 卡片曾因此消失）。

## S03 卡片库透底伪影与 golden 矩阵（完成）

### 根因

- 不是卡片库配色或层次问题：`egui::Area` **默认带淡入**（`fade_in = true`）。卡片库是一整页 `Order::Foreground` 的 Area，开场数帧整页处于半透明，底下的画布与菜单/状态栏会透上来。
- 真实窗口里淡入只有百毫秒级，肉眼通常看不到；离屏 golden 在第 4 帧抓图，恰好落在淡入未完成的时刻，于是表现为「仅 harness 可见的右栏透底」。此前看到的画布节点残影与菜单残影同源。
- 修改前实测：整页背景 alpha=254、右栏 alpha=237（远低于不透明的 255），与淡入中间态吻合。

### 做了什么

- 卡片库 Area 加 `.fade_in(false)`：全屏页直接不透明，消除开场透底与离屏随机性。
- 卡片库打开时不再绘制画布（`main.rs` 中央面板早退）：整页不透明，画布本来就不可见，跳过可省一帧合成。
- `MW_LIBRARY_DEMO` 在笔记库为空时改用 `%TEMP%\mw-library-demo-v1` 里 4 张固定卡片（固定时间戳/标签），不读不写用户真实笔记库。
- 新增卡片库 golden 矩阵 `shots/golden/library/shell-ppp{1.00,1.50,2.00}.png`；`scripts/ci.ps1` 用 `MW_LIBRARY_DEMO=1` + `target/ci-appdata/library` 隔离 APPDATA 跑三档。

## S05 无证书签名钩子与发布文档（完成，正式证书待采购）

### 做了什么

- [`scripts/package.ps1`](../scripts/package.ps1) 接入签名钩子：先复制 exe 到暂存目录再签（失败不污染 `target\release`），新增 `-RequireSignature`；无证书时继续产出未签名 ZIP。

- 修复打包脚本真实缺陷：数组 splat `@('-Path', $exe)` 会按位置传参，`Path` 收到字面量 `-Path`；改为命名哈希表 splat。`sign.ps1` / `package.ps1` 补 UTF-8 BOM，PS 5.1 下中文不再乱码。

## S09 大纲聚焦子树与面包屑（完成，R13）

  - 重建时从聚焦点起栈，只收它和后代；自由主题与兄弟分支都不进聚焦视图；聚焦点等于文档根、或已被删除时自动退回全图。
  - 面包屑沿 `parent_id` 从文档根走到聚焦点，形状是「大纲 › 祖先 › 当前」。
- 聚焦根按「视图里的根」处理：
  - `depth = 0`、`parent = None`、`index = 0`，拖拽落在它前/后都按「挂成子节点」解释（与真根一致）；

  - 聚焦根的 Enter 落成「新建子节点」，避免新行建到视野外；

- 删除聚焦根：先记住父级，删除后退出聚焦并把选中与键盘焦点交给父节点，不会留在已消失的视野里。
- 表头（`outline_screen`）：

- 新增 `shots/golden/outline-focus/shell-ppp1.50.png` 基线（snow @1.5），`scripts/ci.ps1` 增加 outline focus golden 步骤。

## S10 大纲 20k 行性能（完成，R16）

### 做了什么

- 删掉每帧的 `collapsed_key(doc)`：旧实现每次 `sync` 都要遍历整张节点表、对所有折叠节点算一次 FNV 指纹；而 `SetCollapsed` 本来就走 `ChangeSet`、会推进 `revision`，这层「双保险」纯属每帧 O(n)。现在 `sync` 只做一次 `u64` 比较 + 一次主题 id 字符串比较。
- 筛选结果按下标缓存：
  - `Outline` 新增 `visible: Vec<usize>` 与 `filter_key: Option<String>`；
  - `ensure_visible(needle)` 只在筛选词变化或行缓存重建后扫一遍全表，其余帧不分配；
  - 绘制循环直接迭代缓存下标；键盘定位、「上一行 / 下一行」也复用同一份缓存，不再每帧另建一次可见行 `Vec`。
- 旧 `show()` 在 20k 行时每帧要做约三次全表筛选（计数、绘制、键盘），每次每行一次 `to_lowercase` 堆分配；现在滚动帧为零次。
- 新增 20k 行性能门测试：构建 4000 分支 × 4 叶（20001 行），断言冷重建只发生一次、200 帧空 `sync` 不重建、同一筛选词 200 帧不重扫、换词才重扫一次，并把四段耗时打印出来。
- 外观零改动：行高、缩进、角标、提示文案都没动，outline / outline-focus golden 用于守住「性能优化没改画面」。

### 证据

| 项 | 结果 |
| --- | --- |
| 冷重建（20,001 行） | `24.5033ms`（release，含分支色解析与 20k 行结构拷贝） |
| 空 `sync` 200 帧 | `1.5µs` 合计，约 `7.5ns/帧`；`rebuilds` 始终为 1 |
| 首次全表筛选 | `1.1935ms`（20k 行一次 `to_lowercase` + 子串匹配） |
| 同词复用 200 帧 | `600ns` 合计，`filter_scans` 始终为 1 |
| 测试 | `cargo test -p mw-shell panels::outline --release` 16 passed；新增 `twenty_thousand_rows_rebuild_once_and_filter_once` |
| 回归 | `cargo fmt --check` 通过；outline / outline-focus 两张 golden 在 CI 中逐像素复核（本包不改画面） |

### 已知边界

- 20k 行是 release 数字；debug 构建会慢一个量级，测试阈值按 debug 留了 10s 余量，只拦「每帧 O(n)」这类结构性回退。
- 性能门只覆盖「行缓存 + 筛选缓存」；滚动区仍是 `ScrollArea::show` 全量布局（egui 会跳过不可见行的绘制，但每帧仍会为 20k 行各分配一次占位矩形）。若真到 50k 行，需要换成 `show_rows` 的行高虚拟化。
- 筛选词每次输入变化都会整表扫一遍；20k 行约 1.2ms，打字时无明显卡顿，但没有做防抖或增量索引。
- 分支色 `resolve_all` 在每次文档修订后整树重算，仍是冷重建的大头；本次没有拆它。

## S15 大纲备注点直达检查器 + 三标记悬停提示（完成，R14 交互补全）

### 做了什么

- 备注点从只读变可点：单击行尾备注点 → 画布选中该节点 → 退出大纲、打开检查器、切到「内容」页，并把键盘焦点交给备注框（一次性 `note_focus_pending`，下一帧 `request_focus`）。没有备注时给 toast「这个主题还没有备注」，不空开面板。
- 新增 `Action::OpenNote(node)`，由 `app_methods_2` 解析：文档查询、轨迹 `outline_open_note node=… has_note=…`、选中与面板路由都在壳层完成；大纲面板仍只发 Action。
- 命中分派统一为 `marker_at`：任务框 / 备注点 / 卡片点三个 20pt 热区重叠时按「指针到中心最近」裁决，悬停与点击共用同一函数，避免提示与动作指向不同标记。
- 三个标记都有悬停提示：任务「待办/进行中/完成 · 单击…」、备注「单击在检查器中编辑」、卡片「单击打开」；指针靠近右边缘时提示向左翻转（`p.x + 220 > content_rect.right()`），不再折行。备注点悬停补圆底与手型。
- 编辑行不注册任何角标热区，避免输入时误触。

| 真实窗口 | `shots/final/s15-live/note-open.png`：点备注点后画布选中「中文排版」，检查器「内容」页显示备注「标点悬挂与避头尾规则要逐条对照。」；`note-tip2.png` 为一行提示；`outline-again.png` 为 F8 返回大纲 |

- 6pt 点体的发现性仍依赖悬停提示；后续可考虑选中行常显标记文字。
