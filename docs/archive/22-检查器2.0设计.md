# 检查器 2.0：三包设计（I01–I03）

> 2026-10-21 · 设计稿，尚未改代码。
> 触发：用户反馈「检查器的功能、布局、各种东西都很丑，交互差，点击手感也不好」。
> 参考：XMind 26.5 样式面板，只读截图 `shots/qa/xmind-style.png`、`shots/qa/xmind-style2.png`。
> 现状实拍：`shots/qa/current-inspector-style.png`、`current-inspector-content.png`、`current-inspector-mark.png`、`shots/final/acceptance/inspector-p1.50.png`。
> 约束：纯 Rust / egui；检查器只发 `Action` / `mw_core::Command`；不碰 `mw-core/src/theme.rs`、`mw-render/src/instances.rs`；冻结发布包不动；XMind 只读。

## 0. 一句话

把检查器从「一列 260px 的控件堆」升级成「320px、分组可折叠、XMind 式表单、键鼠同权、点下去有反馈」的原生面板。

三包分别解决：

| 包 | 解决的问题 | 用户感知 |
| --- | --- | --- |
| I01 骨架与信息架构 | 挤、乱、重点埋在下半屏 | 打开就知道先改哪里 |
| I02 视觉与控件 | 控件小、杂、像半成品 | 每个控件都像同一个产品里的 |
| I03 手感与键盘 | 点不准、没反馈、键鼠体验断裂 | 点得中、看得见、撤得回 |

三包按顺序做，每包都能单独编译、单独截图、单独验收。

## 1. 现状（有证据的硬伤）

| # | 问题 | 证据 | 后果 |
| --- | --- | --- | --- |
| 1 | 默认只有 260px，且 11 个色点挤在一行 | `PANEL_W = 260.0`（`inspector.rs:65`）；现状截图色点直径 12px、格 17px | 每个色点实际命中 17×17，手指和触控板都难点 |
| 2 | 色点、页签、关闭、重置普遍小于 32px | 色点 17；页签 28；关闭 20；分段 24–26；重置只有文字 ↺ | 不达 Windows 桌面最小点击目标，点空率高 |
| 3 | 三行颜色各带一行「自定义…」，九行圆点占掉首屏 | 现状样式页：填充 / 分支线 / 文字 三排色点，+ 三条自定义行 | 形状、字号、粗斜体全部掉到折叠线以下 |
| 4 | 自绘控件与 egui 默认控件混用 | `seg`/`toggle`/`swatches` 是自绘；`checkbox`、`menu_button`、`button`、`color_edit_button_srgba` 是默认 | 高度 18–28 不等，字体、边距、圆角、悬停色全不一样 |
| 5 | 分组只有一条 3px 色条 + 一行字，没有折叠 | `section_label_hint`（`inspector.rs:348`） | 长页面没有节奏，用户只能一路滚 |
| 6 | 内容页把备注、任务、图片、卡片、链接竖着堆 | `note_body` / `card_section` / `link_body`（`inspector_methods_1.rs:732/888/971`） | 备注框独占 9 行，其它能力像附赠品 |
| 7 | 文档页所有设置全部展开 | `doc_body`（`inspector_methods_2.rs:304`）：主题、强调色、对比度、7 行配色微调、线型 | 首屏被主题占满，对比度和微调埋得很深 |
| 8 | 只有 hover，没有按下、选中过渡和键盘空间感 | 现有 `seg` 只有 selected/hover 两态；色点只有选中环 | 点下去像点在一张图上，不像按钮 |
| 9 | 备注手动保存，保存/清除是默认按钮 | `note_body` 的默认「保存 / 清除」 | 和全应用「即时保存」的心智不一致 |
| 10 | 没有样式预览，没有作用域粘性 | 作用域分段在样式页最上面，滚动后消失 | 改到下半页时不知道自己在改当前节点还是整棵子树 |

XMind 值得抄的不是配色，而是**表单秩序**：灰底面板、白控件、40px 行高、分组可折叠、一个色井代替一排小点、下拉里带形状预览、左侧标签右侧控件、当前值始终可见。

## 2. 目标形态

### 2.1 线框

```
┌────────────────────────────────────┐
│ 检查器                          ×  │ 48  面板头
│ ◆ 2026 路线图                      │ 56  身份区（类型图标 / 标题 / 元信息）
│   中心主题 · 4 个子主题             │
│ ┌──────────┬──────────┬──────────┐ │
│ │  样式    │  内容    │  标记    │ │ 36  页签
│ └──────────┴──────────┴──────────┘ │
│ 作用   [ 当前节点 ] [ 含子树 ]      │ 40  粘性作用域
│ ┌────────────────────────────────┐ │
│ │ ▾ 形状              圆角 · 1px │ │ 40  分组头（整行可点）
│ │ 形状    [▢ 圆角             ▾] │ │ 40
│ │ 填充    [■] #FFFFFF         ↺  │ │ 40  色井 + 当前值 + 覆盖时出现重置
│ │ 边框    [□] 1 px            ▾  │ │ 40
│ ├────────────────────────────────┤ │
│ │ ▾ 文字                   18 px │ │
│ │ 字号    [18 px              ▾] │ │
│ │ 颜色    [■] #2A2E33         ↺  │ │
│ │ 字重    [ B ] [ I ]         ↺  │ │
│ ├────────────────────────────────┤ │
│ │ ▾ 分支线              跟随主题 │ │
│ │ 颜色    [●] 主题强调色      ↺  │ │
│ └────────────────────────────────┘ │

└────────────────────────────────────┘
```

### 2.2 尺寸与令牌

| 项 | 目标值 | 说明 |
| --- | --- | --- |
| 面板默认宽 | 320 | 从 260 提升；280 最小，560 最大；旧存档 260 迁移到 280 |
| 面板内边距 | 16 | 与大纲、状态栏同一内距 |
| 页签高 | 36 | 3 等分，白色选中胶囊，不再用强调色填充 |
| 分组头 | 40 | 整行可点，右侧显示折叠摘要 |
| 表单行 | 40 | 标签 13px，控件 32–36px |
| 卡片 | 圆角 10，1px 描边，内距 12 | 面板底 `panel2`，卡片底 `panel`，不堆阴影 |
| 色井 | 28×28，命中 32×32 | 圆角 7；内圈 1px；覆盖时右侧出现 24px 重置 |
| 图标按钮 | 28×28，命中 32×32 | 关闭、重置、更多统一 |
| 分段 / 任务 / 标签 | 高 32 | 分段最小宽 64，不再 24 高 |
| 字号 | 标题 14 强 / 行标签 13 / 值 13 / 摘要 11 | 沿用现有 `Type`，不再出现 10.5 |
| 动效 | hover 90ms / press 70ms / focus 120ms / 分组 120ms | `reduce_motion` 与 golden 下直接落位 |
| 正文对比度 | ≥ 4.5:1 | 沿用主题令牌，不新增颜色体系 |

### 2.3 取与不取

**取：**

- 灰底面板 + 白控件：控件边界不靠阴影，靠明度和 1px 描边。
- 分组可折叠，标题即状态：折叠后仍显示「圆角 · 1px」这类摘要。
- 一个色井 + 弹层，代替一排 11 个色点。
- 形状/字号用带预览的下拉，而不是四个等宽文字段。
- 40px 行高，标签在左、控件在右，扫读路径固定。
- 顶部身份区显示「你在改什么」，作用域常驻。

**不取：**

- XMind 的升级横幅、演说页、主题市场。
- 为了像 XMind 而新增模型没有的字段：字体家族、文本对齐、固定节点宽度、下划线/删除线、节点类型切换。这些留给后续数据模型包。
- 富文本备注。备注仍是纯文本 Markdown 草稿，Typora 式排版在卡片阅读页。

## 3. I01 · 骨架与信息架构

### 目标

先把「东西放哪里」做对：面板变宽、页签变清楚、所有设置进入可折叠分组、首屏顺序符合使用频率。I01 结束时即使控件还是旧样式，结构也已经是 2.0。

### 具体改动

1. **面板宽度**
   - `PANEL_W` 260 → 320；`window_state` 默认 320，clamp 280–560；旧值自动迁移。
   - `app_methods_2.rs:1387` 的 `max_w` 改为 `(available - 360).clamp(280, 560)`；`app_methods_1.rs` 的 `MW_INSPECTOR_W` 同步。
   - 窗口过窄时优先保画布 360px，面板可降到 280；低于 280 不硬挤。
   - 更新 `inspector_width_round_trips_and_clamps`：333 往返、9999→560、10→280。

2. **面板头 + 身份区**
   - 48px 面板头：「检查器」13px 强 + 28px 关闭。
   - 56px 身份区：32px 节点类型图标（中心/分支/自由/多选/关系线/概要/边界/文档）+ 标题 16px 强 + 元信息 11px。
   - 节点元信息：`中心主题 · 4 个子主题`；多选：`已选 3 个主题`；文档：文件名 + 主题数；关系线：`起点 → 终点`。
   - 身份区不参与滚动，滚动时始终知道在改谁。

3. **页签**
   - 3 等分 36px，白色选中胶囊 + 1px 描边；未选中 hover 用 `hover` 底。
   - 页签仍只在节点态出现；文档/关系线/注解/多选使用各自身份区，不强行套三页签。
   - 页签切换不重置滚动位置之外的编辑草稿；备注/链接草稿保持现有同步逻辑。

4. **粘性作用域**
   - 样式页在页签下方固定 40px：「作用  [当前节点] [含子树]」。
   - 滚动正文时不随内容滚走，避免改到下半页忘了作用域。

5. **分组卡片系统**
   - 新增 `SectionId` 枚举（Shape/Text/Branch/Note/Task/Card/Link/Image/Icon/Label/Annotations/DocTheme/DocAccent/DocContrast/DocPalette/DocLine）。
   - `Inspector` 保存本次会话的展开状态；默认：形状、文字、分支线、备注、任务、卡片、图标、标签、主题、强调色展开；链接、图片、对比度、配色微调、文档信息默认折叠。
   - 分组头 40px：左侧 16px chevron（展开 90°，收起 0°）+ 标题 13px 强 + 右侧摘要 11px；整行 `Sense::click()`，键盘 Space/Enter 可切换。
   - 折叠后摘要显示当前值，例如「形状 · 圆角」「填充 · #FFFFFF」「备注 · 24 字」「主题 · 纸感」。
   - 卡片底 `panel`、面板底 `panel2`、1px `border`，圆角 10；正文内距 12。
   - 删除 `ui.separator()` 和零散 `add_space`，统一 4px 网格。

6. **三页重排**
   - **样式**：形状（形状 / 填充 / 边框）→ 文字（字号 / 颜色 / 字重）→ 分支线（颜色 / 继承说明）。
   - **内容**：备注（6 行，可展开）→ 任务 → 卡片笔记 → 链接（折叠）→ 图片（折叠）。
   - **标记**：图标 → 标签 → 概要/边界（仅在有选中注解时出现）。
   - **文档**：主题 → 强调色 → 对比度（折叠）→ 配色微调（折叠）→ 线条与布局 → 文档信息（折叠）。
   - **关系线/注解/多选**：身份区 + 同样的分组卡片，不再出现裸标题和默认按钮。

7. **首屏预算**
   - 在 320×720 逻辑尺寸下，样式页首屏完整看到：作用域、形状、填充、边框、字号、文字颜色、B/I、分支线颜色。
   - 内容页首屏看到：备注编辑框、任务、卡片笔记；链接和图片以折叠摘要出现。
   - 文档页首屏看到：主题网格与强调色；对比度和微调折叠。

### 技术落点

- `crates/mw-shell/src/panels/inspector.rs`：`PANEL_W`、`Ink`、`SectionId`、`open_sections`、`Action` 不变（I01 不新增命令）。
- 新增 `crates/mw-shell/src/panels/inspector/tokens.rs`：`PANEL_W`、`HEADER_H`、`ROW_H`、`SECTION_H`、`WELL`、`ICON_HIT`、`CARD_RADIUS`、`CARD_PAD`。
- 新增 `crates/mw-shell/src/panels/inspector/widgets.rs`：`section_card`、`field_row`、`panel_header`、`identity`、`tab_bar`、`sticky_scope`、`icon_button`、`value_menu`、`color_well`（I01 先做无弹层版本）、`hit_rect`。
- `inspector_methods_1.rs`：重写 `show`（133）、`tabs`（353）、`style_body`（381）、`note_body`（732）、`card_section`（888）、`link_body`（971）、`mark_body`（1070）、`relationship_body`（1461）。
- `inspector_methods_2.rs`：重排 `doc_body`（304）、`annotation_body`（4）、`multi_hint`（290）。
- `app_methods_2.rs:1387` 面板尺寸与分隔线；`app_methods_1.rs:205` 环境钩子；`window_state.rs:52/115/119` 默认值与 clamp。
- 新增确定性场景钩子：`MW_INSPECTOR_SELECT=root|first`、`MW_INSPECTOR_TAB=style|note|mark`、`MW_INSPECTOR_SECTION=`（可选），供 golden 和实拍使用。

### 验收

- 默认宽度 320；280/560 clamp 单测；旧存档 260 读成 280。
- 分组：默认展开/折叠集合有单测；折叠摘要包含当前值；页签切换后展开状态不丢。
- 样式页首屏预算用截图逐项核对（320×720、100% 与 150%）。
- `shots/golden/inspector-style/shell-ppp1.00.png`、`-p1.50.png` 等 4 个场景基线建立；`--tol 0` 连跑两次 0 差异。
- 现有 `inspector` 验收表面继续通过；18/18 不退化。

### 不做

- 色值弹层、边框/描边编辑、形状预览、自定义图标（I02）。
- 按压/动效、键盘空间导航、分栏拖拽手感、备注自动保存（I03）。

## 4. I02 · 视觉与控件

### 目标

把所有控件收进同一套视觉语言：灰底白卡、1px 边、8px 圆角、32–36px 命中、色井代替色点、下拉带预览。I02 结束后，检查器与画布、卡片页、大纲看起来是同一个产品。

### 具体改动

1. **统一控件层**
   - `widgets.rs` 提供：`section_card`、`field_row`、`color_well`、`color_popover`、`value_menu`、`shape_menu`、`font_menu`、`segmented`、`toggle_icon`、`icon_button`、`chip`、`text_field`、`empty_hint`。
   - 检查器内不再直接使用 `ui.button`、`ui.menu_button`、`ui.checkbox`、`ui.color_edit_button_srgba`、`ui.separator`（`TextEdit` 除外）。
   - 所有控件统一：高 32；圆角 8；1px 描边；白底；hover `hover`；active 底色再压 4%；focus 2px 强调环；disabled 40% 透明度。
   - 所有自绘控件补 `focus.note`、`PointingHand`、Space/Enter 激活；混合态用半环/中线表示，不再用小圆点。

2. **色井 + 颜色弹层**
   - 每行只留一个 28×28 色井 + 当前值（hex / 「跟随主题」/「无」）+ 覆盖时 24px 重置。
   - 点击色井打开 240×196 弹层：6×2 主题色、1 行「白 / 浅灰 / 正文」、1 行「最近使用」（最多 6）、hex 输入、`恢复主题`。
   - 弹层 120ms 淡入，Esc/点外关闭；键盘左右移动、Enter 选中；打开弹层不立即改色。
   - 色井内圈 1px 分隔线，保证白色填充也能看见边界。

3. **形状与文字**
   - 形状从 4 个 66px 分段改为 36px 下拉：当前值显示 24px 形状缩略图 + 名称；菜单 4 行，每行 20px 缩略图 + 名称 + 选中勾。
   - 新增「边框」行：色井 + 宽度下拉（无 / 1 / 1.5 / 2 / 3 px）。使用现有 `StyleOverride.stroke/stroke_width` 与 `SetStyle`，不改核心模型。
   - 字号下拉 36px，9 档；每行以对应字号显示「18 px」，不再所有行一样大。
   - 字重改为 32×32 的 B / I 图标按钮 + 覆盖时重置；粗体仍用双描边伪粗体。
   - 「分支线」色井 + 说明「沿子树继承」；线宽在文档页「线条与布局」统一改。

4. **内容页**
   - 备注：6 行编辑框，底部状态「正在输入… / 已保存」+ `Ctrl+Enter 保存并离开`；「展开」切 12 行；不再放默认「保存 / 清除」大按钮。
   - 任务：3 枚 36px 状态胶囊（未开始 / 进行中 / 完成）+ 24px 清除；选中态用状态色浅底，不抢强调色。
   - 卡片笔记：64px 卡片行，左侧 32px 卡片图标，标题 13px 强 + 80 字摘要；右侧 32px「打开」；未链接时一枚 32px `新建卡片笔记`。
   - 链接：32px 输入框 + 24px 打开 + 24px 清除；输入框失焦校验，非法 URL 在框下显示 11px 错误文案（现有校验函数已具备）。
   - 图片：56×42 缩略图（加载失败显示占位）+ 文件名 + `更换` / `移除`；无图时一个 32px `添加图片…`。

5. **标记页**
   - 图标 6 列 × 2 行，36×36 命中，20px 图标；选中浅强调底 + 1.5px 环 + 右上角 8px 勾。
   - 「清除图标」24px 图标按钮，放在分组头右侧。
   - 标签胶囊 28px 高，14px 关闭热区扩到 20；输入 32px + `添加` 32px。
   - 概要/边界：每行 40px，色井 24 + 文字（概要文字/跨度 N）+ 24px 编辑 + 24px 删除；不再用「✎」字符按钮和 14px 圆点。

6. **文档页**
   - 主题：2×2 卡片 136×84，每张画 3 个迷你节点 + 连线 + 主题名；选中 1.5px 强调边 + 勾。保留「存为我的主题」32px 次按钮。
   - 强调色：10 枚 28px 色相井 + 1 枚自定义井，一行 6 + 一行 5；`主题默认` 24px。
   - 对比度：折叠，摘要显示「AA 3/3」；展开每行 36px，等级用 11px 胶囊。
   - 配色微调：折叠，7 行 × 6 色井，行高 36；`恢复` 为 24px 图标按钮。
   - 线条与布局：线宽/收细分段 36px 高；标签 13px。

7. **关系线 / 注解 / 多选**
   - 关系线：身份区 `起点 → 终点` 两枚 28px 节点胶囊；标签输入 32px；端点列表 36px 行；删除为 32px 危险按钮（低饱和红，不整行红）。
   - 注解：跨度胶囊 24px；颜色井；编辑/删除 24px。
   - 多选：身份区 `已选 N 个主题`；样式页作用域默认「含子树」时显示明确提示；内容页只显示不可批量编辑的说明卡。

### 技术落点

- 新增 `inspector/icons.rs`：`chevron`、`reset`、`close`、`check`、`plus`、`open`、`note`、`card`、`image`、`link`、`fill`、`border`、`branch` 等 16px 线性图标，用 painter 描边绘制，不引入图标字体。

- `inspector_methods_1.rs`：`style_body` 改为三个 section；`note_body`/`card_section`/`link_body` 重写；`mark_body` 重写。
- `inspector_methods_2.rs`：`doc_body` 重写；`annotation_body`/`relationship_body` 统一。
- `Ink` 增加派生色：`card`、`card_border`、`control`、`control_hover`、`control_pressed`、`focus_ring`，全部从现有 `Chrome` 派生，不改 `theme.rs`。
- `Action` 不新增语义；描边继续走 `SetStyle`。

### 验收

- 控件尺寸单测：色井 28/命中 32、图标格 36、行高 40、页签 36、分组头 40；网格布局函数返回的矩形不重叠、不越界。

- 全局主题令牌重写（只从现有 `Chrome` 派生，避免与另一会话的 `theme.rs` 冲突）。

## 5. I03 · 手感、键盘与就地编辑

### 目标

让检查器「点得中、按得下、看得见、退得出」：所有控件有按下态和焦点环；面板分栏有明确把手；备注自动保存；键盘能走完整个面板；动效克制且尊重减少动态。

### 具体改动

1. **按压与反馈**
   - 所有可点控件三态：hover（90ms 底色）、pressed（70ms 底色再压 4% + 控件内缩 1px）、focus（2px 强调环，120ms 淡入）。
   - 色井 hover：色块从 28 长到 30（布局不跳动，向外 1px），外圈 2px；按下时收缩到 27。
   - 图标格选中：底色 + 环 + 勾同时出现，不做弹簧；标签关闭 X 热区 20×20。
   - 点击只在松手时提交一次；拖出控件后松手不触发（`Sense::click` + `drag` 抑制）；`MW_TRACE` 记录一次 `inspector-apply`，防止键盘/鼠标双触发。

2. **分栏把手**
   - 面板左缘 8px 命中条；hover 显示 3px 强调色竖条 + `ResizeHorizontal` 光标；拖动时浮出 `320 px` 小标签。
   - 双击复位 320；松手才写 `window.json`；拖动中不重排画布布局之外的缓存。
   - 宽度 280–560，窗口窄时优先保画布 360；拖到极限有 1px 回弹提示（不循环抖动）。

3. **键盘**
   - Tab 进入检查器先落当前页签；页签聚焦时 ←/→ 切换；`Alt+1/2/3` 直达样式/内容/标记。
   - 色井行：←/→ 在同一行，↑/↓ 跨行；图标格：←/→ 同排，↑/↓ 按 6 列跨行；Home/End 到首尾。
   - Space/Enter 激活所有自定义控件；Esc 的顺序：先关颜色弹层 → 再回画布（`Action::FocusCanvas`）；F9 仍关面板。
   - 焦点环不得被卡片裁切；焦点丢失后 Tab 回到上次位置；`FocusMemory` 稳定键沿用。

4. **备注与链接的就地编辑**
   - 备注停止输入 800ms 自动保存；失焦保存；`Ctrl+S` 立即保存；`Ctrl+Enter` 保存并离开；`Esc` 丢弃草稿回上次值。
   - 保存状态在备注框底部：`正在输入…`（warm）/`已保存`（faint），不弹 toast。
   - 保存走现有 `SetNote` 命令，仍是一步撤销；空备注=清除。
   - 链接失焦提交、Enter 提交、Esc 还原；非法 URL 不提交，保留草稿并聚焦。
   - 输入法组合期间不抢 Enter/Esc（用 egui 的 IME 状态判断），不重设焦点。

5. **分组与弹层**
   - 分组头按下态 + chevron 120ms 旋转；内容显隐即时，避免高度动画造成滚动跳动。
   - 颜色弹层打开时锁定面板滚动；点外/Esc 关闭；关闭后焦点回色井；打开时不改色。
   - 弹层在面板左右边缘自动翻转，不超出窗口。

6. **空态与多选**
   - 无选中时文档页身份区显示「未选中主题 · 正在编辑文档外观」；多选样式页顶部提示「一次修改 N 个主题，可一次撤销」。
   - 备注/链接多选时显示可读说明，不再只有一行灰字。

### 技术落点

- `Inspector` 增加 `reduce_motion: bool`（壳层注入，golden/harness 为 true）、`open_sections`、`popover: Option<PopoverState>`、`note_dirty_at: Option<f64>`、`note_saved_flash: f32`。
- `app_methods_2.rs` 面板分隔线与双击复位；`window_state.rs` 宽度持久化沿用。
- `widgets.rs` 增加 `press_state`、`focus_ring`、`animated_fill`、`splitter`。
- 备注自动保存复用 `sync_note`/`commit_note`；新增纯函数 `note_autosave_due(now, last_input)` 与测试。
- `MW_TRACE` 语义：`inspector-tab`、`inspector-section`、`inspector-apply`、`inspector-popover-open/close`、`inspector-width`、`inspector-note-save`。

### 验收

- 状态单测：pressed/hover/focus 三态优先级；开弹层不提交；一次点击只产生一个 Action；备注自动保存只在 800ms 后触发一次；Esc 顺序正确。
- 键盘走查脚本/清单：Tab 进入 → 页签 → 作用域 → 形状 → 色井 → 弹层 → 关闭 → 文字 → B/I → Esc 回画布，全程焦点可见。
- 真实窗口实拍：100%/150%，展开/折叠、开弹层、选色、输入备注、拖宽、双击复位，共 ≥ 10 张前后对比图（`shots/final/inspector2/`）。
- 备注自动保存与撤销：输入 → 800ms → 关闭面板 → 重开，内容保留；Ctrl+Z 回到上一版。
- `reduce_motion=true` 时无动画残留；golden 静态基线 0 差异。
- 现有 18/18 验收不退化；新增 inspector 场景后矩阵保持全 PASS。

### 不做

- 触摸手势、触控笔压感、拖拽排序标签。
- 面板浮动/停靠/多显示器独立面板。
- 跨重启记住每个分组的展开状态（先会话内；要持久化再进 `window.json`）。
