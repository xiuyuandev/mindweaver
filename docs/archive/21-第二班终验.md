## 4. 已知缺口（如实交接）

1. **输入法五款矩阵未签字**：本机只注册 3 个 IME 条目，候选窗跟随/翻页/云候选需在装有五款输入法的机器上按 `docs/19` 人工验收。
2. **双屏边界未测**：本机单显示器，脚本明确 SKIP；跨屏拖拽、候选窗跨屏位形需人工签字。
3. **PDF 文本是字形轮廓**：不可选中、不可搜索；节点图片未嵌入 PDF；需要文本可选的场景要另做字体嵌入/ToUnicode 方案。
4. **卡片图片暂不支持**：正文只处理 Markdown 文本与链接，粘贴图片尚未落盘。
5. **大纲备注点**：S15 已可点开并直达检查器备注页、自动聚焦；无备注时只 toast，不提供就地新建。
6. **大纲角标发现性**：S15 已给任务/备注/卡片三类标记加悬停提示与最近中心分派；仍缺右键菜单与底部 `Ctrl+T` 提示，6pt 点体仍需悬停才能确认含义。
7. **面包屑不截断**：极深树在窄窗口下会挤压，未做省略策略。
8. **斜杠菜单边界**：无图片/表格/公式/拖拽插入；窗口过矮时菜单上翻会盖住页头（仍完整可见），200% 下目录按 1040pt 断点收起。
9. **安装包未签名**：`SIGN SKIP`，SmartScreen 会提示；证书采购后走 `docs/20` 的签名参数即可。
10. **任务方框真机点击**：S15 真机验证了 Doing → Done（`shots/final/s15-live/task-done.png`）；再次点击清除后的帧因行焦点/滚动位移落到别的行，`task-cleared.png` 只作旁证，四态循环仍由单测与 `Ctrl+T` 覆盖。
11. **测试覆盖**：UI 命中/悬停仍以 golden + 实拍为主，没有像素级鼠标回归框架；角标上按下后若继续移动仍会启动行拖拽（纯单击不受影响），尚未加「角标区内禁止起拖」的守卫。

## 5. 交接建议（按用户价值）

1. 在测试机补齐五款输入法与双屏人工签字，回填 `docs/19`。
2. 卡片图片：粘贴/拖入 → 本地资源目录 → 导出与 PDF 嵌入，一次做完。
3. PDF 文本可选：字体嵌入 + ToUnicode，或提供「矢量版/可选文本版」两个预设。
4. 大纲角标：补右键菜单（直接设四态、打开卡片/备注）与底部快捷键提示；悬停提示与备注路由已在 S15 完成。
5. 备注就地编辑：当前点备注点会退出大纲进检查器；若要留在大纲，需要行内备注编辑面。
6. 正式签名：采购证书后跑 `scripts/package.ps1 -SignThumbprint …`，更新 `docs/20` 的哈希。
