## 2. 高层差距

| 区域 | Xmind 基准特征 | 当前织思 | 根因 | 优先级 |
| --- | --- | --- | --- | --- |
| 应用外壳 | 极简标题信息、中央悬浮操作簇、低频功能收进菜单 | 顶部文字菜单和图标按钮同时常驻，层级较平 | 缺少统一 chrome 组件与信息架构 | P0 |

| 选择反馈 | 主选、多选、悬停、拖动各有稳定视觉 | 主选/多选已有基础，但缺少统一状态表和节点工具条 | 选择状态分散在画布与大纲 | P0 |

## 3. 功能完成度重新分类

旧清单把“命令存在、UI 有入口、截图能出来”都写成完成。X100 改成以下口径：

| 状态 | 定义 |
| --- | --- |
| 已有基础 | 模型或命令可用，但界面/交互/证据至少缺一项 |
| 已实现 | 功能可达，尚未完成全状态视觉与真实输入证据 |
| 已验证 | 行为、视觉、回归、工程四类证据齐全 |
| 阻塞 | 已知问题使流程无法完成，必须列 P0/P1 |
| 延后 | 不属于核心 1.0 或本轮范围 |

当前核心能力的重新分类：

| 能力 | 当前状态 | 主要缺口 |
| --- | --- | --- |
| 新建/打开/保存/恢复 | 已有基础 | 生命周期 UI 与失败状态未统一 |
| 中心/多级节点 | 已实现 | 节点形状、字阶和局部操作条未对齐 |
| Enter/Tab/F2/双击/IME | 已实现 | 多行、跨 DPI 与全入口证据仍不足 |
| 拖拽改父/多选/批量 | 已实现 | 自动展开/滚动、节点条和非法状态未完整验收 |
| 五种布局 | 已有基础 | 树表、矩阵等布局缺失，参数与过渡不统一 |
| 主题与逐节点样式 | 已有基础 | 字体、对齐、形状和线型模型不足 |
| 检查器 | 已有基础 | 对象感知信息架构未完成 |
| 大纲 | 已有基础 | O04 未收尾，搜索和筛选未完成 |
| 搜索 | 已有基础 | 祖先上下文、高亮、筛选和替换不完整 |
| 关系线/概要/边界 | 已有基础 | 创建入口、选择、拖手柄和样式细节不完整 |
| 图片/附件 | 已有基础 | 实际媒体编辑体验与导出不完整 |
| 评论/音频/标注框 | 未开始 | 需要数据模型、命令、格式和 UI |
| 多画布/Sheet | 未开始 | 需要 Workbook 模型和迁移 |
| 导入 | 已有基础 | 丢失项报告、多画布和高级字段不足 |
| 导出 | 已有基础 | 范围、可搜索 PDF、图片和预览需升级 |
| 演示 | 已有基础 | 演讲者备注、完整舞台和多屏不足 |
| 卡片/复习/知识视图 | 已有基础 | 保留但降低主入口优先级 |

Xmind，再决定是否保留旧设计中的行级快捷层，不能为了兼容旧计划继续强化不存在的交互。

## 5. P0 修复顺序

1. 证据闭环：参考 manifest、同视口本项目图、差距编号和 trace。
2. 外壳与组件：统一菜单、标题栏、图标、浮层和按钮密度。
3. 画布：节点、分支、选择、折叠和局部工具条。
4. 编辑：键盘、IME、多行、拖拽和上下文菜单。
5. 检查器与样式：对象感知页签、字体/线型/形状模型。
6. 大纲与搜索：完成 O04 后按 X100 重做。
7. 文档与互通：多画布、导入丢失报告、导出范围和 PDF。

## 6. 明确不做

- 不追求逐像素复刻 Xmind 品牌界面，只对齐核心几何、信息层级和手感。
- 不复制 Xmind 专有字体、图标、模板、贴纸、文案或静态资源。
- 不实现账号、云同步、团队协作、社区模板商城、移动端和联网 AI。
- 不因为“大多数功能”把低频扩展做成核心路径的常驻按钮。
