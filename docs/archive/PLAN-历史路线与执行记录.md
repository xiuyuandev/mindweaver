## 0. 现状判断（不留情面）

现有版本能画、能存、能导、测试也绿，但作为"产品"是失败的：

| 层面 | 问题 |
| --- | --- |
| 视觉 | 没有设计系统。字号/间距/圆角/描边都是逐处硬编码的魔数；卡片内距不一致；面板密度忽松忽紧；图标是字符拼的 |
| 配色 | 纯白画布 + 近黑文字，长时间看得眼睛累；9 套主题里真正"能看"的只有 2–3 套；强调色满天飞 |
| 排版 | 行高偏紧，中英混排的基线不齐，粗体用得太随意，层级靠字号硬撑 |
| 交互 | 大量操作只有菜单入口；没有悬停工具条；没有过渡动效；选中/悬停反馈只有一种描边 |
| 结构 | 工具栏是功能按钮的堆叠，没有分组语义；空状态、错误提示、加载态都很粗糙 |

**结论：不是加功能，是重做"呈现层"。** 功能该有的基本都有了，问题在它长得不像产品。

## 1. 目标（明早验收什么）

1. 打开即"哇"：默认主题是**纸感暖白**（不是刺眼纯白），卡片有呼吸感，连线柔和，整体像一个成熟笔记产品。
2. 视觉一致性：全应用只用**一套令牌**（字阶/间距/圆角/描边/动效），改一处全局生效。
3. 交互有质感：悬停有反馈、拖拽有暗示、切换有 120–180ms 的缓动，不突兀。
4. 护眼：默认浅色低眩光；内置一套真正调过的**深色**；文字对比度全部 >= 4.5:1。
5. 门槛不破：`cargo test` / `fmt` / `clippy`（新增 0）/ `golden --tol 0` 全绿。

## 7. 400 小时 / 80 包产品路线图（P01–P80）

> **产品定位（这一版写死，不再漂移）**：GitHub 上的开源本地知识工具，不收费、不联网、不做账户/云同步/多语言/遥测/升级体系。
> 目标只有一个：**让一个人用思维导图吸收、组织、内化知识**。导图负责结构，卡片笔记负责深度；检查器是第二工作台，不是属性表单；
> 任何浮层都不能遮挡用户正在看/正在编辑的对象。质感、留白、排版、动效、键盘路径与基础功能同等重要。
>
> **施工单位**：80 个包 × 5 小时 = **400 小时**。每包必须是一个可编译纵切（模型 → 命令/状态 → UI → 测试 → 记录），
> 不允许把"编译不过"留过包边界。P01–P13 已完成，另有导入异步前置提前落地；当前断点见下。

### 产品原则（所有包都受这六条约束）

1. **本地优先**：所有内容可离线读写；卡片笔记是磁盘上的 Markdown，应用删了也能读。
2. **结构 × 深度**：节点是索引，卡片是内容；不允许把长文塞进节点备注假装笔记。
3. **检查器 2.0**：分组、折叠、即时预览、键盘可达；宽度可调，永不盖住画布焦点。
4. **不遮挡**：浮动工具条、菜单、检查器、搜索条、卡片阅读页之间必须有避让/互斥规则；同一时刻只有一个"工作表面"抢指针。
5. **克制动效**：120/180/240ms 三档，全部来自令牌；不为炫技加动画。
6. **可测**：视觉用像素/几何代理，交互用状态断言，性能用 release 基准；每个包至少留下一条可复跑证据。

### 明确不做（防止再次跑偏）

- 不做英文版 / i18n / 多语言切换。
- 不做付费、订阅、License 校验、升级弹窗、账户体系。
- 不做云同步、协作、分享链接、遥测、崩溃上报上传。
- 不做插件市场、模板商店、AI 功能。
- 保留：开源 LICENSE、便携 ZIP/安装器、文件关联、文档与贡献指南。

### 卡片笔记的架构决定（P07 起按此实现，避免返工）

- **数据**：`NoteCard { id, title, body_markdown, tags, created_at, updated_at, source_doc, source_node }`。
- **存储**：`.zmind` 包内 `notes/<card-id>.md` + `notes/index.json`；正文是纯 Markdown，front matter 存 id/title/tags/链接。
- **全局库**：`%APPDATA%\织思\notes\` 维护索引，聚合最近文档内嵌卡片；打开文档时合并、去重、修复孤儿。
- **链接**：节点存 `card_id`；卡片存 `source_doc` + `source_node`；节点移动/改名不破坏链接，节点删除卡片保留为孤儿并在库中可见。
- **标签**：卡片的一等字段（不是正文里的 `#tag`），支持补全、重命名、颜色、层级；正文里的 `#tag` 仅作为快捷输入。
- **渲染**：阅读页、编辑器预览、库预览、导出共用同一个 Markdown 渲染器；不允许四套排版。
- **搜索**：卡片标题/正文/标签/反链统一入口；中文按字/词混合索引，支持拼音首字母。
