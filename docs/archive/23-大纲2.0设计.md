# 大纲 2.0：八包设计（O01–O08）

> 2026-10-21 · 设计已确认；O01–O03 已落地，O04 已落地约 80% 后中途交接（实施记录见 §16，接手先读 [`HANDOFF.md`](../HANDOFF.md)）。
> 触发：用户反馈「大纲功能实在太弱，界面也很丑，没有丝滑感，编辑体验和视觉效果都不好」，要求完全参考 XMind，并吸收幕布的实现方式。
> 参考：XMind 大纲公开指南、幕布新手指南 / 快捷键、现有只读截图 `shots/qa/xmind-nodebar.png`、`shots/qa/xmind-new-1.png`。
> 现状实拍：`shots/final/acceptance/outline-p1.50.png`、`shots/golden/outline/shell-ppp1.50.png`。
> 约束：纯 Rust / egui，不使用 WebView；大纲面板只发 `Action`，出了闭包再映射为 `mw_core::Command`；不碰 `crates/mw-core/src/theme.rs`、`crates/mw-render/src/instances.rs`；XMind 只读；冻结发布包 `dist/zhisi-v0.1.0-win64.zip` 不动；测试与截图只用隔离 `APPDATA` 和临时文档。

## 0. 一句话

把大纲从「一张能缩进的表」升级成「像 XMind / 幕布一样，键盘不断线、拖拽有落点、长文有呼吸、任务与标签长在行里」的编辑表面。

八包分别解决：

| 包 | 解决的问题 | 用户感知 |
| --- | --- | --- |
| O01 视觉基座 | 行、层级、选中、文字样式都停在「能用」 | 第一眼像编辑器，有主次、有呼吸 |
| O02 页头与页脚 | 页头只有一行字，页脚是静态说明书 | 工具随手可及，状态随时可见 |
| O03 行内编辑 2.0 | 只能单行改名，回车不会长出新行 | 打字即编辑，回车即下一行 |
| O04 多选、拖拽与剪贴板 | 只能单选，拖拽没有把手和落点 | 像编辑器一样选、拖、批量改 |
| O05 查找与筛选 2.0 | 筛选会丢祖先，找不到折叠里的节点 | 找得到、看得见上下文、不搞乱折叠 |
| O06 行的语义 | 任务、标签、备注、卡片只是几个点 | 语义直接长在行里，点得到、看得懂 |
| O07 专注、模式与导出 | 聚焦只是少显示几行，切换丢状态 | 专注、画布、导出是同一套动作 |
| O08 丝滑度与排版引擎 | 固定行高、全量分配、无动画、无换行 | 20k 节点仍顺，动画不挡手，DPI/IME 不破 |

顺序建议 O01 → O02 / O03 → O04 / O05 → O06 → O07 → O08。每包都能单独编译、单独截图、单独验收；O08 做最终收口。

## 1. 现状：不是缺功能，是每个功能都停在「能用」

### 1.1 有证据的硬伤

| # | 问题 | 证据 | 后果 |
| --- | --- | --- | --- |
| 1 | 所有行固定 38px，层级只靠字号差 | `ROW_H = 38.0`（[outline.rs:35](../crates/mw-shell/src/panels/outline.rs#L35)）；`row_font()` 根 17 / 一级 15 / 更深 13.5（[outline.rs:365](../crates/mw-shell/src/panels/outline.rs#L365)） | 长标题被硬切；行与行没有节奏，深层级越看越平 |

| 12 | 页头只有「← 画布 / 大纲 / N 个主题」，页脚是固定长句 | [app_methods_2.rs:1141](../crates/mw-shell/src/app_methods_2.rs#L1141) | 折叠层级、密度、导出、帮助都没有入口 |
| 13 | 默认常驻一条 36px 搜索框 | 现有 `filter` 区 | 没搜索时也占着一整行，正文被推低 |

### 1.2 核心能力其实比 UI 走得远

`mw-core::Command` 已经支持：

- `DeleteNodes { ids }`：批量删除（[command.rs:30](../crates/mw-core/src/command.rs#L30)）
- `SetIcon { ids, icon }`、`SetStyle { ids, style }`：批量语义与样式（[command.rs:47](../crates/mw-core/src/command.rs#L47)、[command.rs:51](../crates/mw-core/src/command.rs#L51)）
- `AddLabel / RemoveLabel`：标签（[command.rs:156](../crates/mw-core/src/command.rs#L156)）
- `SetCollapsedAll`：全局折叠（[command.rs:60](../crates/mw-core/src/command.rs#L60)）
- `SetNote`、`SetNodeCard`、`SetTask`、`SetLink`：行内语义
- `Batch { commands }`：单条撤销记录、失败整体回滚（[command.rs:223](../crates/mw-core/src/command.rs#L223)）

大纲当前只用了 `SetText / MoveNode / SetTask / DeleteNodes` 等少数几条，大量能力没有入口。**这次升级的主体是 UI 编排与交互，不是改文档模型。** 这是八包能控制风险的前提。

### 2.2 一行的解剖

```
[拖拽把手 14][＋/⋮ 28][折叠箭头 18][任务框/项目符号 14][标题 ........][标签][备注][卡片][链接]
     hover 才显形         常驻           常驻          按内容       行内    右缘图标簇
```

- **左侧留槽**：拖拽把手与 `＋ / ⋮` 共用 42px 留槽，始终预留，悬停显形时不顶动文字。
- **折叠箭头**：有子节点才画；点击热区 22×行高。
- **任务框/项目符号**：有任务时项目符号变成任务框；没有任务时仍是分支色圆点。放在文字前，符合幕布的任务阅读顺序；XMind 的标记在行尾，这里取「一眼看到要做的事」。
- **标题**：单行省略；O08 支持 `Shift+Enter` 换行后的多行。
- **标签**：行内 chip，最多露 2 个，其余 `+n`；点击即筛选。
- **右缘图标簇**：备注、卡片、链接；固定槽位，永远给文字留出空间。
- **hover**：左侧把手 + `＋` + `⋮` 淡入 90ms；行底铺 `panel2` 圆角 8。
- **选中**：低透明度强调色底 + 1px 强调色内描边；文字保持正文色，只有项目符号和折叠箭头变强调色。键盘焦点另有一圈 2px 焦点环（仅键盘可见时）。
- **层级线**：只画「祖先还有后续兄弟」的那几层；当前行从最后一条竖线拐一个肘到项目符号，行底不再无限延伸。

### 2.5 取与不取

**取：**

- 大纲首先是键盘工具：Enter / Tab / Shift+Tab / 方向键必须一条不断。
- 拖拽必须有「拖的是什么、会落到哪、落到第几层」三件事同时可见。
- 任务、标签、备注、卡片是行的一部分，不是检查器里的附赠品。
- 搜索保留祖先上下文；筛选不改变文档的折叠状态。
- 页头只放高频动作；低频动作进 `…` 菜单；页脚随场景换提示。
- 动效只做「看得见的反馈」，不做行高动画；`reduce_motion` 下全部落位。

**不取：**

- **不照搬幕布的 `Ctrl+Enter` 切换任务**：本产品已有「Ctrl+Enter 新建子级」的肌肉记忆，冲突代价大于收益；任务继续用 `Ctrl+T` 和点击复选框，帮助页标注差异。
- XMind 的升级横幅、主题市场、演说模式、贴纸/插画标记。
- 幕布的块文档、附件、分享协作、移动端手势、云端能力。
- 富文本（下划线、删除线样式、字体家族、对齐、固定节点宽度）；节点文字仍是纯文本 + 现有 `StyleOverride`，完成态划线是任务语义的呈现，不是新的富文本字段。
- 为了像大纲而改文档格式；所有新状态只存在 `Outline` / `Shell`，不写进 `.zmind`。
- WebView、HTML、CSS、JS、Electron、Tauri。

## 4. O01 · 视觉基座：行、层级与选择

### 目标

先把「一行」做对。O01 结束时，即使编辑、拖拽、搜索还没升级，大纲也应该一眼像 XMind / 幕布，而不是一张带缩进的表。

### 具体改动

1. **行模型扩展**
   - `Row` 增加：
     - `last: bool`：是否为本层最后一个孩子。
     - `guide_mask: u64`：哪些祖先层仍有后续兄弟，决定画哪几条竖线。
     - `style: RowTextStyle { bold, italic, color: Option<Rgba>, size: Option<u16> }`：从节点 `StyleOverride` 解析后的文字样式。
     - `labels: Vec<String>`：供 O06 的 chip 使用；空标签时 Vec 为空，不额外分配。
   - 在 `rebuild` 的展平过程中顺带算出 `last` / `guide_mask`，不增加第二遍树遍历。
   - `row_font()` 改为 `row_text_style(depth, density, style)`；字号仍受密度和 O07 缩放影响。

2. **层级线**
   - 不再对 `0..row.depth` 每一层画通高竖线；按 `guide_mask` 只画仍有后续兄弟的祖先层。
   - 当前行画一条肘线：从最后一条竖线弯到项目符号；`last` 为真时不向下延伸。
   - 当前选中分支的线用强调色 35%，其它用 `border` 60%；深层级线透明度递减。
   - 折叠行在项目符号右侧保留子节点数小 chip；不再贴最右缘，跟文字尾部保持 8px。

3. **选中 / 悬停 / 焦点**
   - hover：`panel2` 圆角 8，90ms 淡入。
   - 选中：`accent` 10% 混 `panel` 填充 + 1px `accent` 35% 内描边；文字用正文色；项目符号、折叠箭头用强调色。
   - 键盘焦点：在选中样式外再加 2px 焦点环；鼠标点击不显示焦点环，Tab / 方向键进入时显示。
   - 删除左侧 2px 实心强调条；不再整行把文字染成强调色。

4. **文字层级与节点样式**
   - 根：18px / 600；一级：15px / 500；二级及更深：14px / 400。
   - 应用节点 `bold` / `italic` / `text_color` / `font_size`；`font_size` 只在 12–28 之间生效，避免极端值把行撑坏。
   - 节点 `fill` / `stroke` 不在大纲里画；大纲只表达结构与文字，避免变成第二张画布。
   - 空标题显示「未命名」，用 `faint`；不显示成空白行。

5. **密度与列宽**
   - 新增 `OutlineDensity { Compact, Standard, Comfortable }`，行高 32 / 40 / 48，缩进 22 / 26 / 30，字号各降/升 1px。
   - `COL_MAX` 920 → 1040；左右最小 32；页头、正文、页脚共用 `column_margin()`。
   - 列内不做纸张卡片、不叠第二层圆角；用整屏平面 + 页头/页脚框住，避免「卡片里再套卡片」。

6. **长文处理**
   - 单行标题按可用宽度 layout 后省略；被省略时 hover 出全量 tooltip（复用现有 `Area` tooltip 模式）。

7. **标记重新排布（仅视觉，不改语义）**

## 5. O02 · 页头、页脚与视图控制

### 目标

页头是控制台，不是一行字；页脚是状态，不是静态说明书。默认界面把纵向空间还给正文。

### 具体改动

1. **页头（56px）**

   - 右：28px 工具按钮，命中 32px：
     - 搜索（Ctrl+F）
     - 折叠菜单（展开全部 / 折叠全部 / 只显示 1 / 2 / 3 级）
     - 密度菜单（紧凑 / 标准 / 宽松）
     - 聚焦（有选中时可用；聚焦态变成「退出聚焦」）
     - 画布切换（`大纲 | 画布` 分段控件或单图标，F8）
     - `…`（导出、快捷键、文档信息）
   - 窄窗（< 980px）时把搜索以外的低频按钮收进 `…`；分段控件退化为图标，保证不换行、不重叠。

2. **条件搜索行**

5. **页脚（28px）**

   - 右：上下文提示，按状态切换：
     - 普通：`Enter 同级 · Tab 缩进 · ? 帮助`
     - 编辑：`Enter 提交并新建 · Esc 取消 · Shift+Enter 换行`

   - 右侧 `?` 打开帮助表。

6. **快捷键帮助表**
   - 全屏浮层或大尺寸 `egui::Window`，三列：导航 / 编辑 / 结构；每行「键位 + 一句话」。
   - 支持 F1 / `?` 打开，Esc 关闭；搜索框可过滤键位（可选，若成本高先做静态三列）。
   - 复用 `panels/help.rs` 的视觉语言，不新建一套弹窗样式。

7. **响应式**
   - 页头在 840 / 980 / 1200 三个断点做收纳；正文列宽随窗口收缩，最小左右 32。
   - 页脚提示在窄窗只保留最关键的 2 条，不换行、不裁字。

## 6. O03 · 行内编辑 2.0：打字即编辑，回车即下一行

### 目标

编辑不再是一个「白底输入框」；它就是行本身。Enter 应该长出新行，拆分/合并应该像文本编辑器，撤销应该一步到位。

### 具体改动

1. **编辑会话**
   - `Edit` 扩展为 `EditSession`：
     ```rust
     struct EditSession {
         id: String,
         draft: String,
         original: String,
         just_started: bool,
         select_all: bool,
         caret_hint: Option<usize>,
     }
     ```
   - 编辑器仍用 `egui::TextEdit::singleline`（O08 换成 multiline），但：
     - `frame(Frame::NONE)`，透明背景；
     - 字体、颜色与行完全一致；
     - 行底保留选中态，底部画 2px 强调色下划线（编辑中唯一的高亮）；
     - 不再画白底 + 1px 边框。
   - 编辑中隐藏行尾图标，避免误点；左侧 `＋/⋮` 也隐藏。

2. **进入编辑**
   - F2：进入编辑并全选（重命名最快路径）。
   - 双击：进入编辑，尽量把光标放到双击位置；取不到字符索引时全选。
   - **type-to-edit**：行有键盘焦点、非编辑态时，输入一个可打印字符（不含 Space、不含 Ctrl/Alt 组合）→ 进入编辑，原文字被该字符替换。事件必须被消费，不能既进编辑又插入两遍。
   - 中文输入法：收到 `Event::Composition` / `Ime` 预编辑时进入编辑，draft 从空开始；组合期间不拦截 Enter/Tab。
   - Space 仍保留为折叠/展开，不触发 type-to-edit，避免和浏览冲突。

3. **编辑中的键**
   | 键 | 行为 |
   | --- | --- |
   | Enter（光标在末尾） | 提交当前文字，在下方新建同级，并立即进入新行编辑 |
   | Enter（光标在中间） | 拆分：光标前留在当前节点，光标后成为新同级；`Command::Batch { SetText, AddNode }` 一次撤销 |
   | Ctrl+Enter | 提交并在当前节点下新建第一个子级；光标在中间时，后半段成为子级文字 |
   | Tab / Shift+Tab | 提交，然后缩进 / 升级（沿用现有 deferred 逻辑） |
   | Esc | 取消本次编辑，文字恢复原值，焦点回到行；再按 Esc 才退出聚焦/大纲 |
   | ↑ / ↓ | 光标在首行/末行时提交，并把焦点移到上/下一可见行 |
   | 失焦 | 提交（点击其它行、切换视图、窗口失焦都提交） |
   | Shift+Enter | O08 起：插入软换行；O08 之前不响应，避免造出显示不了的多行 |

4. **Backspace 与合并**
   - 空行按 Backspace / Delete：删除该节点，焦点落到上一可见行（没有上一行则下一行 / 父级）。
   - 光标在文字开头按 Backspace：
     - 有上一同级兄弟：把当前文字并入上一兄弟末尾，删除当前节点；`Batch { SetText, DeleteNodes }` 一次撤销；光标落在拼接处。
     - 没有上一同级兄弟：不做结构变更，避免误把节点并到别的分支。
   - 光标在文字中间/末尾：交给 TextEdit 正常删字符，不做结构操作。

5. **焦点与 IME**
   - 提交后必须把焦点抢回当前行，不能落到搜索框（现有 [outline.rs:1144](../crates/mw-shell/src/panels/outline.rs#L1144) 已处理，继续保留并加测试）。
   - 组合输入期间（有预编辑串）不消费 Enter/Tab/Esc；用 `Ime` 事件状态判定，并写 trace 便于验收。
   - 编辑框宽度跟文字可用宽度一致；长文编辑时横向滚动而不是把行撑破。
   - 双击 / 点击进入编辑时光标位置尽量准确；做不到时全选不阻塞。

6. **撤销语义**
   - 拆分、合并必须一条撤销；新建行先落空节点、提交文字是第二条命令，撤销顺序是「先撤文字，再撤空行」，符合直觉。
   - 若验收发现连续新建后撤销体验断裂，再在 O03 内引入延迟创建或撤销合并（不改文档格式）。
   - Ctrl+Z / Ctrl+Y 在编辑中交给 TextEdit 的本地撤销；提交后走文档撤销。

7. **空行与占位**
   - 新建后立即进入编辑，行内显示光标，不显示「未命名」占位，避免和新行冲突。
   - 提交空文字仍保留节点（与现在一致），画布显示「未命名」；如果用户在新行直接 Esc，节点保留为空行，不自动删除，避免误删刚按出来的结构。

### 改动范围

| 文件 | 改动 |
| --- | --- |
| `crates/mw-shell/src/panels/outline.rs` | `Edit` → `EditSession`；输入分派；编辑绘制；新 `Action` |
| `crates/mw-shell/src/app_methods_2.rs` | `apply_outline_action` 增加 Split / Merge / AddSiblingWithText 等映射 |
| `crates/mw-core/src/command.rs` | 不需要新命令；拆分/合并用 `Batch` 组合现有命令 |

### 验收

- 单测：Enter 末尾新建同级；Enter 中间拆分（文字与顺序正确）；Ctrl+Enter 子级；Tab/Shift+Tab 提交后缩进；Esc 取消恢复原文；失焦提交；Backspace 合并上一兄弟；空行删除后的焦点。
- 撤销：拆分/合并一次 Ctrl+Z 完全复原；新建行两步撤销顺序正确。
- 焦点：提交后连续按 Enter 能一直长出新行；按 Tab 不会跳到搜索框/按钮。
- IME：中文组合输入时按 Enter 选词不提交行；组合结束后 Enter 正常提交（真机 + trace）。
- golden：`outline-edit`，编辑器无白框、下划线可见、文字不位移。
- 性能：编辑输入不触发整树重建；每次按键只重绘，不做 O(n) 扫描。

### 不做

- 多行 / 软换行（O08）。
- 富文本、行内链接、图片粘贴。
- 结构树以外的 Markdown 快捷输入（如 `# ` 变标题）。

## 7. O04 · 多选、拖拽与批量结构操作

### 目标

像编辑器一样选，像编辑器一样拖。多选不是「能选多行」，而是「选多行之后能一次改完」。

### 具体改动

1. **选择模型**
   - `Outline` 增加 `selection_anchor: Option<String>`；点击行时记录锚点。
   - 新增 `Action::SetSelection(Vec<String>)`；`apply_outline_action` 调 `Canvas::select_many(&ids)`（新增 shell 方法，底层复用 `select_node` / `toggle_select_node` 的选中集合）。
   - Shift+点击：从锚点到目标行的可见区间全选（替换当前选择）。
   - Ctrl+点击：toggle；Ctrl+Shift+点击：把区间并入当前选择。
   - Shift+↑/↓：从锚点向上/下扩展一行；Ctrl+Shift+Home/End（可选）：扩到首/末。
   - Ctrl+A：选中当前聚焦范围内的全部可见行；再按一次全选整棵树？不引入二段式，固定为「当前可见范围」。
   - Esc：编辑/搜索都不在时，把多选收敛为当前主选中行，不直接退出大纲。

2. **多选视觉**
   - 主选中行：O01 的选中样式 + 1px 强调色描边。
   - 其它选中行：更淡的强调色底，无描边。
   - 页脚显示「已选 N 项」；拖拽时 ghost 显示数量。
   - 选中集合变化不滚动、不重建行缓存。

3. **批量结构操作**
   - 先对选中集合去重：若某节点与其祖先同时选中，结构操作只保留祖先（避免把子树拆两次）；任务/标签类操作则作用于全部选中节点。
   - 所有批量操作走 `Command::Batch`，一次撤销：
     - 删除：`DeleteNodes { ids }`；删完焦点落到删除区之后的第一个可见行。
     - 缩进：从下往上处理，每个选中节点挂到其上一个兄弟下；没有上一个兄弟的节点跳过。
     - 升级：从上往下处理，每个节点挂到其父的父下、父的 index+1；根的子节点跳过。
     - 上/下移：按方向从边缘向内处理，避免 index 互相踩踏。
     - 任务 / 标签：批量 `SetTask` / `AddLabel` / `RemoveLabel`。
   - 若批量移动的 index 语义在 `Batch` 里无法保证顺序，再在 mw-core 增加一个 `MoveNodes { ids, new_parent, index }`；只加这一条命令，不碰 theme / instances。

4. **剪贴板**
   - 复用画布已有的 `copy_action / cut_action / paste_action / duplicate_selected`（[canvas_methods_1.rs:873](../crates/mw-shell/src/canvas/canvas_methods_1.rs#L873)）。
   - Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D；粘贴默认成为当前主选中行的子级；Ctrl+Shift+V 粘贴到根末尾。
   - 大纲选中集合先同步到画布选中，再调用画布剪贴板，避免两套选中模型。
   - 内部剪贴板保留子树；同时写入缩进纯文本，方便粘到外部应用；从纯文本粘贴时按 Tab/空格缩进解析成树（解析失败则作为单节点文字）。
   - 剪切 = 复制 + 删除，必须一条撤销（画布已有 `cut_wins_over_copy_because_cut_is_copy_plus_delete` 测试，沿用）。

5. **拖拽**
   - 把手：行左侧 14px 握把，hover / 选中时出现；整行仍可拖，但移动超过 4px 才算 drag，避免误触。
   - ghost：半透明行卡（标题 + 数量），跟随指针；多选拖拽显示「3 项」。
   - 落点：
     - 行上 30%：插到该行之前；行下 30%：之后；中间 40%：成为子级。
     - 插入线 2px 强调色，左端 6px 圆点落在目标缩进位置；子级落点用整行圆角描边。
     - 横向移动改变层级：指针 x 落在哪个缩进档，就预览哪一级的父级；松手按预览层级插入。
     - 折叠目标悬停 600ms 自动展开；拖到面板上下缘自动滚，速度从 4px/帧加速到 18px/帧。
     - 拖到列表下方空白：追加为根的最后子级；拖到自由主题/根自身：拒绝。
     - 禁止拖进自身或后代（沿用 `is_self_or_descendant`）。
   - 多选拖拽：拖任一选中行即拖整组；保持相对顺序；落点若在选中集合内部，忽略。

6. **悬停操作**
   - 项目符号左侧 hover 出现 `＋`（添加子级）与 `⋮`（菜单）；`＋` 命中 24×24。
   - `⋮` 菜单：在上方插入、在下方插入、添加子级、复制、剪切、粘贴、删除、聚焦。O06 再补任务/标签/备注/卡片入口。
   - 菜单支持键盘：Shift+F10 或菜单键打开；↑↓ 选择，Enter 执行，Esc 关闭。

### 改动范围

| 文件 | 改动 |
| --- | --- |
| `crates/mw-shell/src/panels/outline.rs` | 选择锚点、区间选择、拖拽 ghost/落点、hover 控件、批量 Action |
| `crates/mw-shell/src/app_methods_2.rs` | 新 Action → Command 映射；批量顺序处理 |
| `crates/mw-shell/src/canvas/canvas_methods_1.rs` | 新增 `select_many`；复用剪贴板 |
| `crates/mw-core/src/command.rs` | 仅在必要时增加 `MoveNodes`；优先用 `Batch` |

### 验收

- 单测：Shift 区间、Ctrl toggle、Shift+↑/↓ 扩展、Ctrl+A、Esc 收敛。
- 批量：缩进/升级/上移/下移在混合层级上的顺序与 index 正确；一次撤销整体回滚；删除后的焦点位置正确。
- 剪贴板：复制子树 → 粘到另一节点；剪切 → 一次撤销恢复；纯文本粘贴解析缩进；空剪贴板不产生空命令。
- 拖拽：before / after / child 三区；横向改层级；多选拖拽顺序；拖进自身/后代被拒；折叠目标自动展开；自动滚速度有上限。
- golden：`outline-multi`、`outline-drag`（插入线 + ghost + 子级描边）。
- 真机：200% 缩放下把手和 `＋` 仍可点中。

### 不做

- 跨文档拖拽。
- 触屏长按选择。
- 自由主题在大纲里的特殊拖拽（仍按现有规则显示/隐藏）。

## 8. O05 · 查找、筛选与定位 2.0

### 目标

找得到、看得见上下文、不把折叠状态搞乱。搜索不是「把不匹配的行藏掉」，而是「在树里定位」。

### 具体改动

1. **搜索入口**
   - Ctrl+F / 页头搜索按钮 → 展开 O02 的 40px 搜索行。
   - 左侧放大镜，右侧「当前 / 总数」、上一个、下一个、关闭。
   - 输入即时筛选（沿用现有防抖/缓存思路），但不再常驻。
   - Enter / Shift+Enter：下一个 / 上一个命中；到末尾回绕。
   - 命中行滚动到视口中央并 240ms 高亮脉冲；`reduce_motion` 直接落位。
   - 选择跟随命中行，但不自动进入编辑。

2. **全树搜索**
   - 搜索模式遍历整棵树，**忽略 `collapsed`**；不再复用只包含可见行的 `rows`。
   - 命中行保留；从根到命中行的祖先作为上下文行一起显示，上下文行 55% 透明度、仍可点击/编辑。
   - 搜索只改 `visible` 缓存，不改文档的 `collapsed`；清空搜索后折叠状态原样恢复。
   - 上下文行不参与「命中数」统计；页脚显示「3 / 17 命中」。
   - 搜索期间结构折叠按钮仍可用，但不影响搜索遍历。

3. **命中高亮**
   - 命中子串用强调色 18% 背景 + 正文色；多次命中全部高亮。
   - 行文字仍单行省略；被省略的命中段通过滚动/ tooltip 补足（O08 多行后可完整显示）。
   - 高亮与 O01 的节点文字样式叠加，不覆盖 `bold` / `italic` / `text_color`。

4. **筛选 chips**
   - 搜索行下方（有筛选时）出现 32px chips 行：
     - 全部 / 待办 / 进行中 / 已完成
     - 有备注 / 有卡片
     - 标签：下拉选标签，支持多选；显示 `#标签` chip
   - 文本与 chips 是 AND 关系；同一类多选是 OR（例如待办+进行中）。
   - 点击行内标签 chip（O06）直接激活对应标签筛选，并打开搜索行。

   - 当前筛选条件进入 `filter_key`，只有条件变化才重扫；滚动帧不重新计算。

5. **Esc 顺序**
   - 搜索框有焦点：
     1. 有文字 → 清文字，保留搜索行和焦点；
     2. 无文字但有 chips → 清 chips；
     3. 都没有 → 关闭搜索行，焦点回当前行。
   - 行焦点：有聚焦 → 退出聚焦；无聚焦 → 退出大纲（沿用现有 `esc_step` 语义）。

6. **空状态**
   - 无命中：保留现有放大镜插画，但文案改成「没有找到「xxx」」+「清除筛选」可点击；不要只给一句静态提示。

## 9. O06 · 行的语义：任务、标签、备注与卡片

### 目标

任务、标签、备注、卡片是行的一部分，不是三个点和一句 `#n`。用户应该在不打开检查器的情况下读懂一行。

### 具体改动

1. **任务框左置**
   - 有 `TaskState` 时，项目符号位置改为 16×16 任务框；折叠箭头仍在它左边。
   - 单击循环：待办 → 进行中 → 完成 → 取消（沿用 `next_task`）。
   - 待办：1.2px 描边空框。
   - 进行中：强调色描边 + 中心小圆点，文字不变；tooltip「进行中」。
   - 完成：强调色填充 + 对勾；标题 55% 透明度 + 删除线；子节点不自动完成。
   - 右键 / `⋮` 菜单可直接选四态，不必循环。
   - 行尾旧任务方框删除；`Ctrl+T` 仍循环。

2. **标签 chips**
   - 标题后显示标签 chip：高 18、圆角 9、11px、`panel2` 底；最多 2 个，其余 `+n`，tooltip 列出全部。
   - 颜色由标签文本 hash 到主题分支色板，保证暗色/亮色都有对比度；同一标签全文颜色一致。
   - 点击 chip：激活该标签筛选（O05），打开搜索行。
   - `⋮` 菜单 →「标签」：列出已有标签可勾选，也可输入新标签；走 `AddLabel / RemoveLabel`。
   - 编辑中在行尾输入 `#` 触发标签补全浮层（↑↓ / Enter / Esc）；`#` 后面允许中文、字母、数字、下划线、连字符，空格结束。
   - 标签不写入正文，仍是 `Node.labels`。

3. **备注**
   - 有非空备注时，标题后显示 14px 便签图标；hover 出预览浮层：
     - 前 3 行纯文本（去掉 Markdown 标记，保留换行）；
     - 底部「打开备注」；点击图标或按钮 → 画布选中节点、切到检查器备注页并聚焦（沿用现有 `OpenNote`）。
   - 没有备注时不显示图标，不占位。
   - 预览浮层用 `Order::Tooltip`，不阻挡行点击；鼠标移入浮层可点击「打开备注」（需要可交互 tooltip，注意延迟关闭）。

4. **卡片**
   - 有卡片时显示 14px 卡片图标；hover 预览：卡片标题 + 最后修改时间 + 前两行摘要；点击打开阅读页（沿用 `OpenCard`）。
   - 卡片图标与备注图标视觉区分：便签 vs 页面；颜色分别用分支色/强调色。
   - 无卡片时不显示。

5. **链接 / 图标**
   - `Node.link` 存在时显示链接图标，点击用系统默认浏览器打开；hover 显示 URL。
   - `SetIcon` 的图标（优先级/星标等）在标题前显示 12px 字形或自绘符号；不在大纲里加载图片。
   - 图片节点只显示图片图标，不显示缩略图，避免行高失控。

6. **行尾布局**
   - 行内语义（任务、标签、图标）在文字后；右缘只留备注/卡片/链接三个 18px 槽位。
   - 所有槽位固定宽度；hover 不改变文字宽度。
   - 折叠计数 chip 与右缘槽位之间留 8px，长标题不会压住任何图标。
   - 标签过多时 `+n` 不换行；窄窗下最多 1 个 chip + `+n`。

| 文件 | 改动 |
| --- | --- |
| `crates/mw-shell/src/panels/outline.rs` | `Row.labels/link`、绘制、命中、预览浮层、标签补全 |

## 10. O07 · 专注、模式切换与导出

### 目标

聚焦、画布、导出是同一套动作：不丢选择、不丢滚动位置、不丢上下文。大纲不是画布的「另一个页面」，而是同一份文档的另一种看法。

### 具体改动

1. **聚焦**
   - 入口：`Alt+Enter`（现有）/ `Ctrl+;`（XMind 只显示分支）。
   - 聚焦态：只显示该节点及后代；页头面包屑可点祖先；页脚左侧显示「聚焦 N / 全图 M」；右侧「退出聚焦」。
   - 聚焦根不能上移/下移/升级（现有约束保留）；删除聚焦根时退回父级（现有行为保留）。
   - Esc：先退出聚焦，再退出大纲。
   - 每个文档记住聚焦根；重新进入大纲时恢复，除非该节点已不存在。
   - 聚焦根本身不画折叠箭头；它的子节点从 0 级缩进开始。

2. **大纲 ↔ 画布**
   - 页头分段控件 + F8；切换时：
     - 大纲 → 画布：画布视口居中到当前主选中节点；若没有选中，居中到聚焦根/根。
     - 画布 → 大纲：大纲滚动到当前主选中行并选中；若当前行被折叠，展开其祖先。
   - 切换保留：搜索词、筛选 chips、聚焦根、密度、缩放、滚动锚点。
   - 切换前提交编辑（或取消？规则：提交，和点击其它行一致），避免丢字。
   - 每文档一份 `OutlineMemory`：
     ```rust
     struct OutlineMemory {
         filter: String,
         chips: FilterChips,
         focus: Option<String>,
         scroll_anchor: Option<String>,
         density: OutlineDensity,
         zoom: f32,
     }
     ```
     以文档 id/路径为键存在 Shell 会话内；密度/缩放另存全局设置，跨会话恢复。

3. **缩放**
   - `Ctrl+=` / `Ctrl+-`：80%–150%，步长 10%；`Ctrl+0` 回到 100%。
   - 缩放同时作用于字号、行高、缩进、图标槽；列宽按比例但不小于 640。
   - 页头显示「110%」小 pill（仅非 100% 时）；点击可重置。
   - 缩放与密度相乘；两者都变时以 O08 的可变高度引擎计算，避免行高抖动。
   - 125% / 150% 缩放下不允许文字被裁切；长标题优先省略，不撑破列宽。

4. **导出**
   - 页头 `…` →「导出大纲」子菜单：
     - Markdown（`- ` 缩进列表；任务输出 `- [ ]` / `- [x]`；标签输出 `#tag`）
     - OPML 2.0（`<outline text="...">`，保留层级；任务/标签放 `_note` 或自定义属性）
     - 纯文本（Tab 缩进）
   - 默认导出全部；聚焦态提供「只导出当前分支」选项。
   - 导出走现有文件对话框与原子写入；测试用临时目录，不碰真实笔记库。
   - 导出成功 toast「已导出 Markdown」；失败给可读错误，不吞掉。
   - 暂不做大纲 PDF；画布 PDF 已存在，避免两套 PDF 排版。

5. **状态与快捷键一致性**
   - 页头按钮、菜单、快捷键、帮助表使用同一套名称（「聚焦」不叫「只显示分支」又叫「专注」）。
   - F8 切换画布、Esc 退出、Ctrl+F 搜索在所有视图一致。
   - 大纲关闭再打开，恢复滚动锚点而不是跳回顶部。

### 改动范围

| 文件 | 改动 |
| --- | --- |
| `crates/mw-shell/src/panels/outline.rs` | `OutlineMemory`、聚焦/滚动锚点、缩放 |
| `crates/mw-shell/src/app_methods_2.rs` | 页头模式切换、导出菜单、切换时居中/展开 |
| `crates/mw-shell/src/main.rs` | Shell 持有 per-doc Outline 状态 |
| `crates/mw-shell/src/export_*.rs` | Markdown / OPML / 纯文本导出 |

### 验收

- 单测：聚焦进入/退出/删除聚焦根；重进大纲恢复聚焦；每文档状态互不串；缩放 clamp 与重置；模式切换后选中不丢。
- 导出：Markdown/OPML 快照测试；任务、标签、空标题、深层嵌套；聚焦分支导出只含子树。
- golden：`outline-focus`、`outline-zoom150`。
- 真机：切换画布后视口确实居中到选中节点；再切回大纲行在视口内。

### 不做

- XMind 文件导入/导出（后续单独做）。
- 大纲 PDF。
- 多窗口并排大纲 + 画布（仍是全屏二选一）。

## 11. O08 · 丝滑度、排版引擎与最终验收

### 目标

20k 节点仍然顺；动画只做反馈、不挡手；任何 DPI / IME / 多屏都不破。O08 不是「最后跑一遍测试」，而是把 O01–O07 的表现收进一个真正的虚拟列表与布局缓存。

### 具体改动

1. **真虚拟列表**
   - 替换当前「遍历 `self.visible` 全量 `allocate_space`」的循环。
   - 视口驱动：只对可见行 `allocate_space` / `interact` / 绘制；视口外用高度占位。
   - 高度表：
     - 固定密度时行高一致，可直接用前缀和 + 二分。
     - 多行/缩放时用「测量高度 + 估算高度」：可见行实测，未测量行按字符数/可用宽度估算；滚动到附近时修正。
     - 文档 revision 变化时保留 `anchor_id + offset`，避免新增/删除导致视口跳。
   - 滚动条位置按前缀高度算；不要求 1px 精确，但拖动滚动条不能出现大幅跳动。
   - 键盘 `scroll_to_me` 只对目标行布局，不触发整表测量。

2. **多行与软换行**
   - 编辑框改 `TextEdit::multiline`；`Shift+Enter` 插入 `\n`。
   - 行高 = 行内边距 + 行数 × 行高；最多 6 行，超出后行内滚动或省略？选择：最多 6 行，超出用 tooltip 显示全文；编辑时编辑框内部滚动。
   - 折行宽度 = 列宽 - 缩进 - 左槽 - 右槽；中文按字断行，英文按词断行，长 URL 强制断行。
   - 行尾图标与折叠 chip 在多行行里垂直居中到第一行，不跟着最后一行跑。
   - 多行行仍支持整行选中、拖拽、任务框、标签。
   - O03 的 Enter 分叉在多行文本里按「当前段」拆分：光标前的整段留在当前节点，光标后的内容成为新节点；具体规则在实现时用 `text[..caret]` / `text[caret..]`，测试覆盖中英文。

3. **文本布局缓存**
   - 缓存键：`(text_hash, avail_width, font_size, bold, italic, color, zoom, ppp, theme_id)`。
   - 每帧复用 `Galley`，测量与绘制共用同一份布局；不在绘制时二次 layout。
   - LRU 上限（例如 4096 条），主题/字体/缩放变化时整体失效；不缓存整棵树。
   - 命中高亮用 `LayoutJob` 的 `TextFormat.background`，不重新拆字符串。

4. **动效**
   - hover 90ms、选中 120ms、折叠箭头旋转 160ms、新行淡入 160ms、拖拽 ghost 跟手（无额外缓动）、插入线 80ms 淡入、搜索命中 240ms 脉冲。
   - 不做行高动画（会引起滚动抖动）；折叠只动箭头和子行淡入，不做高度展开动画。
   - `reduce_motion` / harness / golden 下全部直接落位；不在截图里留下半透明中间态。
   - 动画只影响绘制，不影响命中矩形与键盘焦点。

5. **滚动与拖拽**
   - 新增/删除/筛选后保持锚点：视口第一行 id 不变，除非该行被删。
   - 搜索/聚焦定位用 120ms 缓动；`reduce_motion` 直接跳。
   - 拖拽自动滚：边缘 48px 触发，速度线性加速，最大 18px/帧；松手立即停。
   - 折叠目标 600ms 自动展开；展开后落点重新计算。
   - 滚轮滚动不重建行、不重排文本；只移动视口。

6. **IME × DPI × 多屏**
   - 编辑框、光标、选区、下划线全部按 ppp 缩放；125% / 150% / 200% 下不偏位。
   - 组合输入浮层不被滚动区裁剪；跨屏拖动窗口后 ppp 变化，重新计算行高与光标，不丢预编辑串。
   - 真机矩阵：100 / 125 / 150 / 200%，单屏 + 双屏（不同 DPI），中文输入法（微软拼音）。
   - trace 记录：`outline_edit_start`、`outline_commit`、`outline_ime_*`、`outline_scroll_anchor`、`outline_virtual_range`，便于失败复现。

7. **性能预算与测试**
   - 目标（release，同一台机器，记录实测而不是口头承诺）：
     - 20k 节点重建 ≤ 8ms；
     - 20k 节点筛选 ≤ 12ms；
     - 稳定滚动帧 CPU ≤ 4ms；
     - 编辑按键到重绘 ≤ 2ms；
     - 首屏只布局可见行，不为 20k 行创建 rect。
   - 扩展现有 `twenty_thousand_rows_rebuild_once_and_filter_once`（[outline.rs:2258](../crates/mw-shell/src/panels/outline.rs#L2258)）为：
     - 重建 / 筛选 / 可见区计算 / 布局缓存命中；

```
O01 视觉基座
 ├── O02 页头页脚 ── O05 查找筛选 ──┐
 ├── O03 行内编辑 ── O04 多选拖拽 ──┼── O06 行内语义 ── O07 专注/模式/导出
```

- **必须串行**：O01 → O03 → O04（同一份行绘制/输入逻辑）；O02 → O05（搜索行入口）。
- **可以并行**：O02 与 O03 文件重叠少，可分两班；O05 与 O04 可并行，但都要改 `ensure_visible` / `visible`，需先约定接口。
- **O06 依赖 O03 的编辑器**（`#` 补全）和 O05 的 chips；先做 O05 再做 O06 的筛选联动。

### O03 · 行内编辑 2.0（2026-10-21 完成）

**落地内容**

- `EditSession { id, draft, original, just_started, select_all, caret_hint, composing }`。编辑态就是行本身：`TextEdit` 同字体、同字号、同正文色、无边框无白底，2px 强调色下划线只跟文字宽度（最短 40）；任务框、备注/卡片点、标签计数、折叠 chip 在编辑行全部隐身，行尾不给角标留位。
- 三种入口都在正文绘制**之前**判定，同一帧立起 TextEdit，输入法第一帧预编辑不会丢：
  - F2：进入编辑并全选（`CCursorRange::select_all_str`）；
  - 双击：`caret_at_pointer` 按指针落点排版一次，光标落在字与字之间（实测双击「织思」中段 → caret=1）；
  - type-to-edit：可打印且不是 Space 的 `Text` 直接替换原文；IME `Preedit` 先开空编辑框，交给 TextEdit 接管组合串。
- 结构键全部 `matches_exact`，不用 egui 的「忽略多余 Shift」：
  - 末尾 Enter：提交 + 新建同级 + 就编辑新行；中间 Enter：`Batch { SetText(head), AddNode(tail) }` 拆分，一次撤销；
  - Ctrl+Enter：中间拆出的后半成为**子级**；根行/聚焦根的回车落成子级，不把新行甩出视野；
  - Tab / Shift+Tab：先提交再缩进/升级；Esc 撤回草稿保留原文；↑/↓ 提交并把焦点交给相邻行；失焦即提交；
  - Shift+Enter 在 O08 之前吃掉（`outline_edit_soft_break_ignored`），不提交、不换行；
  - 组合态（`composing`）与 IME 确认帧把 Enter/Tab/Esc/方向键/退格从事件队列里**吃掉**，不让 TextEdit 拿去当提交/失焦——预编辑串不会被提前落盘。
- Backspace：空行删除并把焦点交回上一可见行；光标在 0 且有上一同级时并入上一行——`Batch { SetText(prev, prev+text), MoveNode(children), DeleteNodes }`，一次撤销，光标落在拼接处，子节点不丢；其余情况走原生删字。
- 编辑中 Ctrl+Z/Y 是 TextEdit 本地撤销（新行启动时 `clear_undoer`，不会回放上一行）；提交后 Ctrl+Z 回到文档历史。
- 焦点连续性：`begin_edit_at` 先清掉排队的行焦点请求（否则下一帧会把 TextEdit 的光标抢走）；键盘提交/取消后把焦点钉回行；点击可见行不再强制 `reveal` 居中（否则双击两下会落到相邻行）；Outdent 与大纲内撤销后重新钉焦点。
- 新增**金样输入脚本**（`MW_GOLDEN_INPUT`）：在 `eframe::App::raw_input_hook` 里按帧注入键、文字、IME Preedit/Commit、指针点击/双击，脚本一行动作一帧（`key` 按下/松开各一帧）。验收不再用 SendKeys 抢前台，键永不落到别的应用，输入法状态也不影响结果。
