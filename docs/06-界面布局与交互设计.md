## 1. 设计原则

1. **画布是主角**：一切面板可收起，画布最大化；面板默认只开"大纲"。
2. **直接操纵**：能拖拽的不做按钮，能右键的不藏菜单；每个操作点得到即时视觉反馈。
3. **永不丢内容**：删除可撤销、关闭有确认、自动保存静默兜底；破坏性操作二次确认但≤1 次。
4. **克制动效**：动效用于解释因果（节点从父节点"长出"），不用于炫技；系统"减少动画"全局尊重。
5. **键盘优先**：高级用户全程不碰鼠标可完成 02 全部功能。

### 2.1 从实拍提炼的硬结论

| 项 | XMind 2026 的做法 | 旧实现（我们此前） |
| --- | --- | --- |
| 画布背景 | 纯色近白，**没有点阵**；暗色主题是纯深灰 | 点阵 24px，处处可见 |
| 中心主题 | 白底、1.5px 浅灰描边、黑字加粗、圆角矩形 | 蓝底胶囊、白字 |
| 一级主题 | **实色马卡龙填充**（薄荷/珊瑚/蜜桃/草绿），无描边，黑字**常规** | 白底 + 彩色细描边（廉价感的主因） |
| 次级主题 | 白色卡片或纯文字，轻描边；字号明显小于一级 | 与一级几乎同字号 |
| 连接线 | 按分支取色、约 2px、S 形三次曲线、端头干净 | 细线 + 彩色描边盒，线被盒子抢掉 |

| 顶栏 | 一整条极简顶栏：左汉堡/主页/标题，中悬浮胶囊工具栏，右系统按钮 | 40px 文本标题栏 + 无工具栏 |
| 工具栏 | 白色悬浮胶囊、轻阴影、图标线性；按选择态点亮 | 无 |
| 层级 | 标题与画布之间没有第二行菜单；一切从简 | 文档曾画过三行 chrome（早于实现） |

### 2.3 暗色

暗色沿用同一几何与层级规则：画布 `#17191F`，面板 `#1C1F26`，一级填充改为深色系（如 `#2E3A57`、`#4A3A2A`），文字提亮。暗色不通过“把亮色整体调暗”实现，需单独校验对比度。

### 3.1 顶栏与工具栏（本轮实现口径）

- 顶栏底色纯白（不再依赖 Mica 透出，避免与白色画布出现色差）；底部 1px `#ECEDF0` 分隔线。
- 中央胶囊：40px 高、圆角 12px、白底、1px `#E7E9ED` 边框、向下 4px 柔和阴影；图标按钮 34×34、圆角 8px、悬停 `#F2F3F5`。
- 工具按钮与快捷键一一对应，**按钮只是快捷键的同源入口**：撤销 `Ctrl+Z`、重做 `Ctrl+Y`、加子主题 `Tab`、加同级 `Enter`、删除 `Del`、适应画布 `Home`。
- 禁用态：无可撤销/无选择/根节点不可删时按钮降到 35% 灰，不弹错误。
- 窄窗口（<820px）优先保留撤销/加子/适应，隐藏删除与同级；不换行、不溢出顶栏。
- 顶栏文档名宽度上限 240px，超出省略；悬停显示完整路径。

### 3.2 标签条与文件状态（X19 口径）

- **标签条**：仅在 ≥2 个标签时出现，位于标题栏下 34px；标签 28px 高、顶圆角 6、间距 2、左右内距 8；宽度 `clamp(文字宽 + 脏点 12 + 关闭 22 + 内距 16, 108, 220)`，超宽用字符级尾部省略。选中标签 `accent_soft` 底 + 2px `accent` 下划线（内缩 8），非活动悬停 `hover` 底；6px `warn` 脏点固定在文字左侧，关闭叉 14px 图标装在 22×22 命中格内；加号固定在标签条右端 28×28，不随横向滚动移走。
- **标签操作**：单击 / 焦点上 Enter、Space 激活；中键关闭；关闭叉关闭。脏标签关闭走三选弹窗（保存并关闭 / 不保存关闭 / 取消），非活动标签先在自己的会话上保存。横向拖拽超过 4px 进入重排，原标签淡出、指针处 60% `accent_soft` 幽灵、间隙画 2px `accent` 插入线，松手移动且激活文档跟随，Esc 取消，拖拽期间不触发单击激活。
- **右键菜单**：关闭（Ctrl+W）· 关闭其他 · —— · 复制文件路径 · 在资源管理器中显示；未落盘禁用复制与定位；菜单开着时画布与标签条都不收输入。
- **焦点**：标签体、关闭叉、加号都画 1.4px `accent` 焦点环；Tab 顺序为标签 1 → 关闭 1 → 标签 2 → 关闭 2 … → 加号。
- **保存状态**：六态 `Home / Untitled / Saving / Saved / Dirty / Failed`，标题芯片与状态栏同源。Ctrl+S 先显示「保存中…」一整帧，下一帧开头才写盘；成功记录写入那一刻的修订号，失败绑定失败修订且不改路径/恢复点/不关标签，继续编辑退回 Dirty。不做壁钟「已保存 HH:mm」渐隐，完成后用 toast「已保存 <文件名>」。
- **打开状态**：两段式加载，先画「正在打开…」模态（无按钮、不可 Esc、遮挡画布与菜单），至少完整一帧后才读盘；失败弹窗给文件名、完整路径、原因与「重试（主）/ 打开其他文件… / 从最近列表移除 / 关闭」，默认关闭，重试重走两段式；失败不替换当前文档、不关标签、不静默删除最近记录。

## 4. 关键面板

**大纲面板**：**全屏大纲已被 28 §5 取代**——行 = 节点（缩进树）、拖到行上 1/3=前、2/3=后、悬停 1s=成为子级这些旧交互全部作废，改按 28 §5 的 `Enter / Tab / Shift+Tab / Ctrl+Enter / Alt+.` 与 32px 行、24px 缩进、拖拽插入线执行。**侧栏大纲**仍按本文：与画布同源数据的另一投影视图，选中行与画布选中双向同步、点击定位。

**检查器**：分段"样式/备注/链接/标记"。样式区按 **填充 → 分支线 → 文字** 三行排列（v7）：每行 = 小标题 + "已覆盖"圆点（点击 ↺ 恢复继承）+ 主题色板 + 自定义取色；填充与文字可一键清除覆盖；**分支线**沿子树继承，改它等于换整条分支的色系（自身连线、子孙连线与二三级卡片淡染一起变）；文字行另有「文字样式应用到子树」复选（默认不勾）。色板为 17px 方色块内嵌 6px 圆点、间距 3px，自定义按钮 22px；文案 14px 左缩进与页签对齐。备注区多行编辑，Enter 换行、Ctrl+Enter 提交（失焦也提交）；链接区：输入 + 域名摘要（"打开"按钮已接线）。

## 7. 编辑态（节点文字编辑）——IME 关键设计

- **编辑器实现**（⚠️ 载体已改，精神仍有效）：~~画布上绝对定位的原生 DOM 输入元素（contenteditable）~~ → **已落地为：自绘画布纹理之上压一个标准文本控件（egui `TextEdit` 覆盖层），不自绘 caret**（M2a，13 §4.12）。原句「**禁止**用画布内绘制文本框的方式做编辑（会失去浏览器 IME 管线，07 §3）」**不约束现行方案**：那条禁的是"自己画 caret、自己算候选窗位置"，而覆盖层走 winit 的 `set_ime_cursor_area`——候选窗仍由系统输入法定位，管线没丢。「字体/颜色/内边距与渲染一致」改由**同一份 `Scene` + 同一套 DirectWrite 度量**保证（比旧版的 CSS 变量更硬），节点盒随输入实时增长。
- 进入编辑：编辑器按 `Camera` 把节点世界矩形换算到屏幕并覆盖其上，输入控件获焦点后光标即就位；候选窗由 winit 的 IME 管线定位；
- 退出编辑：失焦/Enter/Esc/选中他节点 → 提交或取消（02 §3），覆盖层卸载，自绘文字接管；
- 编辑期间画布锁定缩放（防候选窗错位），平移仍可用（编辑元素跟随节点移动）。**✅ 2026-10-17 已补全**：键盘 Ctrl± 与滚轮/pinch 两条路径都判编辑态（M2b-2，见 13 §4.13；`scripts/m2b2-canvas.ps1` 用「非编辑态同样滚轮必须真的放大」作对照，证明它是真锁住而不是滚轮没送到）。
- **「字体/颜色/内边距与渲染一致」是 2026-10-19 v4 才真正做到的**（13 §4.35）：覆盖层与画布走的是**两条不同的排版调用**（画布 `mw-render` DirectWrite 逐字形，编辑器 epaint `layout_job`），一致性靠把 `mw-core` 那一份几何喂给编辑器保证——字号 `n.geom.font_size × zoom`、字重跟随 `bold`、**行高显式写成 `字号 × 1.45`**（epaint 默认按雅黑自身 ≈1.17 em 排行，不锁住会让多行节点一进编辑态当场收紧）、首行基线由同一条排版路径**实测** `row.pos.y + glyph.pos.y`（拿到显式行高后 epaint 把字形行内居中并取整到设备像素，公式恒差 1 px）、内边距用 `PAD_X/PAD_Y × zoom` 挂 `Frame::inner_margin`、编辑态强调环画到节点盒**外侧**（合成器对该节点跳过自己的环）。验收：`scripts/v4-edit.ps1`（release、150% DPI、`snow`/`inkNight` 三行中文样例）量编辑态相对画布态的行位移，**明暗两套均 ≤0.73 px（亚 CSS 像素）**、行距 86 物理 px 与 `14 × 1.45 × zoom 1.5` 吻合，断言 `EDITOR_PARITY OK`。**仍未达成的一条**：caret 高度占满 1.45 em 行盒，比本文件 §7 想要的「贴着字高」明显偏长，改它需要覆盖 `TextEdit` 的 caret 几何，排在 v5。

| 搜索命中 | 350ms 呼吸外环 ×2 后常亮 | Ctrl+F 跳转 | ✅ 已实现（0.7s 两拍扩散后常亮，颜色取主题 accent，13 §4.26） |
| 演示步进 | 350ms / ease-out（居中+放大） | → | ✅ 已实现（13 §4.32）：中心线性插值、缩放走几何插值（更自然），连按从当前插值相机续接；`←` 反向同样 350ms；减少动画时直接终态 |

结构动效只在**两帧 `Scene`** 之间插值，命中、选择、编辑框从第一帧起就按目标场景算——不会出现"看着在 A、点得到 B"。编辑期间不启动新过渡，编辑器跟着插值盒走。

全部动效尊重系统"减少动画"设置与应用内开关（降级为 ≤80ms 的透明度过渡，保留因果可读性）。**现行实现**：读 `SPI_GETCLIENTAREAANIMATION`，关闭时面板直接终态、搜索环直接常亮（不再扩散）、场景插值直接落目标帧；golden harness 同样强制终态。应用内开关尚未提供。

## 9. 微交互细节清单

- 保存状态：Home / Untitled / Saving / Saved / Dirty / Failed 六态；标题芯片与状态栏同源，「保存中…」先画一帧、下一帧开头写盘，完成后 toast「已保存 <文件名>」，失败显示「保存失败」并可 Ctrl+S 重试；不做壁钟「已保存 HH:mm」渐隐（X19）；
- 打开状态：两段式加载，「正在打开…」模态无按钮且不可 Esc；失败弹窗默认「关闭」，可重试 / 打开其他文件 / 从最近列表移除（X19）；
- 拖拽落位的"吸附"感：目标区高亮时指针吸附延迟 60ms 再判定，防止边缘抖动；
- 删除整棵子树确认对话框显示子树节点计数（"将删除 12 个节点"）；
- 导出完成：**当前实现**是 toast 提示，无「打开所在文件夹」按钮；大导出走任务栏进度**未做**（导出在 UI 线程同步完成，超出 8192 边 / 32M 像素时自动缩回比例并提示）；
- 空搜索/无结果：行内提示"未找到，试试拼音首字母（如 xm）"；
- 未保存关闭标签：对话框三选（保存并关闭 / 不保存关闭 / 取消），默认焦点在取消；「不再提示」未实现；
- 首次启动：**已实现**（2026-10-18，13 §4.28）——默认落在开始页，顶部欢迎条三步（新建或打开 · 记住 Tab/Enter · 遇到问题 F1），可关闭；不是设计稿里的居中三步卡。
- 开始页空状态：**已实现**（2026-10-18，13 §4.28）——5 张模板卡片（思维导图/逻辑图/组织架构/鱼骨图/时间轴，矢量预览）+ 最近文件列表（最多 8 份，相对时间、父目录、点击打开）+ 拖入文件提示；空列表显示空状态。开始页键盘：`1–5` 选模板、`Enter` 新建空白、`Ctrl+N/O` 新建/打开、`Esc` 返回被盖住的文档（仅菜单进入时）。
- **窗口标题跟随文档**（2026-10-18）：任务栏 / Alt+Tab 显示「文档名 — 织思」，开始页显示「织思」；只在名字变化时发一次命令。
- **窗口记忆（已实现 2026-10-18，13 §4.27）**：外层矩形（物理像素）/ 最大化 / 大纲、检查器、小地图三块面板状态防抖写入 `%APPDATA%\织思\window.json`，退出时补一次；重启按原尺寸与位置恢复，最大化记忆还原矩形；**目标矩形标题栏落在任何显示器外时只丢几何、面板状态照常应用**；跨 DPI 迁移有 1–2px 漂移；最小化状态、标签页与相机位置不恢复。同一轮补上默认窗口按**工作区**（扣任务栏）居中，150% 缩放下状态栏不再被任务栏盖住。

## 10. 深浅色与对比度

- 主题即外观：内置 4 套（2 亮 2 暗）；默认跟随系统，切换即时生效无白闪（`color-scheme` + 预渲染双主题变量）；
- 所有主题过 WCAG AA：正文 ≥4.5:1、大字 ≥3:1；焦点环对比度 ≥3:1（每套主题给定焦点色）；
- 画布与界面chrome材质统一：Mica 下画布背景用主题纯色（Mica 仅用于标题/面板chrome）。

## 11. 无障碍要点（对应 02 §12）

- 画布节点在无障碍树中暴露为 role=list 项（名称=标题文本）；大纲面板为主交互通道（完整键盘+读屏）；
- 全键盘路径覆盖：焦点在面板与画布间 `F6` 循环；画布中 `←↑→↓` 在节点间导航（逻辑树方向）；
- 焦点环 2px 永可见；toast 带 aria-live=polite；所有对话框标准 tab 序。
