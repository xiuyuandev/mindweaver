## 1. 架构总览

```
┌─────────────────────────────────────────────────────────────┐
│ mw-shell（eframe/egui 0.37）                                 │
│  标题栏 / 菜单 / 面板 / 对话框 / 开始页 / 演示 / 快捷键        │
│  canvas.rs：画布交互 + Scene 消费                             │
│  session.rs：文档会话、撤销入口、自动保存                      │
└───────────────┬─────────────────────────────┬───────────────┘
                │ 只读 Session / Command        │ 离屏渲染
┌───────────────▼───────────────┐   ┌─────────▼───────────────┐
│ mw-render（wgpu 30）           │   │ mw-io / mw-format        │
│  四层合成器 + DirectWrite 文本  │   │  .zmind / 导入 / 导出     │
└───────────────┬───────────────┘   └─────────┬───────────────┘
                │ Scene                        │ Document
┌───────────────▼──────────────────────────────▼───────────────┐
│ mw-core：Node/Document/Command/撤销/主题/布局/Scene/检索       │
└──────────────────────────────────────────────────────────────┘
        ▲
        │ 纯逻辑
┌───────┴────────┐
│ mw-ui           │  选择 / 框选 / 拖拽落点 / 吸附
└────────────────┘
```

**核心纪律**：

1. **数据唯一权威在 `mw-core`**：文档内容、撤销栈、脏状态只有一份。
2. **UI 只读**：面板拿到 `&Document`/`Session`，修改一律返回 `Action` 或 `mw_core::Command`，由壳层执行。
3. **Scene 单一来源**：画布、导出、缩略图都消费 `mw_core::Scene`；不为导出另写布局。
4. **core 无 GUI 依赖**：`mw-core` / `mw-format` / `mw-io` 可在无窗口环境测试。

## 3. 数据流

### 3.1 编辑一次节点

```
用户输入（egui）
  → canvas/panel 生成 Action 或 Command
  → Session::apply(Command)（mw-core：校验 + ChangeSet + 压栈）
  → Document 版本/revision 变化
  → rebuild Scene（级联 + 布局 + 高级元素）
  → Canvas 下一帧把 Scene 喂给 mw-render
  → 自动保存后台线程每 3s 取快照写恢复点
```

- Undo/Redo 走 `ChangeSet` 反向应用，不重放命令。
- 批量操作包成 `Command::Batch`，只压一次撤销栈。
- 面板不得持有 `&mut Document`；这是编译期与代码评审共同保证的。

### 3.2 渲染

```
Scene（世界坐标）
  → camera：世界 → 物理像素（含 DPI）
  → instances：L0 背景点阵 / L1 连线边界 / L2 节点 / L3 覆盖层
  → flatten：贝塞尔按物理像素容差细分
  → wgpu：5 条管线 + 16 块实例缓冲 + 字形图集
  → egui 纹理（画布区域）
```

- 选中环、折叠点等「铬件」按屏幕像素绘制，不随 zoom 变粗。
- 文本走 DirectWrite 整形 + 灰度字形图集；编辑器（epaint）复用同一份几何。
- 离屏导出复用同一合成器，背景可选文档底色或透明。

### 3.3 打开 / 保存

```
打开：mw-format::load → Document → Session → Scene
保存：Session 快照 → mw_format::save（临时文件 + 原子替换 + .bak）
恢复：<docdir>/.autosave/<stem>.autosave.zmind，3s 节流，后台线程
```

自动保存只覆盖活动标签；切换/关闭时 `settle` 等在途写盘。

## 4. 线程与并发

| 任务 | 线程 | 说明 |
| --- | --- | --- |
| UI / 渲染 | 主线程 | eframe 每帧；Scene 重建在预算内 |
| 自动保存 | 后台线程 | 快照 + 合并 + 正本保存作废；UI 不被磁盘阻塞 |
| 导出（PNG/PDF） | 后台任务 | 结果回传主线程；导出期间仍可交互 |
| golden | 测试进程 | 离屏回读，逐字节/逐像素比较 |

纪律：后台线程只拿快照，不回写 UI 状态；UI 线程不做重 IO。

## 5. 命令模型（摘要）

- 文档修改统一走 `mw_core::Command`（26+ 种：文本、样式、移动、层级、折叠、标签、备注、链接、关系线、边界、概要、布局、主题、强调色、批量等）。
- `Document::apply` 返回 `ChangeSet`；失败不留半态（Batch 回滚）。
- 撤销上限 500；`Command::Batch` 只占一步。
- 样式覆盖 `StyleOverride` 是**节点级**的；`resolve_all` 按「主题层级 → 分支继承 → 节点覆盖」解析。
- v7 规则：一级主题显式 `branchColor` 时，卡片填充由 `Theme::branch_fill(branch)` 派生；未覆盖时仍用 `palette_fill`。

## 6. 窗口与 DPI

- Per-Monitor V2 DPI 感知；所有几何计算区分 CSS px 与世界坐标/物理像素。
- 自定义标题栏 + 原生窗口按钮 + DWM Mica；不用三行堆叠标题栏。
- 窗口状态（矩形、最大化、三块面板开关）防抖写入 `%APPDATA%\织思\window.json`；目标矩形完全在屏外时只丢几何。
- 最小化不持久化；跨 DPI 迁移有 1–2px 漂移（已记录）。

## 7. 错误处理与诊断

- 各 crate 用 `thiserror` 定义错误；文件层错误带上下文（路径、条目、版本）。
- 读文件有版本守卫、解压总体积/单条目上限、路径穿越检查。
- 诊断开关：`MW_TRACE`（焦点轨迹）、`MW_STATS`（帧时间）、`MW_HOME/MW_OPEN/MW_WINDOW_STATE`（探针现场）。
- 用户可见错误走 toast/对话框；不吞错、不 panic 到用户。
