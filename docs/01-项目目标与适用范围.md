# 01 · 项目目标与适用范围

> 状态：**当前** · 更新：2026-10-19 · 上游：无 · 下游：02、03、09
>
> 技术载体已定：**纯 Rust 原生界面**（eframe/egui 壳 + 自绘 wgpu + DirectWrite），不使用 WebView / Tauri。目标、原则、非目标自 v0.2 起未变。

---

## 1. 背景与问题

中文用户目前没有一款同时满足以下条件的桌面思维导图工具：

1. **性能可靠**：节点上千后不卡顿、不崩溃、保存不丢数据；
2. **中文输入不打架**：输入法候选窗跟随光标、组合输入期间快捷键不误触、中文排版（标点禁则、中英混排）正确；
3. **本地优先、数据自主**：文件在本地、格式开放可迁移，不强制联网、不强制订阅；
4. **界面现代**：深浅色主题、细腻动效、Windows 11 视觉语言。

现有产品各有短板：XMind 订阅制且大文档易卡；MindManager 昂贵且界面陈旧；FreeMind 开源但停止演进；在线工具（知犀、TreeMind、ProcessOn）受网络与隐私制约。**用 Rust 承载从数据核心到界面的完整栈**（egui 壳 + 自绘 wgpu + DirectWrite），可以在不引入 WebView、不依赖 Node 运行时的情况下同时满足上述四点，这正是本项目的立项依据。与此同时，开源世界也缺少一款打磨到商业级完成度的 Windows 思维导图工具——本项目以 GitHub 成熟开源项目的标准填补这个空缺。

## 2. 产品愿景与定位

> **一句话定位**：Windows 平台上"快、稳、美、中文好"的**免费开源**思维导图工具——面向个人单机使用，成熟度对标 XMind，但完全免费、完全本地、完全开源。

- **快**：启动、编辑、保存、导出全程响应迅速，性能见 08。
- **稳**：崩溃不丢数据（自动保存 + 恢复），打开即所见。
- **美**：现代 UI、4 套精修内置主题、动效克制而精致——舒服但不花哨。
- **中文好**：中文输入、排版、检索为第一优先级，专项设计见 07。

本项目按 GitHub 成熟开源项目的标准开发与运营：源码、文档、架构决策记录全部公开（MIT OR Apache-2.0 双许可），以质量与真实体验立身，不以功能数量取胜。

产品原则（优先级从高到低，冲突时依此裁决）：

1. 数据安全与完整性（宁可拒绝操作，不可损坏文件）
2. 中文输入与排版正确性
3. 交互响应性能
4. 功能完备度
5. 视觉表现力

## 3. 目标用户与核心场景

| 用户画像 | 典型场景 | 关键诉求 |
| --- | --- | --- |
| 学生 / 备考人群 | 读书笔记、知识点整理、背诵提纲 | 快捷键高效录入、大纲面板、导出打印 |
| 产品经理 / 创业者 | 需求梳理、产品规划、会议记录 | 图片级导出（汇报用）、主题美观、演示模式 |
| 开发者 / 架构师 | 技术方案脑暴、系统架构图、复盘 | Markdown 互通、纯文本友好、快捷键、命令面板 |
| 写作者 / 策划 | 文章大纲、活动策划、SWOT | 大量文本节点、软换行、聚焦模式 |

共性假设：**单机使用、文件归档在本地或网盘、对订阅付费敏感、高频使用中文输入法**。

## 4. v1 目标（1.0 版必须达成）

- 完整的节点增删改、层级管理、撤销重做、多选与批量操作；
- 五种自动布局（思维导图放射式 / 逻辑图向右 / 组织结构图向下 / 鱼骨图 / 时间轴）；
- 主题与样式系统：内置 4 套精修主题（2 亮 2 暗）+ 节点级样式覆盖 + 自定义主题；
- 导入导出矩阵（见 02 §8）全部落地；
- 快捷键体系（见 02 §10）与命令面板；
- 自动保存 + 崩溃恢复；
- 性能预算（见 08）在参考硬件上全部达标；
- 5 款主流中文输入法通过 07 §8 的全部验收用例。

## 5. v1 非目标（明确不做，防蔓延）

| 不做 | 理由与去向 |
| --- | --- |
| macOS / Linux 版 | 聚焦 Windows 做深；架构已隔离，未来可评估 |
| 移动端 / 网页版 | **永久非目标**：个人单机定位，无同步即无意义（见 10 §5） |
| 多人实时协作 / CRDT | **永久非目标**：个人工具，无服务端、无合并语义（见 10 §5） |
| 云同步 / 官方云存储 / 账号体系 | **永久非目标**：文件即数据，交给系统网盘/备份；织思只负责检测文件被外部改动（见 10 §5） |
| 图片 / 附件 / 富文本节点 | 归入 1.x；文件格式已预留 `assets/` 目录 |
| 插件系统 | 远期评估，社区有真实诉求再启动（见 10 §4） |
| AI 功能 | 远期可选，仅本地模型且默认不联网（见 10 §4） |
| 甘特图 / 项目管理融合 | 超出思维导图范畴，永久非目标 |

## 6. 竞品对照与差异化

| 维度 | XMind | MindManager | 幕布 | FreeMind | **织思 v1** |
| --- | --- | --- | --- | --- | --- |
| 收费模式 | 订阅为主 | 高价买断 | 订阅（云） | 免费 | **免费开源，本地优先** |
| 大文档性能 | 数千节点易卡 | 中 | 依赖网页 | 尚可 | **2 万节点可打开（08 预算）** |
| 中文 IME 体验 | 良好 | 一般 | 良好 | 差 | **专项验收（07），硬标准** |
| 文件格式 | 闭源 .xmind | 闭源 .mmap | 云端 | 开放 XML | **开放 .zmind，带完整规范** |
| 界面现代化 | 好 | 陈旧 | 中 | 陈旧 | **好（深浅色 + 云母材质）** |
| 数据位置 | 本地 | 本地 | 云端 | 本地 | **本地，零遥测** |

差异化总结：**不做"功能比 XMind 多"，做"XMind 用户最痛的四件事"——卡、贵、格式封闭、订阅压力。**

## 7. 成功指标（1.0 发布后 3 个月评估）

个人工具不设商业与增长 KPI，成功与否只看质量与真实使用：

| 指标 | 目标 |
| --- | --- |
| 作者本人将其作为日常主力工具（真实文档全部迁入） | 达成 |
| 1,000 节点文档全程交互帧率 | ≥ 55fps（参考硬件） |
| 输入法兼容用例通过率 | 100%（07 §8 全矩阵） |
| 崩溃率 | < 0.5% 会话 |
| 逃逸缺陷 | 无 P0/P1 级数据丢失类缺陷 |

> GitHub star 数与 issue 活跃度作为社区健康参考，不设目标值。

## 8. 范围边界与约束

- **平台**：Windows 10/11 x64；当前只在 x64 上实现与验收，ARM64 未测、不作为近期承诺（见 08）。
- **运行时**：零 Web 运行时；只使用系统自带的 DirectWrite / DWM / DXGI，不依赖 WebView2。
- **语言**：界面与文档语言 zh-CN 为源语言；文案自 v1 起键化，en-US 为 1.x 追加项。
- **离线**：全部核心功能离线可用；唯一联网点是可选的更新检查（指向 GitHub Releases，可在设置中关闭）。
- **许可**：全量开源（含 UI 与全部文档），MIT OR Apache-2.0 双许可；仓库根已有 `LICENSE` / `LICENSE-MIT` / `LICENSE-APACHE`；禁止引入 GPL 系依赖（见 03 §8）。

## 9. 术语表

| 术语 | 定义 |
| --- | --- |
| 节点（Node） | 思维导图的基本单元，含标题文本与可选的备注、链接、图标、样式 |
| 分支（Branch） | 从某节点出发的整棵子树的视觉呈现；分支颜色按层级循环取自调色板 |
| 场景图（Scene） | 布局引擎输出的、带坐标与尺寸的渲染中间表示（前端渲染与导出共用） |
| 聚焦（Focus） | 将某子树临时视为全图的查看模式，面包屑可逐级返回 |
| 演示模式（Presentation） | 按先序遍历逐节点展开的全屏演示 |
| 大纲面板（Outline） | 左侧的树形文本列表视图，与画布双向同步编辑 |
| 命令面板（Command Palette） | `Ctrl+K` 唤起的命令与节点快速搜索入口 |
