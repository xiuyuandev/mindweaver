## 2. 拆成四刀（每刀自带证据）

### 20a 保存管道（本刀先做）

- `CardReader`：脏 → 800ms 去抖到期 → 发 `ReaderAction::Save{close:false}`；壳层把它存进
  `pending_card_save`，**下一帧开头**才写盘（与文档 `SavePhase::Saving` 同一套两阶段，`保存中…` 才有意义）。
- 顶栏：`保存中…`（12/18 辅助色 + 6px 点）→ `已保存`（同时刻）。
- 离开/关闭/切换卡片：先把在途保存 flush 掉再走（不许丢最后一笔）。
- 失败：草稿保留、顶栏 `保存失败`、`Ctrl+S` 重试；不做模态。

### 20b 外部修改与只读（第二刀）

- 卡片持有 `notes/<id>.md` 的指纹（mtime + 长度）；写盘后更新。
- 顶栏下方 32px 行内条：`文件已在外部修改` + `重新加载 / 覆盖 / 取消`（不遮正文）。
- 只读：文件写不进去（`PermissionDenied` / 被另一个实例锁）→ 顶栏 `只读`、正文 `TextEdit` 只读、
  `Ctrl+S` 提示另存为。

### 20c 长文性能（第三刀）

- 20k 中文正文：打开到首帧、连续输入 200 字的帧耗时、IME 组合帧耗时；`MW_TRACE`/探针记录。
- 只做**测量 + 记录**；若超预算，再决定是否上块级缓存（合同 §6.9 的块级缓存是手段，不是门）。

### 20d 证据（第四刀）

- 场景：`card-autosave`（敲完等 1s → 已保存）、`card-conflict`（外部改文件 → 行内条）、`card-readonly`。
- 报告 `shots/x100/CER-20/report.md` + `manifest.json`；性能日志入 `target/x100/cer20/`。

## 3. 非目标

- 不改 `.zmind` / `NoteCard` 字段 / `notes/` 目录结构。
- 不做云同步、版本历史（恢复点沿用现有 `autosave.rs`）。
- 不把文档级冲突模态改成行内条（那是 Stage B2-C 之前的遗留，单独记账）。
- 不引入新依赖。

## 4. 验收判据（每刀）

1. 单测：纯逻辑（去抖判定、指纹比较、只读传播）必须可在 `cargo test` 里跑。
2. 金样：每刀至少一张基线，双跑 `--tol 0`。
3. 失败路径：写盘失败时**草稿不丢**（单测 + trace）。
4. 文档：`docs/STATUS.md` 对应行 + 本目录报告。
