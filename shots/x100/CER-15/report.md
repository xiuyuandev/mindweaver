# CER-15 · 卡片页块级排版收口

- 日期：2026-10-28

- 设计合同：`docs/28` §6.2 块级排版表 + §6.3 单一表面约束

## 1. 范围（本包只做块级排版，不碰交互语义）

1. 空行承载块间距（CER-15 的核心机制）
2. 标题四级字号/行高/上下边距
3. 段落、引用、列表（无序/有序/任务）的缩进与记号
4. 围栏代码块容器 + 语言标签
5. 分隔线
6. 行内码 0.92em
7. CRLF 容错（粘贴来的 Windows 文本）

## 2. 非目标

- 表格（`docs/28` §6.2 表中无表格行，本包不做）
- 图片、脚注、定义列表
- 语法高亮（代码块只做容器 + 等宽，不做着色）
- 改动正文字节：单一表面约束要求正文 buffer 一个字节都不能变

## 3. 实现要点

### 3.1 间距只能落在空行上

单一表面编辑器里正文是**真实文本**：块之间的空行是真实 `\n`，删不得（光标映射靠它）。
所以 `build_job` 预扫围栏、给每个空行算一个 `gap`，把它写进该行自己的 `TextFormat.line_height`：

- 连续空行只有**第一个**承担间距，其余压到 0（否则两段之间双倍空白）；
- 代码块内的空行一律 0（围栏内不算块间距）；
- 间距取「上一个块的下边距」和「下一个块的上边距」的**较大值**（边距折叠语义），
  否则「列表下 8」会把紧随其后的「标题上 40」压掉。

### 3.2 记号缩进靠字距，不靠空格

失焦时标记要隐形，但隐形之后正文起点也跟着回到 0，缩进就没了。
旧的 `hidden()` 把记号缩到 0.1px 透明——等于缩进为 0。现在改成
`marker_indent(chars, hide, target)`：留 4px 隐形字，用 `extra_letter_spacing` 把记号撑到目标宽度。

实测校准：4px 字的单字宽约 1.1px，字距只在字符之间生效，故解 `n·g + (n−1)·s = target`。
单元测试 `hidden_list_marker_indents_the_text_by_24px` 直接量排版后的落点，实测 24.0。

### 3.3 代码块容器不逐行铺底

围栏正文用 `code_line()`（等宽、无逐行底色），整块容器单独用 `rect_filled` 画：
底色 60%、圆角 10、内距 16，右上角 11px 语言标签。

行→行盒的映射按 `row.ends_with_newline` 累计，**不是**「行盒数 == 源码行数」：
末尾换行会多出一个空行盒，用等值守卫会导致容器永远画不出来（本轮踩过）。

### 3.4 CRLF 容错

fixture 与粘贴文本都可能是 `\r\n`。整行判定（标题、列表、任务框、分隔线、围栏）前统一
`trim_end_matches('\r')`，**字节不变**，只影响分类。

### 4.4 基线重拍

`card-default`、`card-empty`、`card-long`、`card-narrow`、`card-tags`、`card-slash`、

## 5. 偏差与未做（诚实清单）

1. **折叠后的「列表项间 4」写在上一条的行高里**：视觉等价，但那 4px 属于上一行的行盒，
   光标命中判定不受影响（纵向命中按行盒算），若将来做「段落级拖拽」需要重新折算。
2. **代码块容器不含围栏行**：围栏行仍是普通行（28px），所以容器上下各有 8px 由围栏行占据。
   合同未规定围栏行处置，按「围栏行不算内容」处理。
3. **表格未做**：合同表里没有表格行（见 §2）。
4. **H1 不在本包**：H1 是页面标题（30/40），由 CER-14 的标题输入框承担，正文不解析 `# `。
5. **未做实机 IME 验证**：CER-15 只改排版，但行高改动可能影响候选窗位置，归 CER-07 复核。
6. **人工视觉门未开**：G-B2-2 需要用户在真机上看过才算「已验证」，本轮只到「已实现」。

## 6. 风险

- 行高从 26 抬到 28（正文）后，同一屏可见行数减少约 7%；长文滚动性能未见退化（无新增分配）。
- `extra_letter_spacing` 撑缩进的方案依赖字体度量；换字体会让缩进略偏（±1px），已用单测钉住 24.0。
- 容器绘制以「行盒与源码行 1:1 映射」为前提改为按 `ends_with_newline` 累计；折行行也能正确覆盖。
