# M28b · 撤销栈上限调低的提示与保存口径

> 打磨轮 59 · 2026-11-01
> 账本：`docs/x100/polish-ledger.md`（M28 行的「未做」项）
> 合同：`docs/02` §2「栈上限默认 500 步（可配 100–2000）」；设置中心「编辑」组

## 1. 为什么是这一轮

第 51 轮（M28）把撤销栈上限做成 100–2000 可配，但记着一条未做：
「降上限后旧记录不可恢复且**无二次确认**」。现在的滑轨拖到 100 就直接生效、
最旧的记录当场丢掉，用户没有任何「这一步丢了多少」的提示。

本轮不引入模态框：在设置里滑轨下方就地给一条 **28px 警告行**，写清
「调低会立即丢弃最旧的 N 步撤销记录」，N 由「当前撤销+重做深度 − 新上限」算出。
这是把「不可逆」在**按下保存之前**说清楚，而不是事后 toast。

## 2. 范围

- 纯函数 `undo_limit_dropped(old, new, depth) -> usize`：
  `new >= old` 或 `depth <= new` 时 0；否则 `depth - new`（真正会被丢的步数）。
- 设置中心「编辑」组：滑轨下方在 `dropped > 0` 时画 28px 警告行
  （`ch.warn` 10% 底 + `warn` 文字），文案带步数；`dropped == 0` 时该行不出现、
  布局不留空位。
- 验收旋钮 `MW_SETTINGS_DEMO=1` + `MW_SETTINGS_DRAFT_UNDO=100`：只改设置对话框的
  草稿值，不落盘、不影响真实偏好，专门让金样拍得到警告态。
- 新基线 `settings-undo-warn`：先用 `Enter` 连建 110 个同级（撤销深度 > 100），
  再开设置并把草稿拖到 100 → 警告行写明「丢弃最旧的 10 步」。

## 3. 非目标

- 不加确认模态框、不改保存按钮文案（本轮先在滑轨旁把话说清楚）。
- 不改 `Document::history_limit` 的裁剪语义、不改 `.zmind`。
- 不做按文档覆盖上限（仍是进程级偏好）。

## 4. 验收场景

1. **会丢**：old=500、new=100、depth=110 → 警告 10 步；渲染 28px 行。
2. **不会丢**：depth=17 → 不出现警告（demo 文档平时就是 17 步）。
3. **抬高/持平**：new >= old → 0，不出现警告。
4. **零污染**：既有 `settings` / `settings-limit-100` 两张基线不含警告态（草稿 =
   已存值），应零漂移；`settings-undo-warn` 与 `settings` 的差异只在滑轨下方新增一行。

## 5. 预计证据

- 新基线 `settings-undo-warn`（`--tol 0` 双跑）。
- 单测 `undo_limit_dropped_counts_only_real_losses`。
- 轨迹 `settings warning dropped=… depth=… limit=…`（警告行出现且步数变化时记一笔）。
- `stage-b` 144 → 145 场 / 288 → 290 次比较；`stage-cm` 64/128 顺序复跑。

## 6. 实测结果（2026-11-01）

- **几何/行为**：点根「织思」→ 110 次 `Enter` 后撤销深度 **127**；设置草稿上限 100 →
  轨迹 `settings warning dropped=27 depth=127 limit=100`，滑轨下方 28px 警告行写出
  「调低会立即丢弃最旧的 27 步撤销记录」；图中警告色像素 **377 个**，
  bbox `(577,546)–(774,556)`（一行文字），与周围行不重叠。
- **金样的两个坑（本轮踩到并修掉）**：
  1. `MW_SETTINGS_DEMO=1` 是**开局就开**设置：后续 110 次 Enter 全被对话框吃掉
     （默认动作「保存并应用」还会把上限真写成 100）。新增帧控旋钮
     `MW_SETTINGS_AFTER=<n>`：先让脚本在画布上堆历史，第 n 帧再弹设置；
     n 必须晚于最后一次按键（240 > 脚本 234 帧），否则「丢几步」会随帧数漂。
  2. 对话框里「笔记库当前路径」取自 APPDATA：换一个 appdata 目录基线就漂 47 px。
     显示改用**草稿**的 `s.notes_root()`（改路径时即时预览，也更合理），
     并加旋钮 `MW_SETTINGS_NOTES_DIR` 固定成 `C:/织思笔记`；两个不同 appdata
     目录各跑一遍 `--tol 0` 全过。
- **既有基线**：`settings` / `settings-limit-100` 不含草稿旋钮，警告行不出现，
  几何不变（门内验证零漂移）。
- **单测**：`undo_limit_dropped_counts_only_real_losses` 六档（持平/抬高/深度未顶到/
  真丢 10 步/正好等于上限/空历史）；测试 1123 → **1124**。
