# CER-04 · 大纲页面骨架与版心

> 状态：已实现 · 开始 2026-10-25 · 批次 B2-A · 依赖：CER-02（已完成）
> 设计合同：[`docs/28`](../../../docs/28-内容体验重构规范.md) §5.1（结构）、§4.2（版心）、§4.4（边框圆角）
> 执行合同：[`docs/29`](../../../docs/29-内容体验重构工作包.md) §6

## 1. 范围

只做**骨架**：页面结构（页头/版心/标题/页脚），行绘制 v2 留给 CER-05。

1. **页头 40px**（现 56px）：返回、面包屑（`大纲 › 聚焦路径`，非聚焦时
   `大纲 · 文档标题`）、主题计数（12px 纯文字 `N 个主题`，不再用
   `shown/total` 胶囊）；右侧工具簇 28×28、图标 16、组间 8：
   搜索 ⌕ + 更多 ⋯（折叠/密度/聚焦/文档信息收进更多菜单）。
   删除：56px 页头、"大纲"大标题字、`shown/total` 数量胶囊、
   宽窗"大纲/画布"分段大按钮（返回画布由 ← 承担）、聚焦/密度/折叠三个
   常驻工具按钮（功能保留：键盘 + 更多菜单）。
2. **版心**：`COL_MAX` 1040 → **800**，正文宽 760；窄窗左右 32（不变）。
   页头/页脚与正文共用同一版心边距。
3. **根节点 = 页面标题**：28/38/600（`OUTLINE_TITLE`），无底、无边框、
   无握把/圆点/层级线；子节点从标题下 24px 开始。选中根不再画
   10% 强调底 + 35% 描边大框（X20 人工判词点名的"第一行高亮卡片"）。
4. **页脚 24px**（现 28px）：左侧脏点 + 计数/选中摘要；右侧只放一个 `?`。
   删除常驻快捷键提示（`footer_hints` 整段移除；帮助入口仍在）。
5. `content_kit` 的 `page_title` 组件承担标题排版；行绘制（32px 行、圆点、
   缩进、角标）**保持现状**，CER-05 重做。

## 2. 非目标

- 不做行绘制 v2（32px 行、4px 圆点、无树线——CER-05）。
- 不做选择/焦点/多选状态表（CER-06）、行内编辑（CER-07）、结构命令（CER-08）、
  拖拽（CER-09）、搜索筛选聚焦 v2（CER-10）、虚拟化与 20k（CER-11）。
- 不新增 `≡` 筛选按钮：筛选条在 CER-10 落地；本包页头右侧只放搜索与更多。
- 不动侧栏 232px 大纲面板（F9 面板版本）。
- 不改 `.zmind`、命令层、画布。

## 7. 未做 / 已知偏差

- **标题行行位 44 而非规格 38**：28px 雅黑 galley 实高约 42px，38px 行位会裁字；
  「子节点从标题下 24px」的精确间距在 CER-05 重排行距时一并落实（当前子行仍按
  密度节距 40/32/48 走）。
- **默认 golden 中标题行带 1.5px 焦点环**：演示种子经命令路径 pin 了根行焦点
  （`outline_focus_pin` → `request_row_focus` → `keyboard_focus=true`，MW_TRACE
  证实）。按 docs/28 §4.6/§5.3，程序化选中不该画键盘焦点环——选中与键盘焦点
  的状态拆分属 CER-06（选择/焦点/多选），届时修正并重拍。
- **层级线仍在**：树形竖线按 §5.9 应删除，属 CER-05 行绘制 v2；本包只动骨架。
- 行尾角标（`#1` 标签计数、双色点、任务框）保持 X20 现状——CER-05 改为
  单个 5px 右点。
- 密度三档（compact/standard/comfortable）暂保留；docs/28 §5.2 固定 32px 行高
  与其冲突，CER-05 一并裁决（预计移除密度档或收敛为单一规格）。

## 8. 风险

- 页头工具按钮移入"更多"菜单会改变鼠标路径——`Alt+Enter`（聚焦）、
  菜单项（折叠/密度）仍可用；若 G-B2-1 判词要求常驻密度按钮，回退成本低。
- 根标题编辑入口（双击/F2）保持既有行为不变；只改渲染层。
- 层级线在 CER-05 才删；本包版心变窄后线仍在，属预期中间态。
