# SE-11 · 配色对比度达标 + 令牌归一（可量化视觉修订）

日期：2026-10-30　状态：**已实现**（机器证据齐）

## 1. 范围

"界面现代、专业、统一"必须能量出来，不能靠看截图。这一包只做**有数字可依**的视觉修订：

1. 次要文字 `ui.dim` 在 `panel2` / `hover` 底上不达 WCAG AA 4.5:1 → 修到全部达标。
2. `faint` 文字在三种浅色底上连 3:1 都不到（2.64–2.82）→ 修到 ≥3.0，同时保持"比 dim 更淡"的层级。
3. 令牌归一：字号阶梯第四档没有令牌、焦点环两套常量不一致、布局层挂着两个没人读的内距常量。

### 非目标

- 不改布局几何（盒子尺寸、间距、圆角一个都没动）。这一包**不产生 golden 漂移**，除非文字颜色像素。
- 不改字体、不改行高、不改动画时长。
- 不新增主题。

## 2. 逐条

### 2.1 `ui.dim` 修到四底全 AA

`ui.dim` 是面板里真的当正文用的次要文字（分组说明、副行、路径）。改前它在 `panel2` / `hover` 上只有 4.31–4.36:1，
摸到 AA 线下方 —— 这不是"风格选择"，是没达标。

| 主题 | 改前最差 | 改后最差 | 新值 |
| --- | --- | --- | --- |
| snow | 4.34 | **4.53** | `#67706c` → `#646d6a` |
| mist | 4.36 | **4.56** | `#61706c` → `#5e6d69` |
| sand | 4.31 | **4.51** | `#74665b` → `#716358` |
| ink | 5.73（已达标） | 5.73 | 不变 |

每通道只挪 3–5 个单位，肉眼几乎无法分辨，但把四个底色（`panel` / `panel2` / `hover` / `canvas_bg`）
全部抬过 4.5。**新的验收口径**：`tests/contrast.rs::secondary_text_clears_aa_on_every_surface`
逐主题 × 逐底色断言 ≥4.5，任何主题以后调色只要越线就红。

### 2.2 `faint` 从"几乎看不见"提到 3:1

`content::ALPHA.text_faint` 0.48（亮）/ 0.50（暗），按文字色合成到四种底上算**最终像素**对比度：

| 主题 | 改前最差 | 改后最差 | 新 alpha |
| --- | --- | --- | --- |
| snow | 2.82 | **3.50** | 0.48 → 0.56 |
| mist | 2.69 | **3.28** | 同上（共用 `LIGHT_ALPHAS`） |
| sand | 2.64 | **3.20** | 同上 |
| ink | — | ≥3.0 | 0.50 → 0.58（暗色透明度必须 ≥ 亮色，见既有不变式） |

`faint` 的定位**没变**：只做占位符 / 禁用 / 装饰，不承担正文。所以按"非文本 3:1"验收，不按 4.5。
新增 `tests/contrast.rs::faint_text_stays_visible_but_never_becomes_body_text` 同时钉两条：
① 四种底 ≥3.0；② faint 的对比度必须**严格小于** dim（否则两档并成一档，层级就塌了）。

### 2.3 令牌归一（三处）

- **`design::text::CANVAS_LEAF = 14.0`**：字号阶梯第四档以前是裸写在 `theme::LEVEL_TYPE` 里的 `(14.0, false)`，
  是四档里唯一没有令牌的。现在四档全部指向 `design::text::CANVAS_*`，改字号只需改一处。
  顺带修掉那段自相矛盾的注释（老注释写"中心主题 32 / 一级 18 / 二级 16"，实际令牌是 28/20/15/14）。
- **焦点环 `component::FOCUS_RING / FOCUS_RING_OFFSET`**：原来写成 `1.4 / 1.5`，而内容面
  `content::focus` 是 `1.5 / 1.0`。两条绘制路径画出来的环几乎一样却差 0.5px。现在 `component` 的两个常量
  **直接引用** `content::focus`，两处不可能再分叉。
- **删掉 `layout::PAD_X / PAD_Y`**：`18.0 / 9.0`，全仓**零引用**，但注释写得像在驱动几何，
  让"内距为什么不是令牌"这个问题被反复提出。真实出口是 `design::card_padding(font_size)`
  （中心 26/12、一级 18/10、二级 14/8、深层 12/7，按字号分档）。删常量、留一行指针。

## 3. 证据

- `cargo test -p mw-core --test contrast` → **7 passed**（含新增 2 条）。
- `design::tests::content_alphas_match_the_contract` 同步更新为新 alpha，并保留
  "暗色 ≥ 亮色" "faint < secondary" 两条不变式断言。
- 数值由 `target/tmp/ctr3.py` 一次算出（WCAG 相对亮度公式 + sRGB 反伽马 + alpha 合成到最终像素）。

## 4. 未做 / 风险

- **未做（并已纠正自己的误判）**：四个主题的分支色板**本来就不等长** —— `snow` 8 个，
  `ink` / `mist` / `sand` 各 6 个。我一开始把 `sand` 当成"缺两个"的少数派，实际反了：6 才是多数，
  `docs/30` §5.4 也一直写的是"6 色循环"。**不改色板**，理由：① 取色本来是 `palette_at(i % len)`，
  行为确定、不会越界；② 把 `snow` 从 8 压到 6 会让"第 7/8 个分支配色"变化，是可见回归；
  ③ 给三家各补两色，试过按"与现有 6 色距离最大化"自动挑，选出来是 `#404040` 灰和 `#b070b0` 品红，
  整组跑出土色调语汇之外，而本机看不了截图、无法自证不难看。
  改为**把合同写实**：`docs/30` §5.4 由"6 色循环"改成"按 `palette.len()` 取模（内置主题 6–8 色）"。
- **风险**：`faint` 变浓后，若某处把 `faint` 当"极淡装饰线"用（例如分隔线），视觉上会略重。
  已核：分隔线走 `hairline` / `divider` 令牌，不走 `text_faint`。
