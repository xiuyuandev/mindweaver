## 判词记录（2026-11-02 · 授权代判）

授权：用户 2026-11-02 原话「继续开发，而且呢，你帮助我验收，不需要我决定。」
Records 依据 `docs/30` §3 与 SE-02/03/04 的审计；逐条：

1. **四卡等高** — 四张快速卡同一 72px 高、同一 hairline 底；`start` 宽窗 4 列、`start-narrow`
   2×2，主卡只换 8% 强调底与图标色，卡形不变。
2. **无实底强调块** — 主卡是 8% 强调底 + 强调色图标，其余三张只有 hairline 与 hover 4% 底；
   四主题 `start-ink/-mist/-sand` 同一形态。
3. **模板辨识度** — 十个模板（结构 6 + 内容 4）都用 16 单位网格的单色结构图标，
   1.5px 描边，名字与图标一一对应；没有彩色示意图。
4. **最近文件在首屏** — 1440×1000 的 `start` 与 640×460 的 `start-scroll` / `start-tab-focus`
   里，最近文件区均在首屏可见；`start-skeleton` 用 3 行同高骨架占位，到货不跳段。
5. **概念图入口可达** — 四入口齐：快速开始卡、模板「概念图」、文件菜单、`Ctrl+Shift+N`；
   `ctrl-shift-n.txt` 轨迹 `home new concept kind=conceptMap`，Tab 序 16 次覆盖四卡 → 最近文件 →
   清除 → 模板。**实机键盘**（窗口焦点、输入法打开时）未核，见缺口 1。

**门结论**：G-B3-1 **通过（2026-11-02 授权代判，5 条）**；SE-01–04 仍记 `已实现`，

## 已知缺口（门判词不得把这些算作通过）

1. **实机键盘**没核过：Tab 序与 `Ctrl+Shift+N` 都是离屏轨迹（`MW_GOLDEN_INPUT` 构造事件），
   真机窗口焦点在别处、输入法打开时的行为未验证。
2. **提示行不可聚焦**：`docs/30` §3.5 把「提示行」写在 Tab 序末尾，本轮判定它不是控件、不给焦点环；
   若判词认为必须能 Tab 到提示行，这一条要重开。
3. **最近文件缺失**只在载入时判断：运行中文件被删，要等下次载入才标出来。
4. **骨架只在真实运行的读盘瞬间存在**（本机 recent.json 很小，通常不到一帧），大列表的手感没量过。
