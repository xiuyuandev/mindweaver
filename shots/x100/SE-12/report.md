# SE-12 · 起始页内容模板（空白 / 读书笔记 / 会议记录 / 产品规划）

> 打磨轮 61 · 2026-11-01
> 合同：`docs/02` §1「开始页」行——**原定的 4 个内容模板（空白/读书笔记/会议记录/产品规划）待补**
> 设计：`docs/30` §3.1 / §3.2 / §3.5 / §3.8

## 1. 为什么是这一轮

`docs/02` §1 从立项起就写着开始页要「新建 + 模板 + 最近文件」，其中模板分两类：
按**结构**分类（放射/逻辑/组织/鱼骨/时间轴/概念图）与按**内容**分类
（空白/读书笔记/会议记录/产品规划）。起始页 v2（SE-01–04）只做了前者，
后四张在文档里挂着「待补」已经两周多。用户想要的其实常常是「拿一张有格子的图开始填」，
而不是先想清楚该用哪种结构。

## 2. 范围

- `TEMPLATES` 6 → 10：结构模板 1–6 一字不改，新增内容模板 7–10（全部 `Shape::Tree`、布局 `mindmap`）。
  - 「空白」：真正的空文档——根节点无占位文字、无子级。
  - 「读书笔记」：根「书名」→ 书目信息 / 核心观点 / 章节笔记 / 摘录与金句 / 行动。
  - 「会议记录」：根「会议主题」→ 与会人 / 议题 / 决议 / 待办（待办与决议都带「负责人：」占位）。
  - 「产品规划」：根「产品名称」→ 目标 / 用户与场景 / 里程碑 / 风险。
- 模板区分两组，各带一行组标题「结构模板」「内容模板」（`TPL_GROUP_H=18`、下间距 8、组间距 14）。
  **组标题不是控件**：无命中区、不进 Tab 序，只是把同一张网格分成两组。
- 网格**不改列数断点与卡宽公式**：仍是 `template_cols` 的 3/2/1 列、同尺寸同间距。
  取舍写在 §4。
- 数字键快选扩到 10 张：`template_hotkey(idx)` 纯函数（`1–9` → 前九张，`0` → 第十张），
  模板区提示改「挑一套开始 / 按 1–9/0 快选」，页脚键帽 `1–6` → `1–9/0`。
- `app_methods_1.rs` 首页数字键循环改按 `TEMPLATES::len()` + `template_hotkey` 生成，不再硬编码 6 个。
- 图标全部复用现有单色矢量（`New / Note / Levels / Focus`），**不新增绘制代码**。

## 3. 非目标

- 不改 `.zmind` / `Node` / `NoteCard` 字段；模板内容全部走既有 `Template::session()`
  （`Document::new` + `Command::SetLayout` + 结构命令），不绕过 `Command`。
- 不做「模板库」浏览器、不读磁盘上的外部模板文件。
- 不改卡片尺寸、断点公式与页面上其余区域（快速动作 / 最近文件 / 页脚）的几何。
- 不为内容模板引入卡片笔记（`NoteCard`）——起手树只是标题层级。

## 4. 设计取舍（布局）

10 张卡若强行改成 4 列，会把**已验收**的六张结构卡从 285 px 压到 211 px，
并推翻 `docs/30` §3.2 的卡片几何。因此选择：
**同一张网格、两组卡**——宽窗 3 列下结构模板正好两整行，内容模板 3+1，
末格沿用既有占位分支（补空格而不是拉伸卡片）。窄窗 2 列/1 列同样按组内换行。

## 5. 验收场景

1. 起始页显示 10 张模板卡，分「结构模板 / 内容模板」两组，卡片同尺寸同间距。
2. 逐张 `Template::session()` 都能构建合法文档（`validate()` 通过、布局与 `layout` 字段一致）。
3. 「空白」只有 1 个节点、根文字为空、无子级、`session.dirty()` 为假。
4. 三张有内容的模板：每个一级分支都有子项（不留空标签）；「读书笔记」章节笔记三格、
   「产品规划」里程碑三格、「会议记录」待办含「负责人」占位。
5. 数字键 1–9 与 0 覆盖全部 10 张；Tab 序仍先快速动作、再结构模板、再内容模板、再最近文件。
6. 模板内容全是静态字面量：不读墙钟/随机数，金样可复拍。

## 6. 实测结果（2026-11-01）

- **实现**：`crates/mw-shell/src/start.rs`（`STRUCTURE_TEMPLATES`、`TPL_GROUP_*` 常量、
  `TEMPLATES: [Template; 10]`、`template_hotkey()`、`template_group_label()`、
  `template_grid(..., range)` 改为按下标区间画一组）、
  `crates/mw-shell/src/app_methods_1.rs`（首页数字键按 `TEMPLATES::len()` 生成）。
- **文档**：`docs/02` §1 开始页行改「10 张模板：结构 6 + 内容 4」；
  `docs/30` §3.1/§3.2/§3.5/§3.8 改两组十卡 + 组标题几何 + 数字键 `1–9/0` + 验收场景 `start-templates-content`。
- **单测新增 4 条**（`start::tests`）：
  `templates_cover_six_structures_and_four_content_starters`、
  `blank_content_template_is_a_really_empty_mindmap`、
  `content_templates_build_their_documented_starting_tree`、
  `template_number_keys_cover_1_to_9_and_zero_for_the_tenth`。
  `mw-shell --bins` 631 → **635**（接手会话内实测：`cargo test -p mw-shell --bins template` 8/8 通过）。
- **fmt / clippy**：`cargo fmt -p mw-shell` 干净；`cargo clippy -p mw-shell --all-targets`
  只剩 `export_pdf.rs` 3 条历史告警（均在 `scripts/clippy-baseline.txt`），**新增 0**。
- **金样**：11 张 `start*` 基线按现状重拍（`--update`），随后同一构建再跑一遍
  `--tol 0` **全部零差异**（模板区 2 行 → 4 行，整页重排，这是有意漂移并量化）。
  **不新增场景**：先试过 `start-templates-content`（1440×1120），实测离屏 harness
  无视 `MW_WINDOW_SIZE`（固定 1920×1200 物理画布），拍出来与 `start` **逐字节相同**
  （sha256 `017FFA810F99…`），已删掉该场景与草稿输入脚本；十张卡的证据由
  `start` / `start-ink` / `start-mist` / `start-sand` 等 11 张重拍基线承担。
  基线目录仍 **212**、输入脚本仍 **140**。

## 7. 未做 / 风险（诚实标注）

- 数字键 `0` 的键帽在最右格内是否压边、组标题与 10 张卡在 125%/150% 实机观感**未人工核对**。
- 「空白」模板的空根在画布上的视觉（空文字框）只有单测口径，没拍图。
- 内容模板起手树是中文占位标题，不含备注/标签/卡片——真实用户首次保存前全是「未命名」。
- 实机 IME 不涉及本轮（无输入路径新增）。
- X20 / G-B3-1 / G-B3-2 人工门仍未判，AI 不代判。
