# M31 · 「设为根主题」（把选中的主题提为中心主题）

> 打磨轮 64 · 2026-11-01
> 账本：`docs/x100/polish-ledger.md` M25 行的「未做：设为根主题（P2）」
> 合同：`docs/02` §2「B 节点编辑」；`docs/26` 的可发现性与反馈要求

## 1. 为什么是这一轮

账本 M25 记着「未做：设为根主题（P2）」——大纲行菜单与画布节点菜单里都没有这个动作，
`Command` 枚举里也没有换根命令。用户想把某个分支提成中心主题，只能手搓：
新建一棵树、把整棵子树复制过去、再删掉旧的——中间至少五六条撤销，还容易丢备注卡片。

`ChangeSet` 里早有 `before_root` / `after_root` 快照（当初是给「概念图删掉主概念时重挂根」
用的），所以换根命令可以做成**一条命令、一次撤销**，不需要动数据模型。

## 2. 范围

- 新命令 `Command::SetRoot { id }`：
  - 思维导图：新根从原父级摘除（原父级的概要跨度同步收口）、旧根剩下的整棵树**追加**到新根孩子末尾、
    `root_id` 换成新根；新根若是自由主题则交出 `pos`（思维导图里只有自由主题能带坐标）；
  - 概念图：一律拒绝（`Invalid("概念图里没有中心主题")`）；根自己重复提根、未知 id 各有错误口径。
- `Canvas::set_root_primary()` / `Canvas::set_root_for(id)`：应用命令、记轨迹 `set-root id=… ok=…`、
  成功后 `fit` 一次（新根按布局落在视口外是最容易被当成「点了没反应」的情形，M6b 同类）。
- 入口：画布节点右键菜单「设为根主题」（排在「分离为自由主题」之后）、
  大纲行 `⋯` 与行右键菜单「设为根主题」（单选、非根行才可用）。
- 新基线 `mm-set-root`。

## 3. 非目标

- 不做快捷键（P2，菜单 + 行菜单已经可发现；键位要等 `Ctrl+Shift+↑` 一类的整体规划）。
- 不弹确认框（可一步撤销，且动作本身可逆）。
- 不改变旧根在新根孩子里的**插入位置**规则：本轮固定追加在末尾，理由写在命令注释里。
- 概念图不提供入口（概念图没有中心主题语义，整理布局已经解决了「谁是主角」的问题）。

## 4. 验收场景

1. **提一级子主题为根**：A（有子 X）与 B 是根 R 的孩子 → 对 A 提根 →
   `root_id = A`、`A.children = [X, R]`、`R.children = [B]`，`validate()` 通过。
2. **一次撤销**：`Ctrl+Z` 后根回到 R，`R.children = [A, B]`（原顺序）、`A.parent_id = Some(R)`。
3. **自由主题提根**：分离出来的自由主题提根后 `pos` 清空，撤销后 `pos` 回来。
4. **拒绝路径**：概念图 / 已是根 / 不存在的 id 三种错误各自成立，文档不变。
5. **可发现性**：画布右键菜单与大纲行菜单都有这一项；大纲里根行置灰。

## 5. 预计证据

- 单测 3 条（`mw-core`）：结构 + 撤销/重做、自由坐标、三种拒绝路径。
- 新基线 `mm-set-root`（`--tol 0` 双跑）：右键节点 → 选「设为根主题」→ 画布重排、取景复位。
- 轨迹 `set-root id=… ok=1` 与菜单的 `menu_open`。
- `stage-b` 146 → 147 场 / 292 → 294 次比较。

## 6. 实测结果（2026-11-01）

- **命令**：`Command::SetRoot { id }`（`command.rs` 带文档注释与撤销文案「设为根主题」）；
  `Document::apply` 新分支做五件事：概念图拒绝 → 未知 id → 已是根 → 摘出原父级（概要跨度
  `normalize_annotations_of`）→ 旧根挂到新根末尾 + `root_id` 换新；`ChangeSet::with_root`
  记前后根，撤销/重做连根一起还。
- **壳层**：`Canvas::set_root_primary()` / `set_root_for(id)`（落命令 + 轨迹 + `fit_view()`）；
  画布节点右键菜单「设为根主题」（排在「分离为自由主题」之后）、大纲行菜单同上。
- **单测 4 条**（`mw-core`）：结构 + 撤销/重做、从孙节点提根时祖先链留在旧根那侧、
  自由主题提根交出 `pos`、三种拒绝路径。`cargo test -p mw-core --lib set_root` **4/4 通过**。
- **轨迹（金样实跑）**：`menu_open anchor=1167,503 entries=21` →
  `menu_nav … label=设为根主题` → `set-root id=01a195… ok=1`，随后 `scene_build nodes=13`。
- **金样**：新基线 `mm-set-root`（warmup 20、`MW_NOTES=none`、输入脚本
  `shots/golden/inputs/mm-set-root.txt`，菜单用 `Home + 11×↓ + Enter` 定位第 12 行），
  `--tol 0` 双跑零差异；sha256-12 `B95E11237D8F`。
- **门**：与 SE-12 / M7b / C21 一起进 stage-b（146 → 147 场 / 292 → 294 次比较），
  整门结果见 `docs/STATUS.md` §1。

## 7. 未做 / 风险

- 没有快捷键（菜单 + 行菜单已可发现；键位等整体规划）。
- 不弹确认框（一步可撤销）；旧根固定追加到新根孩子末尾。
- 概念图不提供入口（概念图的 `root_id` 只是「第一个概念」）。
- 实机键鼠节奏与 IME 未核；X20 人工门不代判。
