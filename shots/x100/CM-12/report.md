# CM-12 · 概念图概念节点改为椭圆（形状语言与思维导图分流）

日期：2026-10-30　状态：**已实现**（机器证据齐；G-CM-2 人工门未复判）

## 1. 范围

概念图的"概念"不再沿用思维导图的圆角矩形，改用**椭圆**。这是"概念图不能继续沿用思维导图结构"
在视觉层的落地：思维导图是"盒子里挂子盒子"的层级容器，概念图是"散落的椭圆 + 有向连线"的网络。
`docs/30` §5.3、§12 CM-10 ⑨。

### 非目标

- **不动数据模型**。没有新字段、没有 `FORMAT_VERSION` 变更、没有迁移。形状是"渲染解释"，
  不是存储事实：`conceptMap` 布局下、且节点没有显式形状覆盖时，默认解析成椭圆。
- 不动文字排版。椭圆只让**画出来的盒子**变大，文字盒原样不动 —— 换行点、省略号阈值、
  tooltip 全文全部逐字节不变（下节有界证明）。
- 不动思维导图。任何非 `conceptMap` 文档的形状解析与改动前完全一致。

## 2. 实现路径（五处，一个真相源）

| 位置 | 改动 |
| --- | --- |
| `theme.rs` `Shape` 枚举 | 新增 `Ellipse`；`from_name` 认 `"ellipse"`；新增 `is_ellipse()` 收口"谁该问这一句" |
| `theme.rs` `apply_concept_defaults` | `conceptMap` 且无显式覆盖 → `Shape::Ellipse`（`rounded` 仍是思维导图默认，也是老文档的既有值） |
| `instances.rs` `corner()` | 形状 → 圆角半径的**全仓唯一出口**，改成 `pub`；椭圆返回哨兵 `ELLIPSE_CODE = -1000.0` |
| `rect.wgsl` | 有向距离场加 `sd_ellipse`，`fs` 按 `radius < -0.5` 分流；椭圆不画虚线 |
| `scene.rs` `measure_concept` | 画出的盒子按比例外扩（宽 `+min(0.22w, 24)`、高 `+min(0.16h, 8)`），**文字盒不动** |
| `hit.rs` | 命中用椭圆方程 `((x-cx)/a)² + ((y-cy)/b)² ≤ 1`，不再用外接矩形 |
| `canvas.rs` | 编辑态强调环在椭圆节点上画 `egui::Shape::Ellipse`（圆角矩形环会在四个角露出来） |
| `export_svg.rs` | 直接输出原生 `<ellipse cx cy rx ry>`，不是 4 段贝塞尔近似的 rect |
| `export_pdf.rs` | `round_rect_path` 认哨兵，用 `k = 0.5522848` 的四段三次贝塞尔画真椭圆；`fill_round` / `dashed_round` 都走这一条 |

**为什么用负圆角哨兵而不是给 `RectInst` 加字段**：`RectInst` 现在是 68 字节、Rust 对齐 4，
而 WGSL 侧按 `roundUp(16, 68) = 80` 算 stride。再加一个 `f32` 会让两边对不上（隐式 stride 假设破裂）。
哨兵值 `-1000` 与任何合法半径（最大 `h/2 = 18`）都不可能相撞，判定阈值取 `<= -999.5`。

## 3. 外扩量的界证明（为什么不会挤坏文字）

椭圆内接矩形才是文字盒，所以**盒子必须比文字大**，否则文字会顶到椭圆边界外。

- 宽：内接盒 96 → 画 117.1（`96 × 1.22`）；内接盒 240 → 画 264.0（撞 `+24` 封顶）
- 高：内接盒 36 → 画 41.8（`36 × 1.16`）；内接盒 52 → 画 60.0（撞 `+8` 封顶）

最宽的两行文字（240 宽内接盒）画出来 264 宽、60 高，椭圆四边到内接矩形角点的余量足够，
文字不会出界。**文字盒尺寸、换行结果、省略号阈值一律未变**，所以既有文档的排版零漂移。

## 4. 证据

| 类别 | 证据 |
| --- | --- |
| 单元测试 | `theme::tests::concept_maps_default_to_ellipses_and_mindmaps_do_not`（默认分流）、`shape_names_round_trip`（`rect/rounded/capsule/underline/ellipse` 五种名字往返）、`scene::tests::concept_boxes_follow_the_node_contract`（重写为椭圆契约，并**同图内**把一颗概念显式改回 `rounded` 验它不外扩 —— 这条同时钉住 `BoxKey` 必须比形状，否则第二颗会命中第一颗的缓存尺寸） |
| 命中 | `hit` 的椭圆包含判定；非椭圆节点仍走矩形，行为不变 |
| 导出 | SVG 原生 `<ellipse>`；PDF 四段贝塞尔；两者与 wgpu 共用 `mw_render::corner()` 的同一个判定 |
| 编辑态 | 椭圆节点进编辑态时环是椭圆（`egui::Shape::Ellipse` + `SELECT_RING_GAP/W`） |

## 5. 未做 / 风险

- **未做**：概念图"整理布局"（`concept_layout`）仍按矩形外接盒算间距，椭圆之间会比矩形多出一点视觉空隙。
  这是保守选择：改间距会动所有概念图基线，收益（更紧的视觉密度）不抵风险。
- **未做**：椭圆不支持虚线描边（`rect.wgsl` 里椭圆分支跳过 dash）。概念图默认无虚线，暂无路径能造出来。
- **风险**：自定义主题若把某层形状显式设成 `ellipse`，思维导图也会画椭圆 —— 这是**用户显式要求**，
  不是默认行为，可接受。
- 人工门：G-CM-2 需复判（"概念图看起来像概念图"这一判词现在才有椭圆可看）。
