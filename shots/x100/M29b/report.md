# M29b · 搜索脚注开关的窄窗布局（实拍 + 纯函数）

> 打磨轮 57 · 2026-11-01
> 账本：`docs/x100/polish-ledger.md`（M29 行的「未做」项）
> 合同：`docs/02` §3「匹配方式可切换『精确文本 / 拼音』」；`docs/06` §5 窄窗让位

## 1. 为什么是这一轮

打磨轮 52（M29）把「精确文本 / 拼音」开关做进搜索条脚注右侧，代码里有一条
`let narrow = width < 420.0;` 的短标签分支（「精确文本」→「文本」），但**从未实拍**：
- 现有搜索基线窗口都是 1280×800，卡片宽 560，`narrow` 恒为 false；
- 窄窗分支只在「卡片宽 < 420」时生效——最现实的情况是 640 宽窗口 + 检查器 288，
  画布中央只剩约 350，卡片被 `.max(240)` 夹到 326；
- 这条分支里的三段宽度（40 / 40 / 62）与右让 74 是拍脑袋常量，没有单测，
  改一个数字就可能把 Esc 提示挤出去。

所以本轮不是换肤：把窄窗布局抽成纯函数、钉住「永远装得进脚注、不与左侧提示/右侧 Esc 相交」，
并补一张 `search-narrow` 基线。

## 2. 范围

- 抽 `mode_toggle(footer: Rect, narrow: bool) -> (toggle, text, pinyin)` 纯函数：
  - 宽窗：`精确文本` 62 + `拼音` 40；
  - 窄窗：`文本` 40 + `拼音` 40；
  - 左侧留出至少 `HINT_MIN`（左侧「↑↓ 选择 · Enter 打开」提示不被压）；
  - 右侧留 74（`Esc` 关闭提示的位置）。
- 脚注绘制改用纯函数；新增 `MW_TRACE` 一行
  `search_footer width=… narrow=… toggle=[x0,x1]`，窄窗判据可被脚本断言。
- 新基线 `search-narrow`：640×700 + `MW_INSPECTOR=1` + `Ctrl+F` 输入「排版」，
  停在拼音模式；判据是开关显示「文本 / 拼音」且不压左侧提示。
- 既有搜索基线（宽窗）**必须零漂移**：宽窗几何逐值不变。

## 3. 非目标

- 不改搜索匹配逻辑与结果行；不改宽窗标签文案与视觉。
- 不新增窗口尺寸下限；不做响应式换行（脚注只有一行）。
- 不改 `docs/02` 的快捷键。

## 4. 验收场景

1. **窄窗实拍**：`search-narrow` 2560×? 实际 640×700 @ ppp 1.0 = 960×1050 图像；
   开关在脚注右侧、显示「文本 / 拼音」，左侧提示完整。
2. **装得进**：纯函数单测——宽/窄两种宽度都落在 `footer` 内，且 `toggle.left >= footer.left + HINT_MIN`。
3. **宽窗零漂移**：八张既有搜索基线 `--tol 0` 全过。
4. **轨迹**：`search_footer … narrow=1` 出现在窄窗脚本里。

## 5. 预计证据

## 6. 实测结果（2026-11-01）

- **几何**：640×700 逻辑窗 + 检查器 288 → 中央 383、搜索卡片 **359**（`< 420` 触发窄窗）；
  轨迹 `search_footer width=359 narrow=1 toggle=[218,298]`——左界 218 远大于
  `MODE_HINT_MIN=64`，右界 298 = footer.right 372 − `MODE_RIGHT_RESERVE=74`。
  宽窗（1280×800）仍 `width=560 narrow=0 toggle=[434,536]`，与改前逐值一致。
- **ppp 的坑**：harness 的 `--ppp 1.0` 会让逻辑宽 = 物理宽；`MW_WINDOW_SIZE=640x700`
  在 150% DPI 下拍出 960×1050、逻辑 960，卡片仍是 560、`narrow=0`。必须 `--ppp 1.5`
  才能让逻辑宽回到脚本里的 640，基线因此是 `shell-ppp1.50.png`（960×1050）。
- **基线**：`search-narrow` 双跑 `--tol 0` 零差异。
- **既有宽窗场景**：`mode_toggle` 对 `narrow=false` 的取值与旧行内代码逐值相同，
  八张既有搜索基线预期零漂移（门内验证）。
- **单测**：`mode_toggle_fits_the_footer_at_every_width` 覆盖 240/326/420/560 四档
  （最窄 240 时左界 86 ≥ 64）；测试 1121 → **1122**。
