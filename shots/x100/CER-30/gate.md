## 判词记录（2026-11-02 · 授权代判）

授权：用户 2026-11-02 对「G-B2-3 八判词」与「`scripts/` 解禁登记进门脚本」两件事回
**「我都同意了，继续」**。先例是 G-B2-1 的「通过（2026-10-26 授权代判，8 条）」。
以下是逐条对着基线图看下来的记录，不是转抄 report 的结论。

1. **三层信息架构** — `library-three-pane`（css 1280）：侧栏 232 一列、列表 360 一列、
   预览余量一列，三栏之间只有 1px 分隔线，没有第二层容器。作用域计数 **16 / 2 / 3 / 4**
   四个数字互不相等，「收件箱 4 = 全部 4」这个旧语义分裂已经消失；标签树最深两级
   （`知识 › 方法`、`项目 › 织思`、`读书 › 笔记`），`#知识/方法/整理术` 这种三级路径
   只出现在列表行的元信息里，没有把侧栏撑出第三层缩进。
2. **行密度** — `library-long` 首屏 12 行半、`library-three-pane` 首屏 11 行半：
   行与行之间只有内缩的分隔线，没有白卡底、没有圆角、没有阴影；标题一行、摘要一行、
   元信息一行，三行之间的留白看着比旧版（94px 行 + 绝对坐标）紧，但没有挤到糊。
3. **标签安静** — `library-tag-filter`：筛选态是列表上方一行中性底 `#知识 ×` + 文字动作
   「清除筛选」，不是彩色胶囊墙；同一个 `#知识` 在侧栏圆点、列表元信息圆点、预览标签行
   三处是同一个绿点。`library` 与 `-ink`/`-mist`/`-sand` 四主题下色点跟随主题令牌。
4. **批量** — `library-select`：复选框只在进入选择模式后出现（非选择模式的
   `library-three-pane` 一个都没有）；底部批量条「已选 3 张 · 归档 导出 加标签 移出 取消」
   严格落在 360 列表栏内，没有横跨全窗；「移出」用强调色标危险。
   **未拍到的**：二次确认弹层与「一次批量一条结果提示」是单测 + 轨迹证据，基线里没有这一帧。
5. **两栏/单栏** — `library-preview`（1080×720 两栏档）预览是整页阅读面、左上角返回箭头，
   没有被挤成 300px 窄栏；`library-one-pane-narrow`（css 640×460）侧栏收成一个抽屉开关图标、
   列表满宽、标题/摘要各自省略号收尾，没有换行爆炸。**未拍**：合同列的 800×600 档
   （拍的是 800×720，见缺口 4）。
6. **10k** — `library-long` 首屏 10000 张全部就绪、计数与标签树（知识 10000 / 甲 5000 /
   乙 5000）都是对的，没有白屏；「只画可见行」由行 bbox 单测 + 虚拟化单测钉住。
   **诚实口径**：滚动 ≥55fps 是 CER-25 的探针数字，不是一帧一帧的图。
7. **目录判词** — 盖住 `library-three-pane` 右栏之后，剩下两栏是一行一条目的清单：
   标题、摘要、`#标签 +n 日期`，扫读节奏靠省略号和固定行高撑起来，不是卡片堆。
8. **阅读页判词** — 盖住 `library-preview` 左栏之后，剩下的就是一张卡片页：30/42 标题、
   一行元信息、一行标签、分隔线、H2 + 正文 + 待办，版心约 600，没有任何编辑控件、
   没有「打开编辑」大按钮；`-ink`/`-mist`/`-sand` 三张同一版式换皮不跑版。
